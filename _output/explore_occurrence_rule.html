1 Goal

v7c removed two things by hand-evidenced rows: the sea turtles from the East Bering Sea (zero records in nine channels) and the North Atlantic right whale from the Gulf of America ecoregions (an “outside range” judgment). Tim White (2026-10-21) asked for one written rule that treats both the same way, with tiers: protected places override, “unsampled is unknown, not absent”, wide-ranging taxa. The rule is msens::occurrence_rule() (msens 0.63.0, a wrapper of region_effort_test(), rule E of obis_range_constraint.qmd): per ecoregion, the species’ modelled 0.5-degree blocks that were searched (a record of its effort group exists) against those that hold a record of the species, judged against the species’ record rate in its OTHER ecoregions (OCC_BASELINE=zones, the default since msens 0.63.0; range = the whole modelled range, the rule as first written, kept below as a sensitivity: the right whale’s modelled range spans the North Atlantic, most of it unsurveyed in OBIS, and against that diluted baseline its Gulf pairs could not be significantly fewer); an ecoregion is dropped only when records are significantly (binomial p < alpha) AND materially (rate < ratio x the baseline rate) fewer, kept when nobody looked.

This notebook runs that rule at the D10 defaults over every scored taxon x the 12 BOEM ecoregions and tabulates it by component. It writes data/v11/zone_exclusions_occ.csv, which merge_models.qmd consumes under OCC_RULE=1.

Scope of this version of the notebook. Records come from OBIS only (the obisindicators obis_cell export, libs/obis_h3.R). GBIF through speciesgrids, iNaturalist and the Alaska stranding / observer channels are later additions (plan 2026-10-29 section 4.3, D10): more channels can only add searched blocks and records, so a drop here that disappears with GBIF is a channel gap, and the anchors are read with that in mind (the Gulf of Alaska turtles are reported, not asserted).

Defaults (D10): effort = megafauna records for air-breathers (mammals, turtles, birds) and the taxon’s own order for the rest; buffer d = OCC_BUFFER_KM (100 km: a record just outside an ecoregion counts, for RECORDS and EFFORT only; presence stays inside the ecoregion); ratio 0.25, alpha 0.05, 0.5-degree blocks, no recency weight, critical habitat and narrow-range (< 20 cells) overrides, all taxa. One data-quality choice is not in D10: OBIS records dated before 1950 are ignored (OCC_YEAR_MIN, as obis_range_constraint.qmd did); records without a year are kept.

4 WoRMS: records of a species, its order, the megafauna

OBIS records carry an AphiaID, which may be a synonym or an infraspecific name. Every record is credited to the accepted species: the accepted name (acceptedNameUsageID), then, for a subspecies / variety / form, its parent species. The accepted-species ids are then walked up parentNameUsageID to their Order and Class (worms_lineage). The two effort groups follow: order:{id} = blocks with a record of any species of the order, and mega = blocks with a record of any bird (Aves), mammal (Mammalia) or turtle (order Testudines).

5 The scored taxa and where their modelled range lives

A scored taxon is taxon.is_valid_usa AND taxon.is_marine with sp_cat in the seven components (reptiles and amphibians are not scored). Its present cells are val >= 1 on the v10 merged GLOBAL surface (dist_merged_global, built for the 2,105 range-constrained taxa); a taxon without one is AquaMaps-only, and its present cells are the union of its am models (taxon_model), the surface the merge itself would have used. The global surface is the right one (not the US trim): a zone is judged against the species’ record rate across its whole range. Which bucket directory (b1 … b402, and turtle) of the merged surface holds each key is read once (a taxon lives in exactly one). BirdLife taxa carry a BOTW id, not an AphiaID, so they are matched to WoRMS accepted species by name; an unmatched taxon has no records and every ecoregion comes out “unsearched” (kept), which is the safe direction.

8 Run the rule, batch by batch

For one batch: stream the batch’s surfaces into (taxon, cell) pairs with val >= 1, then reduce them without changing any count the rule takes: it uses present cells (a) inside an ecoregion (n_cells, and the protected test), (b) as distinct 0.5-degree blocks (searched / occupied / totals), and (c) as a worldwide cell count for the narrow-range override. So a species of at least block^2 x min_cells cells keeps every present cell inside an ecoregion plus one representative cell per block (which preserves the block set, and still has at least min_cells cells), and a smaller species keeps all its cells; a check below proves the narrow-range classification is unchanged. The effort relation is the species’ effort group restricted to the species’ own present blocks (the rule reads effort only there). Then occurrence_rule() runs: once at the D10 defaults (effort by taxon, d = OCC_BUFFER_KM, ratio OCC_RATIO) and, for the sensitivity table, at every buffer x effort proxy with ratio = 1 (the verdict at a smaller ratio is the ratio-1 verdict with rate < ratio x p_core applied on top, which the tabulation re-derives with region_effort_test() and checks against the default run).

  con, present = "occ_present", occ = "occ_records", effort = glue("occ_effort_{eff}"),
  region = "occ_region", region_rec = glue("occ_rec_{d}"), ch = "occ_ch",

run_batch <- function(b) {
  f_out <- glue("{dir_cnt}/{b}.parquet")
  if (file_exists(f_out)) return(invisible(NULL))
  t0 <- Sys.time()
  tb <- tx |> filter(batch == b) |> mutate(k = row_number())
  stopifnot(length(unique(tb$src)) == 1)
  dbWriteTable(con, "occ_tx", tb |> transmute(mdl_key, k = as.integer(k), sp_id, grp_order, eff_default, multi), overwrite = TRUE)

  # 1. stream the surfaces into (k, cell_id), val >= 1
  if (tb$src[1] == "merged") {
    globs <- glue("{dir_src}/dist_merged_global/dataset=ms_merge/{unique(tb$bucket)}/*.parquet")
    dbExecute(con, glue("
      CREATE OR REPLACE TABLE occ_scan AS
      SELECT t.k, s.cell_id
      FROM read_parquet([{q(globs)}], hive_partitioning = false) s
      JOIN occ_tx t ON t.mdl_key = s.mdl_key
      WHERE s.val >= 1"))
  } else {
    am <- tm_am |> inner_join(tb |> select(mdl_key, k), by = "mdl_key")
    files <- glue("{dir_src}/dist/dataset=am/{sub('^am[|]', '', am$am_key)}.parquet")
    stopifnot("an AquaMaps surface file is missing" = all(file_exists(files)))
    dbWriteTable(con, "occ_am", am |> transmute(am_key, k = as.integer(k)), overwrite = TRUE)
    dbExecute(con, glue("
      CREATE OR REPLACE TABLE occ_scan AS
      SELECT a.k, s.cell_id
      FROM read_parquet([{q(files)}], hive_partitioning = false) s
      JOIN occ_am a ON a.am_key = s.mdl_key
      WHERE s.val >= 1"))
  }
  # worldwide present cells per taxon (distinct: a multi-model AquaMaps taxon repeats cells)
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_n AS
    SELECT k, count(*) AS n FROM occ_scan WHERE k NOT IN (SELECT k FROM occ_tx WHERE multi) GROUP BY k
    UNION ALL
    SELECT k, count(DISTINCT cell_id) AS n FROM occ_scan WHERE k IN (SELECT k FROM occ_tx WHERE multi) GROUP BY k")
  # 2. reduce (see the prose above)
  dbExecute(con, glue("
    CREATE OR REPLACE TABLE occ_present AS
    SELECT t.mdl_key, x.cell_id FROM (
      SELECT DISTINCT k, cell_id FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n < {thr_small})
      UNION
      SELECT k, min(cell_id) FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n >= {thr_small}) GROUP BY k, {unit_sql('cell_id')}
      UNION
      SELECT k, cell_id FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n >= {thr_small}) AND cell_id IN (SELECT cell_id FROM occ_region)
    ) x JOIN occ_tx t USING (k)"))
  bad <- dbGetQuery(con, glue("
    SELECT count(*) AS n FROM (
      SELECT t.k, count(DISTINCT p.cell_id) AS r FROM occ_present p JOIN occ_tx t USING (mdl_key) GROUP BY t.k) a
    JOIN occ_n USING (k) WHERE (a.r < {occ_min_cells}) <> (occ_n.n < {occ_min_cells})"))$n
  stopifnot("the reduction changed a narrow-range classification" = bad == 0)
  n_in  <- dbGetQuery(con, "SELECT count(*) AS n FROM occ_scan")$n
  n_red <- dbGetQuery(con, "SELECT count(*) AS n FROM occ_present")$n
  dbExecute(con, "DROP TABLE occ_scan")

  # 3. records of each taxon (its accepted species, all synonyms / infraspecifics) and the effort relations
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_records AS
    SELECT t.mdl_key, o.cell_id, sum(o.records)::BIGINT AS records
    FROM occ_tx t JOIN obis_sp o ON o.sp_id = t.sp_id GROUP BY t.mdl_key, o.cell_id")
  mk_eff <- \(name, grp_expr) dbExecute(con, glue("
    CREATE OR REPLACE TABLE {name} AS
    SELECT DISTINCT p.mdl_key, p.cell_id
    FROM occ_present p JOIN occ_tx t USING (mdl_key)
    JOIN effort_blocks e ON e.grp = {grp_expr} AND e.unit_id = {unit_sql('p.cell_id')}"))
  mk_eff("occ_effort_order", "t.grp_order")
  mk_eff("occ_effort_mega",  "'mega'")
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_effort_default AS
    SELECT * FROM occ_effort_order WHERE mdl_key IN (SELECT mdl_key FROM occ_tx WHERE eff_default = 'order')
    UNION ALL
    SELECT * FROM occ_effort_mega  WHERE mdl_key IN (SELECT mdl_key FROM occ_tx WHERE eff_default = 'megafauna')")

  # 4. the rule: the D10 defaults, then the sensitivity grid at ratio = 1
  out <- list(
    rule("default", d_default, occ_ratio) |> mutate(run = "default", eff = "default", d = d_default, ratio = occ_ratio))
  for (eff in c("order", "mega")) for (d in d_all)
    out[[length(out) + 1]] <- rule(eff, d, 1) |> mutate(run = "sens", eff = ifelse(eff == "mega", "megafauna", eff), d = d, ratio = 1)
  res_b <- bind_rows(out) |> mutate(batch = b, n_scan = n_in, n_reduced = n_red)
  dbWriteTable(con, "occ_out", res_b, overwrite = TRUE)
  tmp <- glue("{f_out}.tmp")
  dbExecute(con, glue("COPY occ_out TO '{tmp}' (FORMAT parquet, COMPRESSION zstd)"))
  file_move(tmp, f_out)
  for (t in c("occ_out", "occ_present", "occ_records", "occ_n", "occ_effort_order", "occ_effort_mega", "occ_effort_default")) dbExecute(con, glue("DROP TABLE IF EXISTS {t}"))
  message(glue("batch {b}: {nrow(tb)} taxa, {format(n_in, big.mark = ',')} cells -> {format(n_red, big.mark = ',')} kept, ",
               "{nrow(res_b)} rule rows, {round(as.numeric(difftime(Sys.time(), t0, units = 'secs')))} s"))
  invisible(NULL)
}

9 Re-derive the ratio grid, and check the derivation

## Goal

v7c removed two things by hand-evidenced rows: the sea turtles from the East Bering Sea (zero records in nine channels)
and the North Atlantic right whale from the Gulf of America ecoregions (an "outside range" judgment). Tim White
(2026-10-21) asked for one written rule that treats both the same way, with tiers: protected places override,
"unsampled is unknown, not absent", wide-ranging taxa. The rule is `msens::occurrence_rule()` (msens 0.63.0, a wrapper
of `region_effort_test()`, rule E of `obis_range_constraint.qmd`): per ecoregion, the species' modelled 0.5-degree blocks
that were **searched** (a record of its effort group exists) against those that hold a record of the species, judged
against the species' record rate in its OTHER ecoregions (`OCC_BASELINE=zones`, the default since msens 0.63.0; `range` =
the whole modelled range, the rule as first written, kept below as a sensitivity: the right whale's modelled range spans
the North Atlantic, most of it unsurveyed in OBIS, and against that diluted baseline its Gulf pairs could not be
significantly fewer); an ecoregion is dropped only when records are significantly (binomial p < alpha) AND materially
(rate < ratio x the baseline rate) fewer, kept when nobody looked.

This notebook runs that rule at the D10 defaults over **every scored taxon x the 12 BOEM ecoregions** and tabulates it
by component. It writes `data/v11/zone_exclusions_occ.csv`, which `merge_models.qmd` consumes under `OCC_RULE=1`.

**Scope of this version of the notebook.** Records come from **OBIS only** (the obisindicators `obis_cell` export,
`libs/obis_h3.R`). GBIF through `speciesgrids`, iNaturalist and the Alaska stranding / observer channels are later
additions (plan 2026-10-29 section 4.3, D10): more channels can only add searched blocks and records, so a drop here
that disappears with GBIF is a channel gap, and the anchors are read with that in mind (the Gulf of Alaska turtles
are reported, not asserted).

Defaults (D10): effort = megafauna records for air-breathers (mammals, turtles, birds) and the taxon's own order for
the rest; buffer d = `OCC_BUFFER_KM` (100 km: a record just outside an ecoregion counts, for RECORDS and EFFORT
only; presence stays inside the ecoregion); ratio 0.25, alpha 0.05, 0.5-degree blocks, no recency weight, critical
habitat and narrow-range (< 20 cells) overrides, all taxa. One data-quality choice is not in D10: OBIS records dated
before 1950 are ignored (`OCC_YEAR_MIN`, as `obis_range_constraint.qmd` did); records without a year are kept.

## WoRMS: records of a species, its order, the megafauna

OBIS records carry an AphiaID, which may be a synonym or an infraspecific name. Every record is credited to the
**accepted species**: the accepted name (`acceptedNameUsageID`), then, for a subspecies / variety / form, its parent
species. The accepted-species ids are then walked up `parentNameUsageID` to their **Order** and **Class**
(`worms_lineage`). The two effort groups follow: `order:{id}` = blocks with a record of any species of the order, and
`mega` = blocks with a record of any bird (Aves), mammal (Mammalia) or turtle (order Testudines).

## The scored taxa and where their modelled range lives

A scored taxon is `taxon.is_valid_usa AND taxon.is_marine` with `sp_cat` in the seven components (reptiles and
amphibians are not scored). Its **present** cells are `val >= 1` on the v10 merged GLOBAL surface
(`dist_merged_global`, built for the 2,105 range-constrained taxa); a taxon without one is AquaMaps-only, and its
present cells are the union of its `am` models (`taxon_model`), the surface the merge itself would have used. The
global surface is the right one (not the US trim): a zone is judged against the species' record rate across its whole
range. Which bucket directory (`b1` ... `b402`, and `turtle`) of the merged surface holds each key is read once (a taxon lives in exactly one).
BirdLife taxa carry a BOTW id, not an AphiaID, so they are matched to WoRMS accepted species by name; an unmatched taxon
has no records and every ecoregion comes out "unsearched" (kept), which is the safe direction.

    left_join(bk_n, by = "bucket") |> arrange(suppressWarnings(as.integer(sub("^b", "", bucket))), bucket) |>
    mutate(batch = sprintf("m%03d", dense_rank(cumsum(n) %/% cap_rows)))

    left_join(n_am, by = "mdl_key") |>
    mutate(batch = coalesce(m_b$batch[match(bucket, m_b$bucket)], a_b$batch[match(mdl_key, a_b$mdl_key)]),

## Run the rule, batch by batch

For one batch: stream the batch's surfaces into `(taxon, cell)` pairs with `val >= 1`, then **reduce** them without
changing any count the rule takes: it uses present cells (a) inside an ecoregion (`n_cells`, and the protected test),
(b) as distinct 0.5-degree blocks (searched / occupied / totals), and (c) as a worldwide cell count for the
narrow-range override. So a species of at least `block^2 x min_cells` cells keeps every present cell inside an
ecoregion plus one representative cell per block (which preserves the block set, and still has at least `min_cells`
cells), and a smaller species keeps all its cells; a check below proves the narrow-range classification is unchanged.
The effort relation is the species' effort group restricted to the species' own present blocks (the rule reads effort
only there). Then `occurrence_rule()` runs: once at the D10 defaults (effort by taxon, d = `OCC_BUFFER_KM`, ratio
`OCC_RATIO`) and, for the sensitivity table, at every buffer x effort proxy with `ratio = 1` (the verdict at a smaller
ratio is the ratio-1 verdict with `rate < ratio x p_core` applied on top, which the tabulation re-derives with
`region_effort_test()` and checks against the default run).

```{r}
#| label: run-batches
#| message: false

thr_small <- occ_block^2 * occ_min_cells     # a species with fewer cells than this keeps ALL of them

rule <- function(eff, d, ratio) occurrence_rule(
  con, present = "occ_present", occ = "occ_records", effort = glue("occ_effort_{eff}"),
  region = "occ_region", region_rec = glue("occ_rec_{d}"), ch = "occ_ch",
  nc = occ_nc, block = occ_block, alpha = occ_alpha, ratio = ratio, min_cells = occ_min_cells, baseline = occ_baseline)

run_batch <- function(b) {
  f_out <- glue("{dir_cnt}/{b}.parquet")
  if (file_exists(f_out)) return(invisible(NULL))
  t0 <- Sys.time()
  tb <- tx |> filter(batch == b) |> mutate(k = row_number())
  stopifnot(length(unique(tb$src)) == 1)
  dbWriteTable(con, "occ_tx", tb |> transmute(mdl_key, k = as.integer(k), sp_id, grp_order, eff_default, multi), overwrite = TRUE)

  # 1. stream the surfaces into (k, cell_id), val >= 1
  if (tb$src[1] == "merged") {
    globs <- glue("{dir_src}/dist_merged_global/dataset=ms_merge/{unique(tb$bucket)}/*.parquet")
    dbExecute(con, glue("
      CREATE OR REPLACE TABLE occ_scan AS
      SELECT t.k, s.cell_id
      FROM read_parquet([{q(globs)}], hive_partitioning = false) s
      JOIN occ_tx t ON t.mdl_key = s.mdl_key
      WHERE s.val >= 1"))
  } else {
    am <- tm_am |> inner_join(tb |> select(mdl_key, k), by = "mdl_key")
    files <- glue("{dir_src}/dist/dataset=am/{sub('^am[|]', '', am$am_key)}.parquet")
    stopifnot("an AquaMaps surface file is missing" = all(file_exists(files)))
    dbWriteTable(con, "occ_am", am |> transmute(am_key, k = as.integer(k)), overwrite = TRUE)
    dbExecute(con, glue("
      CREATE OR REPLACE TABLE occ_scan AS
      SELECT a.k, s.cell_id
      FROM read_parquet([{q(files)}], hive_partitioning = false) s
      JOIN occ_am a ON a.am_key = s.mdl_key
      WHERE s.val >= 1"))
  }
  # worldwide present cells per taxon (distinct: a multi-model AquaMaps taxon repeats cells)
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_n AS
    SELECT k, count(*) AS n FROM occ_scan WHERE k NOT IN (SELECT k FROM occ_tx WHERE multi) GROUP BY k
    UNION ALL
    SELECT k, count(DISTINCT cell_id) AS n FROM occ_scan WHERE k IN (SELECT k FROM occ_tx WHERE multi) GROUP BY k")
  # 2. reduce (see the prose above)
  dbExecute(con, glue("
    CREATE OR REPLACE TABLE occ_present AS
    SELECT t.mdl_key, x.cell_id FROM (
      SELECT DISTINCT k, cell_id FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n < {thr_small})
      UNION
      SELECT k, min(cell_id) FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n >= {thr_small}) GROUP BY k, {unit_sql('cell_id')}
      UNION
      SELECT k, cell_id FROM occ_scan WHERE k IN (SELECT k FROM occ_n WHERE n >= {thr_small}) AND cell_id IN (SELECT cell_id FROM occ_region)
    ) x JOIN occ_tx t USING (k)"))
  bad <- dbGetQuery(con, glue("
    SELECT count(*) AS n FROM (
      SELECT t.k, count(DISTINCT p.cell_id) AS r FROM occ_present p JOIN occ_tx t USING (mdl_key) GROUP BY t.k) a
    JOIN occ_n USING (k) WHERE (a.r < {occ_min_cells}) <> (occ_n.n < {occ_min_cells})"))$n
  stopifnot("the reduction changed a narrow-range classification" = bad == 0)
  n_in  <- dbGetQuery(con, "SELECT count(*) AS n FROM occ_scan")$n
  n_red <- dbGetQuery(con, "SELECT count(*) AS n FROM occ_present")$n
  dbExecute(con, "DROP TABLE occ_scan")

  # 3. records of each taxon (its accepted species, all synonyms / infraspecifics) and the effort relations
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_records AS
    SELECT t.mdl_key, o.cell_id, sum(o.records)::BIGINT AS records
    FROM occ_tx t JOIN obis_sp o ON o.sp_id = t.sp_id GROUP BY t.mdl_key, o.cell_id")
  mk_eff <- \(name, grp_expr) dbExecute(con, glue("
    CREATE OR REPLACE TABLE {name} AS
    SELECT DISTINCT p.mdl_key, p.cell_id
    FROM occ_present p JOIN occ_tx t USING (mdl_key)
    JOIN effort_blocks e ON e.grp = {grp_expr} AND e.unit_id = {unit_sql('p.cell_id')}"))
  mk_eff("occ_effort_order", "t.grp_order")
  mk_eff("occ_effort_mega",  "'mega'")
  dbExecute(con, "
    CREATE OR REPLACE TABLE occ_effort_default AS
    SELECT * FROM occ_effort_order WHERE mdl_key IN (SELECT mdl_key FROM occ_tx WHERE eff_default = 'order')
    UNION ALL
    SELECT * FROM occ_effort_mega  WHERE mdl_key IN (SELECT mdl_key FROM occ_tx WHERE eff_default = 'megafauna')")

  # 4. the rule: the D10 defaults, then the sensitivity grid at ratio = 1
  out <- list(
    rule("default", d_default, occ_ratio) |> mutate(run = "default", eff = "default", d = d_default, ratio = occ_ratio))
  for (eff in c("order", "mega")) for (d in d_all)
    out[[length(out) + 1]] <- rule(eff, d, 1) |> mutate(run = "sens", eff = ifelse(eff == "mega", "megafauna", eff), d = d, ratio = 1)
  res_b <- bind_rows(out) |> mutate(batch = b, n_scan = n_in, n_reduced = n_red)
  dbWriteTable(con, "occ_out", res_b, overwrite = TRUE)
  tmp <- glue("{f_out}.tmp")
  dbExecute(con, glue("COPY occ_out TO '{tmp}' (FORMAT parquet, COMPRESSION zstd)"))
  file_move(tmp, f_out)
  for (t in c("occ_out", "occ_present", "occ_records", "occ_n", "occ_effort_order", "occ_effort_mega", "occ_effort_default")) dbExecute(con, glue("DROP TABLE IF EXISTS {t}"))
  message(glue("batch {b}: {nrow(tb)} taxa, {format(n_in, big.mark = ',')} cells -> {format(n_red, big.mark = ',')} kept, ",
               "{nrow(res_b)} rule rows, {round(as.numeric(difftime(Sys.time(), t0, units = 'secs')))} s"))
  invisible(NULL)
}

batch_ids <- sort(unique(tx$batch))
walk(batch_ids, run_batch)
f_counts <- list.files(dir_cnt, "[.]parquet$", full.names = TRUE)
stopifnot("not every batch produced a counts file" = length(f_counts) == length(batch_ids))
res_all <- dbGetQuery(con, glue("SELECT * FROM read_parquet([{q(f_counts)}])")) |> as_tibble()
meta <- tx |> select(mdl_key, taxon_id, scientific_name, common_name, sp_cat, eff_default, src, order_name, class_name)
message(glue("{nrow(res_all)} rule rows over {n_distinct(res_all$mdl_key)} taxa"))
```

## Re-derive the ratio grid, and check the derivation

The sensitivity runs used ratio 1. The verdict at any smaller ratio is `region_effort_test()` on the stored counts
(the "unsearched" test does not depend on the ratio) with the stored override flag applied on top. Two checks make
the derivation trustworthy: at ratio 1 it must reproduce the stored verdicts, and at the default
(buffer, ratio, effort by taxon) it must reproduce the dropped set of the direct `occurrence_rule()` run.

```{r}
#| label: derive

base_cols <- if (occ_baseline == "zones") c("n_searched_zones", "n_occupied_zones") else c("n_searched_all", "n_occupied_all")
verdict_at <- function(x, ratio, cols = base_cols) {
  v <- region_effort_test(x$n_searched, x$n_occupied, x[[cols[1]]], x[[cols[2]]],
                          n_records = x$n_records, alpha = occ_alpha, ratio = ratio)$verdict
  ifelse(v == "dropped" & !is.na(x$override), "kept", v)
}
res_def  <- res_all |> filter(run == "default") |> left_join(meta, by = "mdl_key")
res_sens <- res_all |> filter(run == "sens")    |> left_join(meta, by = "mdl_key")

stopifnot("derivation at ratio 1 must reproduce the stored verdicts" = identical(verdict_at(res_sens, 1), res_sens$verdict))
# effort by taxon at (d_default, occ_ratio) from the order / megafauna sens rows == the direct default run
mix <- res_sens |> filter(d == d_default, eff == eff_default) |> mutate(verdict = verdict_at(pick(everything()), occ_ratio))
key <- \(x) sort(paste(x$mdl_key, x$zone_key))
stopifnot("derived default must reproduce the direct occurrence_rule() default" =
            identical(key(filter(mix, verdict == "dropped")), key(filter(res_def, verdict == "dropped"))),
          "derived default has other rows than the direct run" = nrow(mix) == nrow(res_def))
message(glue("derivation verified: {sum(res_def$verdict == 'dropped')} dropped pairs at the defaults"))
```

## Sensitivity: the baseline the record rate is judged against

Not written to the CSV: the same counts judged against the OTHER baseline. The default (`OCC_BASELINE=zones`, msens
0.63.0) compares an ecoregion with the species' record rate across its other ecoregions of the set (the 12 BOEM
ecoregions, Tim's "US denominator"); the rule as first written (`range`) used the species' WHOLE modelled range. For a
species whose modelled range is far wider than where it is recorded (the right whale: IUCN range x AquaMaps suitability
