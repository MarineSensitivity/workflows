1 Why

The six sea turtles and the North Atlantic right whale all have a published OBIS (MPA Europe) species distribution model on exactly our global05 grid (s3://obis-maps/sdm/species/taxonid={AphiaID}/model=mpaeu/). A model surface is not a range: the loggerhead model calls tens of thousands of Alaska cells suitable, and the v9 right whale surface (the IUCN range at a flat 100) covers the Gulf. This notebook scores five candidate rules for turning a model surface into a range, on one scorecard, by polygon (Program Areas and US EEZ subregions, not latitude / longitude boxes), using only what OBIS published, so nothing here needs a refit.

candidate needs a refit
A OBIS’s own recipe: threshold P10, inside the convex hull of fitted records, keeping only patches within 100 km of a record no
B Tim White’s buffer around occurrences: 150, 250, 400 km no
C the v7.1 rule: AquaMaps suitability of 0.5 or more inside the range, critical habitat kept no
D threshold plus uncertainty: value minus one bootstrap spread clears the threshold; not an extrapolation provisional here
E D plus the regional test with search effort provisional here

The notebook takes one parameter, model. With mpaeu (the default) it scores OBIS’s published models, and D and E are provisional: their threshold is the published P10, which is fitted on training data. With one of our own runs (og, ogm, a control) the threshold of D and E is the held-out one, from the fold predictions our patched pipeline saves. The rule itself is the same either way and lives in msens (R/range.R, tests/testthat/test-range.R), which this notebook only calls.

2.2 The threshold of rules D and E

Code 
# held-out predictions of each accepted algorithm, saved per fold by the patched pipeline
# (metrics/..._method={m}_what=cvpred.parquet; cvpredtrain = the fold's model on its training rows).
# the ensemble is the per-row median of the accepted algorithms, as on the map
algo_file <- c(maxent = "maxent", rf = "rf_classification_ds", xgboost = "xgboost")
cv_read <- function(id, what) {
  good <- str_split_1(d_sp$good[d_sp$taxon == id], ", ")
  map_dfr(good, ~ read_parquet(f_mod(id, "metrics", glue("method={algo_file[.x]}_what={what}\\.parquet"))) |> mutate(algo = .x))
}
cv_ens <- function(d) d |> summarise(pred = median(pred) * 100, .by = c(fold, idx, presence))
if (is_pub) {
  d_sp$thr <- d_sp$thr_p10
  d_thr    <- NULL
} else {
  d_thr <- map_dfr(d_sp$taxon, function(id) {
    te <- cv_read(id, "cvpred"); tr <- cv_read(id, "cvpredtrain")
    # an accepted algorithm can lack folds (its fit failed there: Kemp's ridley ogm maxent has 3 of 5); within a fold
    # the algorithms present share the rows, and the held-out ensemble is the median of those present, as on the map
    n_fa <- count(te, fold, algo)
    stopifnot(all(summarise(n_fa, ok = n_distinct(n) == 1, .by = fold)$ok))
    gaps <- n_fa |> summarise(folds = paste(sort(fold), collapse = ","), .by = algo) |>
      filter(folds != paste(sort(unique(te$fold)), collapse = ","))
    h  <- heldout_threshold(cv_ens(te), cv_ens(tr), sens = SENS)
    tibble(
      taxon = id, thr = h$thr, sens = h$pooled$sens, spec = h$pooled$spec,
      algo_folds = if (nrow(gaps)) paste(gaps$algo, "folds", gaps$folds, collapse = "; ") else "all",
      # what the training threshold of each fold delivers on the rows that fold never saw
      train_thr = mean(h$folds$thr), train_thr_sens = sum(h$folds$tp) / sum(h$folds$tp + h$folds$fn),
      folds = list(h$folds))
  })
  d_sp <- left_join(d_sp, select(d_thr, taxon, thr), by = "taxon")
  write_csv(
    d_thr |> select(taxon, folds) |> unnest(folds), here(glue("data/og/{lbl}_heldout_folds.csv")))
}

2.5 Records and search effort

Records of a species are OBIS’s quality-controlled points for it (one per cell, 1950 on; the file the published model was fitted from). Search effort is where somebody recorded the species’ target group: a cell with any such record was looked at by someone who would have reported the species. Two definitions, because the answer depends on it:

  • order: the species’ own order. All sea turtles for a turtle, all cetaceans for the right whale.
  • mega: every air-breathing marine vertebrate (birds, mammals, turtles). Seabird and marine mammal surveys record turtles and whales when they see them.

Effort comes from speciesgrids (OBIS + GBIF records per species and global05 cell).

3 Cell table

One row per species and cell that any rule could keep: the model’s value, its bootstrap spread, the extrapolation flag, OBIS’s masks, the distance to the nearest record, and the v9 inputs.

Code 
to_xyz <- function(lon, lat) {
  lo <- lon * pi / 180; la <- lat * pi / 180
  cbind(cos(la) * cos(lo), cos(la) * sin(lo), sin(la))
}
# great-circle km from each query cell to the nearest point (kd-tree on the unit sphere)
near_km <- function(cell_id, lon, lat) {
  if (!length(lon)) return(rep(NA_real_, length(cell_id)))
  xy <- xyFromCell(r_cid, cell_id)
  ch <- get.knnx(to_xyz(lon, lat), to_xyz(xy[, 1], xy[, 2]), k = 1)$nn.dist[, 1]
  2 * 6371.0088 * asin(pmin(ch / 2, 1))
}

build_cells <- function(id) {
  sp  <- d_sp[d_sp$taxon == id, ]
  e   <- rast(f_ens(id))
  mk  <- rast(f_mod(id, "predictions", "(what=)?mask_cog\\.tif"))    # our runs write it without `what=`
  ms  <- rast(f_mod(id, "predictions", "what=mess_cog\\.tif"))[["current"]]
  # the bootstrap layer comes from a separate step; without it the spread is missing (the rule then
  # treats it as 0) and the notebook says so in the cell-table summary
  f_bc <- f_mod(id, "predictions", "method=ensemble_scen=current_what=bootcv_cog\\.tif", must = F)
  bc   <- if (is.na(f_bc)) NULL else rast(f_bc)
  stopifnot(compareGeom(e, mk, stopOnError = F), is.null(bc) || (compareGeom(e, bc, stopOnError = F) && names(bc)[1] == "sd"))

  val  <- values(e[[1]], mat = F)
  # the published MESS layer is the count of predictors outside the fitted range, on a 0.6 degree grid
  mess <- values(resample(ms, e[[1]], method = "near"), mat = F)

  ch   <- v9_cells(id, c("ch_nmfs", "ch_fws"))
  am   <- v9_cells(id, "am")
  rng  <- v9_cells(id, c("rng_iucn", "rng_fws", "rng_turtle_swot_dps"))
  iucn <- v9_cells(id, "rng_iucn")
  occ  <- d_occ$cell_id[d_occ$taxon == id]
  fit  <- d_fit[d_fit$taxon == id, ]

  # rule A, as OBIS codes it (functions/post_proc_functions.R limit_by_closest): mask, threshold P10,
  # label 8-connected patches, keep the patches within PATCH_KM of a fitted record
  patch_keep <- function(band) {
    m  <- values(mk[[band]], mat = F) == 1
    ok <- !is.na(val) & val >= sp$thr_p10 & !is.na(m) & m
    r  <- e[[1]]; values(r) <- ifelse(ok, 1L, NA_integer_)
    p  <- values(patches(r, directions = 8), mat = F)
    i  <- which(ok)
    near <- near_km(i, fit$lon, fit$lat) <= PATCH_KM
    ok & p %in% unique(p[i][near])
  }
  a_hull <- patch_keep("convex_hull")
  a_fitr <- patch_keep("fit_region")

  cells <- sort(unique(c(which(!is.na(val) & val >= 1), ch$cell_id, am$cell_id, rng$cell_id, occ)))
  cells <- cells[!is.na(cells)]
  tibble(
    taxon      = id,
    cell_id    = as.integer(cells),
    unit_id    = as.integer(unit_of(cells)),
    val        = val[cells],
    spread     = if (is.null(bc)) NA_real_ else values(bc[[1]], mat = F)[cells],
    sd_algo    = values(e[[2]], mat = F)[cells],
    extrap     = mess[cells] > 0,
    is_ch      = cells %in% ch$cell_id,
    in_hull    = values(mk[["convex_hull"]], mat = F)[cells] == 1,
    a_hull     = a_hull[cells],

6 The regional test

For each species and EEZ subregion: among the units the model calls present (rule D’s cells), how many were searched, how many of those hold a record of the species, and how surprising is that count given the model’s precision everywhere else (msens::region_effort_test()). Four variants: two effort definitions, at the cell (0.05°) and at 0.5° blocks. A block is the more honest trial, because records cluster and neighbouring cells are not independent searches.

6.0.1 Why the test needs an effect size

7.3 Fitted records kept, and the cost to the core range

A rule that removes Alaska by removing the Gulf has not helped. Records kept is the share of the fitted records (whole globe) that fall in a kept cell. Core cost is the share of P10 cells lost in the regions where the species has at least 20 fitted records.

8 Maps

One panel per rule: kept cells in the lower 48 / Gulf / Atlantic window and in the Alaska window. Grey = the model’s P10 cells the rule dropped; colour = the model value in kept cells.

Code 
wins <- list(
  "Gulf and Atlantic" = ext(-100, -60, 17, 48),
  "Alaska and the Pacific coast" = ext(-180, -115, 30, 75))
map_rules <- c("A", "B 250 km", "C", "D", "E", "E mega")   # six panels per window
for (id in d_sp$taxon) {
  cat(glue("\n\n### {d_sp$common[d_sp$taxon == id]}\n\n"))
  d  <- dbGetQuery(con, glue("
    SELECT c.cell_id, c.val, c.val >= t.thr AS p10, k.rule
    FROM og_cell c JOIN og_p10 t USING (taxon) LEFT JOIN sc_keep k USING (taxon, cell_id)
    WHERE c.taxon = {id}"))
  for (wn in names(wins)) {
    tmpl <- crop(r_cid, wins[[wn]])
    par(mfrow = c(2, 3))
    for (rl in map_rules) {
      bg <- tmpl; values(bg) <- NA
      fg <- bg
      i_bg <- cellFromXY(tmpl, xyFromCell(r_cid, unique(d$cell_id[d$p10 %in% TRUE])))
      bg[i_bg[!is.na(i_bg)]] <- 1
      k    <- d[d$rule %in% rl, ]
      i_fg <- cellFromXY(tmpl, xyFromCell(r_cid, k$cell_id))
      fg[i_fg[!is.na(i_fg)]] <- coalesce(k$val[!is.na(i_fg)], 0)
      plot(bg, col = "grey80", legend = F, main = glue("{rl}: {wn}"), mar = c(2, 2, 2, 4))
      if (any(!is.na(i_fg))) plot(fg, add = T, range = c(0, 100), col = hcl.colors(50, "viridis", rev = T), legend = F)
    }
  }
}
