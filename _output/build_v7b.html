Build v7.1 (v7b) — sea-turtle core habitat + the coverage floor

Published

2026-09-20

v7.1 is a surgical patch of the public v7 release — same usa05 grid, same mdl_seq/value schema, same 20 Program Areas — built the way v7 itself was built: clone the previous DuckDB, change only what the fix touches, then re-execute v7’s own scoring chunks verbatim. Two method changes, nothing else:

  1. Sea-turtle core habitat. AquaMaps suitability enters the turtle merge only where P ≥ 0.5 (AquaMaps’ own core-habitat default), and a range cell with no retained suitability is dropped — the floor-of-1 fill goes. A threshold alone removes none of that fill: for five of the six turtles half to nine tenths of the merged US area is fill, with no AquaMaps value at all. Critical habitat still overrides by max, so no designated cell is ever trimmed.
  2. Coverage floor κ = 5 %. A component is reportable in a Program Area only if its scored cells cover ≥ 5 % of the area. Below that it is not reportable — no row, excluded from the composite exactly as a component with no cells is, never published as a zero.

Both are flags whose control value is off, so the same code path reproduces v7 exactly. That is the first gate below, and it is what makes every other number here attributable.

Not in v7.1: the year-integrated productivity, the distribution-share / national score, occurrence masks, per-taxon thresholds, any change to Formula 9.4. All of that is v10. Every primprod* row of v7b must equal v7’s, and a gate asserts it in every run.

get_chunk <- function(label) {
  lab <- grep(glue("^#\\|\\s*label:\\s*{label}\\s*$"), qmd_lines)
  stopifnot("chunk label not found exactly once in old/calc_scores_v7.qmd" = length(lab) == 1)
  open  <- max(grep("^```\\{", qmd_lines[seq_len(lab)]))
  close <- lab + grep("^```\\s*$", qmd_lines[(lab + 1):length(qmd_lines)])[1]
  code  <- qmd_lines[(open + 1):(close - 1)]
  paste(code[!grepl("^#\\|", code)], collapse = "\n")
}

# `IUCN:TN` is a v1-v7 data artifact: an ESA "Threatened" code stamped with the IUCN
# authority, on 11 taxa (1 mammal -- the Arctic ringed seal -- and 10 birds). The msens that
# built v7 did not validate the code, so it fell through `score_iucn`'s `.default = 1L` and
# scored **1**; that is what `taxon.er_score` still stores for all 11. msens >= 0.19 ERRORS
# on it, which stops `calc_cell_metric_redlist` dead. Reproducing v7 means reproducing that
# 1 -- recoding those taxa is a data question, and it belongs to v10, not to a patch that
# must reproduce its predecessor exactly. The IUCN branch also ignores `is_mmpa` (the same
# documented quirk that made `IUCN:LC + MMPA` score 1); that too is v7's behavior and stays.
ER_LEGACY <- c("IUCN:TN" = 1L)
er_score_v7 <- function(extrisk_code, is_mmpa = FALSE, is_mbta = FALSE) {
  n   <- length(extrisk_code)
  out <- rep(NA_integer_, n)
  leg <- !is.na(extrisk_code) & extrisk_code %in% names(ER_LEGACY)
  if (any(leg))  out[leg]  <- unname(ER_LEGACY[extrisk_code[leg]])
  if (any(!leg)) out[!leg] <- msens::compute_er_score(
    extrisk_code[!leg],
    is_mmpa = rep_len(is_mmpa, n)[!leg],
    is_mbta = rep_len(is_mbta, n)[!leg])
  out
}

# copy-on-write clone: APFS `cp -c` on the laptop, `cp --reflink=auto` on Linux. A 3.6 GB
# release database clones in milliseconds and only the pages the patch rewrites cost space.
clone_db <- function(src, dst) {
  if (file_exists(dst))               file_delete(dst)
  if (file_exists(glue("{dst}.wal"))) file_delete(glue("{dst}.wal"))
  dir_create(path_dir(dst))
  flag <- if (is_server) "--reflink=auto" else "-c"
  rc   <- system2("cp", c(flag, shQuote(src), shQuote(dst)))
  stopifnot("copy-on-write clone failed" = identical(as.integer(rc), 0L))
  log_info("cloned {src} -> {dst}")
}

# the turtle rewrite: same rule, same ids. Re-merging through the old loop would RENUMBER
# mdl_seq and break every published ?mdl_seq= deep link, so rows are replaced under the
# existing merged ids.
rewrite_turtles <- function(con, suit_min, fill) {
  seqs <- dbGetQuery(con, "SELECT mdl_seq FROM taxon WHERE sp_cat = 'turtle' ORDER BY mdl_seq")$mdl_seq
  stopifnot("expected v7's six merged turtle models at 54238-54243" =
    identical(as.integer(seqs), 54238:54243))
  seq_sql <- paste(seqs, collapse = ", ")

  dbExecute(con, "CREATE OR REPLACE TEMP VIEW turtle_src AS
    SELECT t.mdl_seq AS ms_merge_key, tm.ds_key, mc.cell_id, mc.value AS val
    FROM taxon t
    JOIN taxon_model tm ON tm.taxon_id = t.taxon_id AND tm.ds_key <> 'ms_merge'
    JOIN model_cell  mc ON mc.mdl_seq  = tm.mdl_seq
    WHERE t.sp_cat = 'turtle'")

  # half_even = TRUE reproduces R's rounding, which is what built v1-v7 (DuckDB round()
  # differs on 28,598 v7 cells where ER = 50); ch_outer = TRUE keeps the 31 CH cells that
  # lie outside the ER footprint, as v7's union did.
  sql <- msens::turtle_sql(
    DS_ER, DS_SUIT, DS_CH, src = "turtle_src",
    suit_min = suit_min, fill = fill, half_even = TRUE, ch_outer = TRUE)
  # materialize BEFORE the delete: turtle_src reads model_cell, which is about to change
  dbExecute(con, glue("CREATE OR REPLACE TEMP TABLE turtle_new AS {sql}"))

  dbExecute(con, glue("DELETE FROM model_cell WHERE mdl_seq IN ({seq_sql})"))
  n <- dbExecute(con, glue(
    "INSERT INTO model_cell (mdl_seq, cell_id, value)
     SELECT mdl_key::INTEGER, cell_id, val::INTEGER FROM turtle_new"))

  rule <- glue(
    "v7.1 turtle core habitat: suit_min={suit_min}, ",
    "fill={if (is.na(fill)) 'none' else fill}, half_even=TRUE, ch_outer=TRUE")
  # idempotent: strip any previous v7.1 clause before appending, so a re-run does not stack
  dbExecute(con, glue(
    "UPDATE model SET description =
       regexp_replace(coalesce(description, ''), ' \\| v7\\.1 turtle.*$', '') || ' | {rule}'
     WHERE mdl_seq IN ({seq_sql})"))
  log_info("turtles rewritten: {format(n, big.mark = ',')} cells under mdl_seq {seq_sql}")
  n
}

# kappa: a ZONE reporting rule. Cell-level rasters are untouched; only the Program-Area
# component row of a pair below the floor is deleted (its raw and _prepctareaweighting rows
# stay, so the diagnostic remains readable), and the composite then averages one fewer
# component -- exactly as it already does for an area with no turtles at all.
apply_kappa <- function(con, tbl_pra, component_keys, kappa, f_csv) {
  if (is.na(kappa) || kappa <= 0) {
    log_info("COVERAGE_FLOOR off -- no _coverage metrics written, no component dropped")
    return(invisible(NULL))
  }
  d <- dbGetQuery(con, msens::coverage_sql(
        tbl_pra, component_keys, weight = "pct_covered",
        val_col = msens::sdm_val_col(con, "cell_metric"))) |>
    msens::coverage_floor(kappa = kappa)

  z_seqs <- dbGetQuery(con, glue(
    "SELECT zone_seq FROM zone WHERE tbl = '{tbl_pra}'"))$zone_seq
  z_sql  <- paste(z_seqs, collapse = ", ")

  for (k in component_keys) {
    k_cov <- glue("{k}_coverage")
    if (!nrow(dbGetQuery(con, glue("SELECT 1 FROM metric WHERE metric_key = '{k_cov}'"))))
      dbExecute(con, glue(
        "INSERT INTO metric (metric_key, description) VALUES
         ('{k_cov}', 'Percent of the zone covered by cells carrying {k} (coverage floor input)')"))
    s_cov <- dbGetQuery(con, glue(
      "SELECT metric_seq FROM metric WHERE metric_key = '{k_cov}'"))$metric_seq
    dbExecute(con, glue(
      "DELETE FROM zone_metric WHERE metric_seq = {s_cov} AND zone_seq IN ({z_sql})"))
    dd <- d |> filter(metric_key == k)
    if (nrow(dd))
      dbExecute(con, glue(
        "INSERT INTO zone_metric (zone_seq, metric_seq, value) VALUES {vals}",
        vals = paste(glue("({dd$zone_seq}, {s_cov}, {dd$coverage * 100})"), collapse = ", ")))
  }

  d_drop <- d |> filter(!reportable)
  for (i in seq_len(nrow(d_drop)))
    dbExecute(con, glue(
      "DELETE FROM zone_metric
       WHERE zone_seq = {d_drop$zone_seq[i]}
         AND metric_seq = (SELECT metric_seq FROM metric WHERE metric_key = '{d_drop$metric_key[i]}')"))

  d_out <- d |>
    left_join(dbGetQuery(con, glue(
      "SELECT zone_seq, value AS programarea_key FROM zone WHERE tbl = '{tbl_pra}'")),
      by = "zone_seq") |>
    arrange(coverage) |>
    select(programarea_key, metric_key, coverage, reportable)
  write_csv(d_out |> filter(!reportable), f_csv)
  log_info("kappa={kappa}: {nrow(d_drop)} of {nrow(d)} (zone x component) pairs not reportable")
  invisible(d_out)
}

# the methods a release actually used, as data -- backfill_versions.qmd stages this table and
# manifest_build() carries it as `methods`, so the docs state the rules from the release itself
write_release_method <- function(con, suit_min, fill, kappa) {
  d <- tibble(
    method_key  = c("turtle_suit_min", "turtle_fill", "coverage_floor_pct", "prev"),
    value       = c(
      as.character(suit_min),
      if (is.na(fill)) "none" else as.character(fill),
      as.character(if (is.na(kappa)) 0 else kappa * 100),
      ver_prev),
    description = c(
      "AquaMaps suitability strictly below this is absent before the turtle multiply (v7: 0)",
      "Suitability assumed for a turtle range cell with none retained; 'none' drops the cell unless critical habitat covers it (v7: 1)",
      "A Program-Area component is reportable only if its scored cells cover at least this percent of the area (v7: 0)",
      "The release this one patches"))
  dbWriteTable(con, "release_method", d, overwrite = TRUE)
  d
}

build_release <- function(db_path, out_dir, suit_min, fill, kappa, label) {
  t0 <- Sys.time()
  dir_create(out_dir)
  clone_db(sdm_db_prev, db_path)

  con <- dbConnect(duckdb(dbdir = db_path, read_only = FALSE))
  on.exit(dbDisconnect(con, shutdown = TRUE), add = TRUE)
  dbExecute(con, "PRAGMA memory_limit='12GB'")
  dbExecute(con, "PRAGMA threads=6")
  dbExecute(con, glue("PRAGMA temp_directory='{out_dir}/duckdb_tmp'"))

  # the server's clone inherits a cell_model VIEW whose read_parquet path is absolute and
  # points at {ver_prev}: left in place it would serve the PREVIOUS release's cells under
  # this release's name. Dropped, then asserted gone.
  dbExecute(con, "DROP VIEW IF EXISTS cell_model")
  v_bad <- dbGetQuery(con, glue(
    "SELECT view_name FROM duckdb_views() WHERE sql LIKE '%/{ver_prev}/%'"))
  stopifnot("a view still references the previous release's path" = nrow(v_bad) == 0)

  # zone tbl suffix _v7 -> _v7b (dev/build_v7.R:55-61)
  for (old_tbl in dbGetQuery(con, glue(
      "SELECT DISTINCT tbl FROM zone WHERE tbl LIKE '%\\_{ver_prev}' ESCAPE '\\'"))$tbl) {
    new_tbl <- str_replace(old_tbl, glue("_{ver_prev}$"), glue("_{ver}"))
    dbExecute(con, glue("UPDATE zone       SET tbl = '{new_tbl}'      WHERE tbl = '{old_tbl}'"))
    dbExecute(con, glue("UPDATE zone_taxon SET zone_tbl = '{new_tbl}' WHERE zone_tbl = '{old_tbl}'"))
    log_info("renamed zone tbl: {old_tbl} -> {new_tbl}")
  }

  n_turtle <- rewrite_turtles(con, suit_min, fill)

  # v7's scoring chunks need these names; a child of globalenv() keeps the chunk code's own
  # assignments out of the session while still resolving library functions
  env <- new.env(parent = globalenv())
  env$con_sdm <- con
  env$tbl_pra <- glue("ply_programareas_2026_{ver}")
  env$tbl_sr  <- glue("ply_subregions_2026_{ver}")
  env$tbl_er  <- "ply_ecoregions_2025"
  env$component_pct_pra_csv <- file.path(out_dir, glue("tbl_component_pct_programarea_{ver}.csv"))
  env$zone_taxon_csv        <- file.path(out_dir, glue("zone_taxon_{ver}.csv"))
  # NEVER narrow sp_cats: the pct-area and composite chunks enumerate every component from it
  env$sp_cats <- dbGetQuery(con,
    "SELECT DISTINCT sp_cat FROM taxon WHERE is_ok ORDER BY sp_cat")$sp_cat
  stopifnot("sp_cats lost a category" = length(env$sp_cats) == 7)

  run <- function(labels)
    for (lbl in labels) {
      log_info("[{label}] chunk: {lbl}")
      eval(parse(text = chunk_fix(get_chunk(lbl))), envir = env)
    }

  run(CHUNKS_PRE)
  d_cov <- apply_kappa(
    con, env$tbl_pra,
    c(glue("extrisk_{env$sp_cats}_ecoregion_rescaled"), "primprod_ecoregion_rescaled"),
    kappa, file.path(out_dir, glue("tbl_component_not_reportable_programarea_{ver}.csv")))
  run(CHUNKS_POST)

  write_release_method(con, suit_min, fill, kappa)

  log_info("[{label}] built in {round(as.numeric(difftime(Sys.time(), t0, units = 'mins')), 1)} min")
  invisible(list(n_turtle = n_turtle, coverage = d_cov))
}

6 Comparing a build against v7

One function, used for v7b and for each control. It compares the three surfaces that carry the release — cell_metric (~22.0 M rows), zone_metric and zone_taxon — by key, exactly, and reports the largest value movement per metric.

A note on “exactly”. model_cell.value is INTEGER, so the six turtle models are compared bit-for-bit and the only admissible answer is 0 diffs. The scored surfaces are DOUBLE and every zone value is a SUM() over up to 662,075 cells: IEEE addition is not associative, and DuckDB’s parallel aggregate does not fix the reduction order, so re-running v7’s own SQL on v7’s own data reproduces zone_metric to about 5 ULP (measured: max 8.9e-15 on values near 10) rather than bit-identically. The gate is therefore exact on keys (no row gained, none lost, none renamed) and bounded on values at 1e-9 relative — four orders of magnitude tighter than the smallest change either method makes, and six orders looser than reassociation noise. n_moved below counts values outside that bound; it is the number the gates assert.

Code 
# rel difference guard: |a-b| / max(|b|, 1) -- absolute for small values, relative for large
REL_TOL <- 1e-9

compare_build <- function(db_path) {
  cc <- dbConnect(duckdb(dbdir = db_path, read_only = TRUE))
  on.exit(dbDisconnect(cc, shutdown = TRUE), add = TRUE)
  dbExecute(cc, "PRAGMA memory_limit='12GB'"); dbExecute(cc, "PRAGMA threads=6")
  dbExecute(cc, glue("PRAGMA temp_directory='{path_dir(db_path)}/duckdb_tmp'"))
  # ATTACH is per DATABASE INSTANCE, not per connection: comparing the release this notebook
  # already holds open would otherwise fail with `database with name "prev" already exists`.
  if (!nrow(dbGetQuery(cc, "SELECT 1 FROM duckdb_databases() WHERE database_name = 'prev'")))
    dbExecute(cc, glue("ATTACH '{sdm_db_prev}' AS prev (READ_ONLY)"))
  ms <- paste(MDL_TURTLE, collapse = ", ")

  turtle <- dbGetQuery(cc, glue(
    "SELECT
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms})
          EXCEPT ALL SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS new_not_prev,
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms})
          EXCEPT ALL SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms}))) AS prev_not_new,
       (SELECT count(*) FROM model_cell      WHERE mdl_seq IN ({ms})) AS n_new,
       (SELECT count(*) FROM prev.model_cell WHERE mdl_seq IN ({ms})) AS n_prev,
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id FROM model_cell WHERE mdl_seq IN ({ms})
          EXCEPT SELECT mdl_seq, cell_id FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS n_gained"))

  cell <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM cell_metric cm JOIN metric m USING (metric_seq)),
          b AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM prev.cell_metric cm JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.k = b.k AND a.cid = b.cid)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  zone <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)),
          b AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM prev.zone_metric zm JOIN prev.zone z USING (zone_seq)
                JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.k = b.k)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  # zone_taxon: key = (zone_fld, zone_value, mdl_seq); zone_tbl differs by the _v7b rename
  ztx <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM zone_taxon),
          b AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM prev.zone_taxon),
          j AS (SELECT coalesce(a.sp_cat, b.sp_cat) AS sp_cat,
                       a.area_km2 aa, b.area_km2 ba, a.avg_suit sa, b.avg_suit sb,
                       a.suit_rl ra, b.suit_rl rb, a.pct_cat pa, b.pct_cat pb,
                       a.f AS af, b.f AS bf
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.mdl_seq = b.mdl_seq)
     -- named `metric_key` so moved_keys() reads the real column: it looked for metric_key,
     -- found nothing on a frame keyed by sp_cat, and the zone_taxon gate passed vacuously
     SELECT sp_cat AS metric_key,
            count(*) FILTER (WHERE bf IS NULL) AS n_only_new,
            count(*) FILTER (WHERE af IS NULL) AS n_only_prev,
            coalesce(greatest(
              max(abs(aa - ba) / greatest(abs(ba), 1.0)),
              max(abs(sa - sb) / greatest(abs(sb), 1.0)),
              max(abs(ra - rb) / greatest(abs(rb), 1.0)),
              max(abs(pa - pb) / greatest(abs(pb), 1.0))), 0) AS max_rel,
            count(*) FILTER (WHERE
              greatest(abs(aa - ba) / greatest(abs(ba), 1.0),
                       abs(sa - sb) / greatest(abs(sb), 1.0),
                       abs(ra - rb) / greatest(abs(rb), 1.0),
                       abs(pa - pb) / greatest(abs(pb), 1.0)) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  pra <- dbGetQuery(cc, glue(
    "SELECT z.value AS programarea_key, m.metric_key, zm.value
     FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)
     WHERE z.fld = 'programarea_key'"))

  list(turtle = turtle, cell = cell, zone = zone, ztx = ztx, pra = pra)
}

# the invariant that must hold in EVERY run, whatever the flags: decision 4 keeps the
# productivity fix with v10. `{key}_coverage` is a NEW zone-only key, not a primprod row --
# it says how much of the zone the component covers and never touches primprod's values.
moved_keys <- function(d) {
  # a check that reads a column that is not there returns character(0) and passes forever
  stopifnot("comparison frame has no metric_key column" = "metric_key" %in% names(d))
  sort(d$metric_key[d$n_moved > 0 | d$n_only_new > 0 | d$n_only_prev > 0])
}
primprod_ok <- function(cmp) {
  k <- c(moved_keys(cmp$cell), moved_keys(cmp$zone))
  !any(grepl("^primprod", k) & !grepl("_coverage$", k))
}

9.7 Sensitivity: other thresholds, and Tim’s percentile rules

v7’s chain, emulated over the turtle component alone: rebuild the six merged surfaces, sum them per cell (extrisk_turtle, since er_score = 100 for a spatial-ER taxon), rescale on the ecoregional min/max, take the pct_covered-weighted Program-Area mean, multiply by pct_area. Run against v7’s own surface it reproduces the published turtle column, which is what licenses the variants.

The percentile rows threshold the merged surface as Tim ran it (area-weighted percentile per species), not the suitability before the merge — which is why they remove nothing for the five species whose merged area is mostly floor-of-1 fill.

# reads v7 through the `prev` attachment of the connection this notebook already holds: a
# second DuckDB instance on the same file would only invite the lock and alias trouble, and
# every input here (taxon_model, the raw model cells, zone_cell) is v7's, unchanged by v7.1.
emulate_turtle_pa <- function(cc, surface_sql) {
  dbExecute(cc, glue("CREATE OR REPLACE TEMP TABLE e_surf AS {surface_sql}"))
  dbGetQuery(cc, glue(
    "WITH er AS (SELECT cell_id, sum(val) AS v FROM e_surf GROUP BY 1),
          eco AS (SELECT zc.cell_id, zc.zone_seq, zc.pct_covered
                  FROM prev.zone_cell zc JOIN prev.zone z USING (zone_seq)
                  WHERE z.fld = 'ecoregion_key'),
          tot AS (SELECT cell_id, sum(pct_covered) AS t FROM eco GROUP BY 1),
          ecn AS (SELECT e.cell_id, e.zone_seq,
                         CASE WHEN count(*) OVER (PARTITION BY e.cell_id) = 1 THEN 100
                              ELSE e.pct_covered * 100.0 / t.t END AS npct
                  FROM eco e JOIN tot t USING (cell_id)),
          mm AS (SELECT ecn.zone_seq, min(er.v) AS lo, max(er.v) AS hi
                 FROM ecn JOIN er USING (cell_id) GROUP BY 1),
          rs AS (SELECT er.cell_id,
                        sum((er.v - mm.lo) / (mm.hi - mm.lo) * ecn.npct / 100.0) * 100 AS v
                 FROM er JOIN ecn USING (cell_id) JOIN mm ON mm.zone_seq = ecn.zone_seq
                 WHERE mm.hi > mm.lo GROUP BY 1),
          pz AS (SELECT zone_seq, value AS pa FROM prev.zone WHERE fld = 'programarea_key'),
          agg AS (SELECT pz.pa,
                    sum(rs.v * zc.pct_covered) / sum(zc.pct_covered) AS mean_v,
                    sum(zc.pct_covered) AS cov
                  FROM pz JOIN prev.zone_cell zc USING (zone_seq) JOIN rs USING (cell_id) GROUP BY 1),
          den AS (SELECT pz.pa, sum(zc.pct_covered) AS tot
                  FROM pz JOIN prev.zone_cell zc USING (zone_seq) GROUP BY 1)
     SELECT agg.pa AS programarea_key,
            round(agg.mean_v * agg.cov / den.tot, 1) AS value,
            round(agg.cov / den.tot * 100)           AS pct_covered
     FROM agg JOIN den USING (pa) ORDER BY 1"))
}

10 Manifest

Digests of the surfaces P4 must reproduce on the server: the six turtle models, cell_metric, zone_metric and zone_taxon. msens::hash_query() is an order-independent reduction (count + bit_xor + sum), so it does not care how DuckDB partitioned the scan.

It DOES care about the last bit of a DOUBLE, and Section 6 measured that the zone sums are not bit-reproducible (parallel SUM() reassociates; ~5 ULP). A digest of the raw doubles would therefore differ between two correct builds, and the server-equals-laptop gate would be red for no reason. So the INTEGER turtle models are digested as they are (exact), and every DOUBLE is digested as CAST(... AS FLOAT): ~7 significant digits at every magnitude (area_km2 runs to 1e6, a score to 100), nine orders coarser than the noise and far finer than anything either rule moves.

The committed manifest is the reference. A build with the same flags on any machine must reproduce its digests, and this chunk stops if it does not – that is P4’s “server build equals the laptop’s” gate, run by the render itself rather than by eye. BUILD_REFERENCE=1 is the only way to move the reference, and says so in the log.

v7.1 is a **surgical patch of the public v7 release** — same `usa05` grid, same `mdl_seq`/`value`
schema, same 20 Program Areas — built the way v7 itself was built: clone the previous DuckDB, change
only what the fix touches, then re-execute v7's own scoring chunks verbatim. Two method changes,
nothing else:

1. **Sea-turtle core habitat.** AquaMaps suitability enters the turtle merge only where P ≥ 0.5
   (AquaMaps' own core-habitat default), and a range cell with no retained suitability is
   **dropped** — the floor-of-1 fill goes. A threshold alone removes none of that fill: for five of
   the six turtles half to nine tenths of the merged US area *is* fill, with no AquaMaps value at
   all. Critical habitat still overrides by `max`, so no designated cell is ever trimmed.
2. **Coverage floor κ = 5 %.** A component is reportable in a Program Area only if its scored cells
   cover ≥ 5 % of the area. Below that it is *not reportable* — no row, excluded from the composite
   exactly as a component with no cells is, never published as a zero.

Both are flags whose **control value is off**, so the same code path reproduces v7 exactly. That is
the first gate below, and it is what makes every other number here attributable.

Not in v7.1: the year-integrated productivity, the distribution-share / national score, occurrence
masks, per-taxon thresholds, any change to Formula 9.4. All of that is v10. **Every `primprod*` row
of v7b must equal v7's**, and a gate asserts it in every run.

```{r}
# copy-on-write clone: APFS `cp -c` on the laptop, `cp --reflink=auto` on Linux. A 3.6 GB
# release database clones in milliseconds and only the pages the patch rewrites cost space.
clone_db <- function(src, dst) {
  if (file_exists(dst))               file_delete(dst)
  if (file_exists(glue("{dst}.wal"))) file_delete(glue("{dst}.wal"))
  dir_create(path_dir(dst))
  flag <- if (is_server) "--reflink=auto" else "-c"
  rc   <- system2("cp", c(flag, shQuote(src), shQuote(dst)))
  stopifnot("copy-on-write clone failed" = identical(as.integer(rc), 0L))
  log_info("cloned {src} -> {dst}")
}

# the turtle rewrite: same rule, same ids. Re-merging through the old loop would RENUMBER
# mdl_seq and break every published ?mdl_seq= deep link, so rows are replaced under the
# existing merged ids.
rewrite_turtles <- function(con, suit_min, fill) {
  seqs <- dbGetQuery(con, "SELECT mdl_seq FROM taxon WHERE sp_cat = 'turtle' ORDER BY mdl_seq")$mdl_seq
  stopifnot("expected v7's six merged turtle models at 54238-54243" =
    identical(as.integer(seqs), 54238:54243))
  seq_sql <- paste(seqs, collapse = ", ")

  dbExecute(con, "CREATE OR REPLACE TEMP VIEW turtle_src AS
    SELECT t.mdl_seq AS ms_merge_key, tm.ds_key, mc.cell_id, mc.value AS val
    FROM taxon t
    JOIN taxon_model tm ON tm.taxon_id = t.taxon_id AND tm.ds_key <> 'ms_merge'
    JOIN model_cell  mc ON mc.mdl_seq  = tm.mdl_seq
    WHERE t.sp_cat = 'turtle'")

  # half_even = TRUE reproduces R's rounding, which is what built v1-v7 (DuckDB round()
  # differs on 28,598 v7 cells where ER = 50); ch_outer = TRUE keeps the 31 CH cells that
  # lie outside the ER footprint, as v7's union did.
  sql <- msens::turtle_sql(
    DS_ER, DS_SUIT, DS_CH, src = "turtle_src",
    suit_min = suit_min, fill = fill, half_even = TRUE, ch_outer = TRUE)
  # materialize BEFORE the delete: turtle_src reads model_cell, which is about to change
  dbExecute(con, glue("CREATE OR REPLACE TEMP TABLE turtle_new AS {sql}"))

  dbExecute(con, glue("DELETE FROM model_cell WHERE mdl_seq IN ({seq_sql})"))
  n <- dbExecute(con, glue(

     SELECT mdl_key::INTEGER, cell_id, val::INTEGER FROM turtle_new"))

  rule <- glue(

    "fill={if (is.na(fill)) 'none' else fill}, half_even=TRUE, ch_outer=TRUE")
  # idempotent: strip any previous v7.1 clause before appending, so a re-run does not stack
  dbExecute(con, glue(
    "UPDATE model SET description =
       regexp_replace(coalesce(description, ''), ' \\| v7\\.1 turtle.*$', '') || ' | {rule}'
     WHERE mdl_seq IN ({seq_sql})"))
  log_info("turtles rewritten: {format(n, big.mark = ',')} cells under mdl_seq {seq_sql}")
  n
}

# kappa: a ZONE reporting rule. Cell-level rasters are untouched; only the Program-Area
# component row of a pair below the floor is deleted (its raw and _prepctareaweighting rows
# stay, so the diagnostic remains readable), and the composite then averages one fewer
# component -- exactly as it already does for an area with no turtles at all.
apply_kappa <- function(con, tbl_pra, component_keys, kappa, f_csv) {
  if (is.na(kappa) || kappa <= 0) {
    log_info("COVERAGE_FLOOR off -- no _coverage metrics written, no component dropped")
    return(invisible(NULL))
  }
  d <- dbGetQuery(con, msens::coverage_sql(
        tbl_pra, component_keys, weight = "pct_covered",
        val_col = msens::sdm_val_col(con, "cell_metric"))) |>
    msens::coverage_floor(kappa = kappa)

  z_seqs <- dbGetQuery(con, glue(
    "SELECT zone_seq FROM zone WHERE tbl = '{tbl_pra}'"))$zone_seq
  z_sql  <- paste(z_seqs, collapse = ", ")

  for (k in component_keys) {
    k_cov <- glue("{k}_coverage")
    if (!nrow(dbGetQuery(con, glue("SELECT 1 FROM metric WHERE metric_key = '{k_cov}'"))))
      dbExecute(con, glue(
        "INSERT INTO metric (metric_key, description) VALUES
         ('{k_cov}', 'Percent of the zone covered by cells carrying {k} (coverage floor input)')"))
    s_cov <- dbGetQuery(con, glue(
      "SELECT metric_seq FROM metric WHERE metric_key = '{k_cov}'"))$metric_seq
    dbExecute(con, glue(
      "DELETE FROM zone_metric WHERE metric_seq = {s_cov} AND zone_seq IN ({z_sql})"))
    dd <- d |> filter(metric_key == k)
    if (nrow(dd))
      dbExecute(con, glue(
        "INSERT INTO zone_metric (zone_seq, metric_seq, value) VALUES {vals}",
        vals = paste(glue("({dd$zone_seq}, {s_cov}, {dd$coverage * 100})"), collapse = ", ")))
  }

  d_drop <- d |> filter(!reportable)
  for (i in seq_len(nrow(d_drop)))
    dbExecute(con, glue(
      "DELETE FROM zone_metric
       WHERE zone_seq = {d_drop$zone_seq[i]}
         AND metric_seq = (SELECT metric_seq FROM metric WHERE metric_key = '{d_drop$metric_key[i]}')"))

  d_out <- d |>
    left_join(dbGetQuery(con, glue(
      "SELECT zone_seq, value AS programarea_key FROM zone WHERE tbl = '{tbl_pra}'")),
      by = "zone_seq") |>
    arrange(coverage) |>
    select(programarea_key, metric_key, coverage, reportable)
  write_csv(d_out |> filter(!reportable), f_csv)
  log_info("kappa={kappa}: {nrow(d_drop)} of {nrow(d)} (zone x component) pairs not reportable")
  invisible(d_out)
}
```

```{r}
    log_info("renamed zone tbl: {old_tbl} -> {new_tbl}")

  # assignments out of the session while still resolving library functions

  env$con_sdm <- con
  env$tbl_pra <- glue("ply_programareas_2026_{ver}")
  env$tbl_sr  <- glue("ply_subregions_2026_{ver}")
  env$tbl_er  <- "ply_ecoregions_2025"
  env$component_pct_pra_csv <- file.path(out_dir, glue("tbl_component_pct_programarea_{ver}.csv"))
  env$zone_taxon_csv        <- file.path(out_dir, glue("zone_taxon_{ver}.csv"))
  # NEVER narrow sp_cats: the pct-area and composite chunks enumerate every component from it

    "SELECT DISTINCT sp_cat FROM taxon WHERE is_ok ORDER BY sp_cat")$sp_cat
  stopifnot("sp_cats lost a category" = length(env$sp_cats) == 7)

  run <- function(labels)
    for (lbl in labels) {
      log_info("[{label}] chunk: {lbl}")
      eval(parse(text = chunk_fix(get_chunk(lbl))), envir = env)
    }

    con, env$tbl_pra,
```

## Comparing a build against v7 {#sec-compare}

One function, used for `v7b` and for each control. It compares the three surfaces that carry the
release — `cell_metric` (~22.0 M rows), `zone_metric` and `zone_taxon` — **by key, exactly**, and
reports the largest value movement per metric.

A note on "exactly". `model_cell.value` is INTEGER, so the six turtle models are compared
bit-for-bit and the only admissible answer is 0 diffs. The scored surfaces are DOUBLE and every
zone value is a `SUM()` over up to 662,075 cells: IEEE addition is not associative, and DuckDB's
parallel aggregate does not fix the reduction order, so re-running v7's own SQL on v7's own data
reproduces `zone_metric` to about 5 ULP (measured: max 8.9e-15 on values near 10) rather than
bit-identically. The gate is therefore **exact on keys** (no row gained, none lost, none renamed)
and **bounded on values at 1e-9 relative** — four orders of magnitude tighter than the smallest
change either method makes, and six orders looser than reassociation noise. `n_moved` below counts
values outside that bound; it is the number the gates assert.

```{r}
#| label: compare_fn

# rel difference guard: |a-b| / max(|b|, 1) -- absolute for small values, relative for large
REL_TOL <- 1e-9

compare_build <- function(db_path) {
  cc <- dbConnect(duckdb(dbdir = db_path, read_only = TRUE))
  on.exit(dbDisconnect(cc, shutdown = TRUE), add = TRUE)
  dbExecute(cc, "PRAGMA memory_limit='12GB'"); dbExecute(cc, "PRAGMA threads=6")
  dbExecute(cc, glue("PRAGMA temp_directory='{path_dir(db_path)}/duckdb_tmp'"))
  # ATTACH is per DATABASE INSTANCE, not per connection: comparing the release this notebook
  # already holds open would otherwise fail with `database with name "prev" already exists`.
  if (!nrow(dbGetQuery(cc, "SELECT 1 FROM duckdb_databases() WHERE database_name = 'prev'")))
    dbExecute(cc, glue("ATTACH '{sdm_db_prev}' AS prev (READ_ONLY)"))
  ms <- paste(MDL_TURTLE, collapse = ", ")

  turtle <- dbGetQuery(cc, glue(
    "SELECT
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms})
          EXCEPT ALL SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS new_not_prev,
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms})
          EXCEPT ALL SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms}))) AS prev_not_new,
       (SELECT count(*) FROM model_cell      WHERE mdl_seq IN ({ms})) AS n_new,
       (SELECT count(*) FROM prev.model_cell WHERE mdl_seq IN ({ms})) AS n_prev,
       (SELECT count(*) FROM (SELECT mdl_seq, cell_id FROM model_cell WHERE mdl_seq IN ({ms})
          EXCEPT SELECT mdl_seq, cell_id FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS n_gained"))

  cell <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM cell_metric cm JOIN metric m USING (metric_seq)),
          b AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM prev.cell_metric cm JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.k = b.k AND a.cid = b.cid)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  zone <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)),
          b AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM prev.zone_metric zm JOIN prev.zone z USING (zone_seq)
                JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.k = b.k)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  # zone_taxon: key = (zone_fld, zone_value, mdl_seq); zone_tbl differs by the _v7b rename
  ztx <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM zone_taxon),
          b AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM prev.zone_taxon),
          j AS (SELECT coalesce(a.sp_cat, b.sp_cat) AS sp_cat,
                       a.area_km2 aa, b.area_km2 ba, a.avg_suit sa, b.avg_suit sb,
                       a.suit_rl ra, b.suit_rl rb, a.pct_cat pa, b.pct_cat pb,
                       a.f AS af, b.f AS bf
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.mdl_seq = b.mdl_seq)
     -- named `metric_key` so moved_keys() reads the real column: it looked for metric_key,
     -- found nothing on a frame keyed by sp_cat, and the zone_taxon gate passed vacuously
     SELECT sp_cat AS metric_key,
            count(*) FILTER (WHERE bf IS NULL) AS n_only_new,
            count(*) FILTER (WHERE af IS NULL) AS n_only_prev,
            coalesce(greatest(
              max(abs(aa - ba) / greatest(abs(ba), 1.0)),
              max(abs(sa - sb) / greatest(abs(sb), 1.0)),
              max(abs(ra - rb) / greatest(abs(rb), 1.0)),
              max(abs(pa - pb) / greatest(abs(pb), 1.0))), 0) AS max_rel,
            count(*) FILTER (WHERE
              greatest(abs(aa - ba) / greatest(abs(ba), 1.0),
                       abs(sa - sb) / greatest(abs(sb), 1.0),
                       abs(ra - rb) / greatest(abs(rb), 1.0),
                       abs(pa - pb) / greatest(abs(pb), 1.0)) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  pra <- dbGetQuery(cc, glue(
    "SELECT z.value AS programarea_key, m.metric_key, zm.value
     FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)
     WHERE z.fld = 'programarea_key'"))

  list(turtle = turtle, cell = cell, zone = zone, ztx = ztx, pra = pra)
}

# the invariant that must hold in EVERY run, whatever the flags: decision 4 keeps the
# productivity fix with v10. `{key}_coverage` is a NEW zone-only key, not a primprod row --
# it says how much of the zone the component covers and never touches primprod's values.
moved_keys <- function(d) {
  # a check that reads a column that is not there returns character(0) and passes forever
  stopifnot("comparison frame has no metric_key column" = "metric_key" %in% names(d))
  sort(d$metric_key[d$n_moved > 0 | d$n_only_new > 0 | d$n_only_prev > 0])
}
primprod_ok <- function(cmp) {
  k <- c(moved_keys(cmp$cell), moved_keys(cmp$zone))
  !any(grepl("^primprod", k) & !grepl("_coverage$", k))
}
```

## Control runs {#sec-controls}

Three clones in a scratch directory, each through `build_release()` with a different flag set, then
deleted. The point of the all-off run is that it is the *same code path* as `v7b`: if it reproduces

### Sensitivity: other thresholds, and Tim's percentile rules {#sec-sensitivity}

v7's chain, emulated over the turtle component alone: rebuild the six merged surfaces, sum them per
cell (`extrisk_turtle`, since `er_score = 100` for a spatial-ER taxon), rescale on the ecoregional
min/max, take the `pct_covered`-weighted Program-Area mean, multiply by `pct_area`. Run against
v7's own surface it reproduces the published turtle column, which is what licenses the variants.

The percentile rows threshold the **merged** surface as Tim ran it (area-weighted percentile per
species), not the suitability before the merge — which is why they remove nothing for the five
species whose merged area is mostly floor-of-1 fill.

```{r}
#| label: emulate

# reads v7 through the `prev` attachment of the connection this notebook already holds: a
# second DuckDB instance on the same file would only invite the lock and alias trouble, and
# every input here (taxon_model, the raw model cells, zone_cell) is v7's, unchanged by v7.1.
emulate_turtle_pa <- function(cc, surface_sql) {
  dbExecute(cc, glue("CREATE OR REPLACE TEMP TABLE e_surf AS {surface_sql}"))
  dbGetQuery(cc, glue(
    "WITH er AS (SELECT cell_id, sum(val) AS v FROM e_surf GROUP BY 1),
          eco AS (SELECT zc.cell_id, zc.zone_seq, zc.pct_covered
                  FROM prev.zone_cell zc JOIN prev.zone z USING (zone_seq)
                  WHERE z.fld = 'ecoregion_key'),
          tot AS (SELECT cell_id, sum(pct_covered) AS t FROM eco GROUP BY 1),
          ecn AS (SELECT e.cell_id, e.zone_seq,
                         CASE WHEN count(*) OVER (PARTITION BY e.cell_id) = 1 THEN 100
                              ELSE e.pct_covered * 100.0 / t.t END AS npct
                  FROM eco e JOIN tot t USING (cell_id)),
          mm AS (SELECT ecn.zone_seq, min(er.v) AS lo, max(er.v) AS hi
                 FROM ecn JOIN er USING (cell_id) GROUP BY 1),
          rs AS (SELECT er.cell_id,
                        sum((er.v - mm.lo) / (mm.hi - mm.lo) * ecn.npct / 100.0) * 100 AS v
                 FROM er JOIN ecn USING (cell_id) JOIN mm ON mm.zone_seq = ecn.zone_seq
                 WHERE mm.hi > mm.lo GROUP BY 1),
          pz AS (SELECT zone_seq, value AS pa FROM prev.zone WHERE fld = 'programarea_key'),
          agg AS (SELECT pz.pa,
                    sum(rs.v * zc.pct_covered) / sum(zc.pct_covered) AS mean_v,
                    sum(zc.pct_covered) AS cov
                  FROM pz JOIN prev.zone_cell zc USING (zone_seq) JOIN rs USING (cell_id) GROUP BY 1),
          den AS (SELECT pz.pa, sum(zc.pct_covered) AS tot
                  FROM pz JOIN prev.zone_cell zc USING (zone_seq) GROUP BY 1)
     SELECT agg.pa AS programarea_key,
            round(agg.mean_v * agg.cov / den.tot, 1) AS value,
            round(agg.cov / den.tot * 100)           AS pct_covered
     FROM agg JOIN den USING (pa) ORDER BY 1"))
}
```

## Manifest

Digests of the surfaces P4 must reproduce on the server: the six turtle models, `cell_metric`,
`zone_metric` and `zone_taxon`. `msens::hash_query()` is an order-independent reduction
(`count + bit_xor + sum`), so it does not care how DuckDB partitioned the scan.

It DOES care about the last bit of a DOUBLE, and @sec-compare measured that the zone sums are
not bit-reproducible (parallel `SUM()` reassociates; ~5 ULP). A digest of the raw doubles would
therefore differ between two correct builds, and the server-equals-laptop gate would be red for
no reason. So the INTEGER turtle models are digested as they are (exact), and every DOUBLE is
digested as `CAST(... AS FLOAT)`: ~7 significant digits at every magnitude (`area_km2` runs to
1e6, a score to 100), nine orders coarser than the noise and far finer than anything either
rule moves.

**The committed manifest is the reference.** A build with the same flags on any machine must
reproduce its digests, and this chunk stops if it does not -- that is P4's "server build equals
the laptop's" gate, run by the render itself rather than by eye. `BUILD_REFERENCE=1` is the
only way to move the reference, and says so in the log.
