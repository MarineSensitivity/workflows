Becker et al. 2020: 13 species, summer–fall habitat-based density on 0.1° cells, area-weighted onto the global 0.05° grid → population-percentile suitability [1,100]

Published

2026-10-29

NOAA Southwest Fisheries Science Center (SWFSC) habitat-based density models for 13 cetacean species in the California Current Ecosystem (CCE), summer–fall (Becker et al. 2020), put on the MarineSensitivity global 0.05° cell grid (global05) as dataset cce, and mapped onto the merge’s [1,100] suitability scale by the population-percentile transform (msens::density_to_suit(method = "ud"), v11 Q6 / D12), the same recipe as the gm and nc density ingests.

cce is registered but not merged by default: like gm and nc, its annual models enter the merge only under FOLD_DENSITY=1 (the interval models are published for the species app and never max()ed into a year), and merge_models_prep excludes the dataset otherwise.

1 Source

The models come from line-transect ship surveys by SWFSC in the CCE, nine summer–fall surveys between 1991 and 2018. Habitat-based density models were fitted to those surveys using dynamic ocean covariates from a model calibrated to the CCE. The authors averaged the predictions over the survey seasons and assigned them to a 0.1° grid, clipped at the coast and the study-area edge. The delivery is an Esri file geodatabase with one layer per species, holding 12,257 cells each. Every cell carries DENSITY (animals km⁻²), UNCERTAINTY, AREA_SQKM and ABUNDANCE (DENSITY × AREA_SQKM). The geodatabase lives at ~/_big/msens/raw/sdm/swfsc/ (cce_gdb in libs/paths.R; CCE_GDB overrides it).

Two points from the InPort metadata (item 64349 and its attribute entity 64350) matter here:

  • UNCERTAINTY is a coefficient of variation. The attribute definition (quoted in Credits and use constraints) calls it “Numerical uncertainty value (CV)”, with -99999 where no estimate exists. No layer here uses that sentinel. The values run from 0.12 to 6.4, and a CV above 1 is legitimate for a sparse species.
  • AREA_SQKM is the true ellipsoidal area of each clipped cell. The source chunk shows that it matches sf::st_area() on WGS84 to within 0.1 %. Because the 0.05° cell areas below are also ellipsoidal, the abundance check can be held to 1 %.

The record’s abstract also lists sperm whale and a small-beaked-whale guild (Mesoplodon spp. and Cuvier’s beaked whale). Those surfaces are not in this geodatabase, which holds 13 layers.

2 What this notebook does

  1. Reads the 13 layers and asserts what it relies on: 12,257 cells per layer, identical geometry across layers, one species and one season per layer, and ABUNDANCE = DENSITY × AREA_SQKM.
  2. Resolves each SPECIES_2 to a WoRMS AphiaID from the pipeline’s own WoRMS snapshot (spp.duckdb worms), with a live worrms cross-check when the network is available.
  3. Area-weighted regrid. For each 0.05° cell c: \(\hat d_c = \sum_p d_p\,A(p \cap c) \,/\, \sum_p A(p \cap c)\). Here \(A\) is the exact overlap area in km², computed as the exactextractr coverage fraction times the cell’s WGS84 ellipsoidal area, which depends on latitude. The same weighting gives the CV and the covered fraction of each cell. The rule lives in msens (poly_cell_overlap(), cells_area_mean()), and test-ingest.R checks it against a synthetic fixture. The polygon-cell weights are computed once, because all 13 layers share the same geometry.
  4. Checks every species: the regridded abundance \(\sum_c \hat d_c \cdot \text{covered km}^2\) is within 1 % of \(\sum\) ABUNDANCE, no output cell lies outside the source extent, and every density is ≥ 0.
  5. Value transform (v11 Q6, D12). Per model, after regridding, val = density_to_suit(d, "ud", area = cell area_km2): 100 minus the percent of the modelled population in cells strictly denser than this one, so the densest cell is 100 and the cells with val >= 100 - p are exactly the p % core. Cells with val < 1 are dropped (the merge’s floor). The transform is scale-free. The old recipe (CCE_TRANSFORM=cap: linear to the species’ p99.5 of positive density) stays available and is compared per model in data/cce_transform_compare.csv.
  6. Interval and annual models. CCE models one interval, summer-fall, so the annual model is that interval: msens::density_annual(n_intervals = 1) is the identity on the density (asserted), and the annual surface is the same ud transform of the same cells. Both keys are written (cce|WORMS:{id}|summer-fall for the species app, cce|WORMS:{id} for the merge) so cce has the same two-part / three-part key shape as gm and nc. They describe summer–fall conditions only; the annual name does not mean the model says anything about winter–spring.
  7. Writes the long Parquet (mdl_key, cell_id, val, plus dens, cv, frac) to the version’s dist/dataset=cce/, model_cce.csv beside it, and the manifest. CCE_COG=1 also writes one 2-band Float32 COG per species (density, CV).
NoteThe CV band is an approximation

An area-weighted mean is right for a density, which is intensive: the regridded abundance equals the source abundance. It is not right for a CV, because the CVs of the parts of a cell do not average linearly. The CV of a mixed cell’s density would need the covariance between its parts, which the delivery does not carry. The cv column is therefore an area-weighted average of the source CVs. It is exact only where an output cell lies inside a single source cell, and the regrid section counts how many cells do.

4 Cell areas

The cell table is a property of the grid, not of the release: this version’s sdm.duckdb is used when build_cell_grid has written it, else ver_prev’s (which build_cell_grid copies unchanged). It is opened read-only.

6 Taxa → WoRMS

Each delivered name (SPECIES_2) is matched exactly against the pipeline’s WoRMS snapshot. Where a name has several WoRMS records (homonyms and synonym records), the rule picks one in this order:

  1. the record that is itself accepted;
  2. otherwise, a synonym whose accepted taxon is accepted and in the same genus;
  3. otherwise, a synonym whose accepted taxon is accepted.

The render stops if more than one record ties at the top, or if any accepted target is not itself accepted.

9 Value transform: density → population percentile

Per species, on the regridded cells, after the checks above. val is msens::density_to_suit(density, "ud", area = cell area_km2): 100 minus the percent of the modelled population (density × the cell table’s area_km2) held by cells strictly denser than this one. The densest cell is 100 and val >= 100 - p is exactly the p % core of the population, whatever the units or the skew of the model. Cells below val 1 are the tail holding the last percent of the population and are not written (the merge’s floor).

The annual surface is msens::density_annual(n_intervals = 1) of the one interval: the identity on the density, asserted below, so the annual model has exactly the interval model’s cells and val. The two keys exist so cce has the same key shape as gm and nc; the merge reads only the annual one.

10 Write COGs (CCE_COG=1)

Off by default. With CCE_COG=1 each species gets one COG, cce_cog/cce_<worms_id>_summer-fall.tif beside dist/: the delivered density, not val. Band 1 is density (animals km⁻²) and band 2 is cv. Both are Float32 with nodata −9999 outside the modelled cells, DEFLATE-compressed with the floating-point predictor, and in 256 × 256 blocks. There are no internal overviews, because titiler decimates from full resolution. The window is cut from the cell-id raster by row and column, so its origin and pixel size are the grid’s own, including the ~5 × 10⁻⁶° float drift. Each output pixel is a global05 cell.

NOAA Southwest Fisheries Science Center (SWFSC) habitat-based **density** models for 13 cetacean
species in the California Current Ecosystem (CCE), summer–fall [@becker2020cce], put on the
MarineSensitivity **global 0.05° cell grid** (`global05`) as dataset `cce`, and mapped onto the
merge's **[1,100]** suitability scale by the **population-percentile** transform
(`msens::density_to_suit(method = "ud")`, v11 Q6 / D12), the same recipe as the `gm` and `nc` density
ingests.

`cce` is **registered but not merged** by default: like `gm` and `nc`, its annual models enter the
merge only under `FOLD_DENSITY=1` (the interval models are published for the species app and never
`max()`ed into a year), and `merge_models_prep` excludes the dataset otherwise.

## Source

The models come from line-transect ship surveys by SWFSC in the CCE, nine summer–fall surveys
between 1991 and 2018. Habitat-based density models were fitted to those surveys using dynamic ocean
covariates from a model calibrated to the CCE. The authors averaged the predictions over the survey
seasons and assigned them to a 0.1° grid, clipped at the coast and the study-area edge. The delivery is
an Esri file geodatabase with one layer per species, holding 12,257 cells each. Every cell carries
`DENSITY` (animals km⁻²), `UNCERTAINTY`, `AREA_SQKM` and `ABUNDANCE` (`DENSITY × AREA_SQKM`).
The geodatabase lives at `~/_big/msens/raw/sdm/swfsc/` (`cce_gdb` in `libs/paths.R`; `CCE_GDB`
overrides it).

Two points from the InPort metadata ([item 64349](https://www.fisheries.noaa.gov/inport/item/64349)
and its attribute entity [64350](https://www.fisheries.noaa.gov/inport/item/64350)) matter here:

- **`UNCERTAINTY` is a coefficient of variation.** The attribute definition (quoted in
  [Credits and use constraints](#credits-and-use-constraints)) calls it "Numerical uncertainty value
  (CV)", with `-99999` where no estimate exists. No layer here uses that sentinel. The values run from
  0.12 to 6.4, and a CV above 1 is legitimate for a sparse species.
- **`AREA_SQKM` is the true ellipsoidal area of each clipped cell.** The `source` chunk shows that it
  matches `sf::st_area()` on WGS84 to within 0.1 %. Because the 0.05° cell areas below are also
  ellipsoidal, the abundance check can be held to 1 %.

The record's abstract also lists sperm whale and a small-beaked-whale guild (*Mesoplodon* spp. and
Cuvier's beaked whale). Those surfaces are **not** in this geodatabase, which holds 13 layers.

## What this notebook does

1. Reads the 13 layers and asserts what it relies on: 12,257 cells per layer, identical geometry
   across layers, one species and one season per layer, and `ABUNDANCE = DENSITY × AREA_SQKM`.
2. Resolves each `SPECIES_2` to a WoRMS AphiaID from the pipeline's own WoRMS snapshot
   (`spp.duckdb` `worms`), with a live `worrms` cross-check when the network is available.
3. **Area-weighted regrid.** For each 0.05° cell *c*:
   $\hat d_c = \sum_p d_p\,A(p \cap c) \,/\, \sum_p A(p \cap c)$. Here $A$ is the exact overlap area in
   km², computed as the `exactextractr` coverage fraction times the cell's WGS84 ellipsoidal area,
   which depends on latitude. The same weighting gives the CV and the covered fraction of each cell.
   The rule lives in msens (`poly_cell_overlap()`, `cells_area_mean()`), and `test-ingest.R` checks it
   against a synthetic fixture. The polygon-cell weights are computed **once**, because all 13 layers
   share the same geometry.
4. Checks every species: the regridded abundance $\sum_c \hat d_c \cdot \text{covered km}^2$ is
   within 1 % of $\sum$ `ABUNDANCE`, no output cell lies outside the source extent, and every density
   is ≥ 0.
5. **Value transform (v11 Q6, D12).** Per model, after regridding,
   `val = density_to_suit(d, "ud", area = cell area_km2)`: 100 minus the percent of the modelled
   population in cells strictly denser than this one, so the densest cell is 100 and the cells with
   `val >= 100 - p` are exactly the p % core. Cells with `val < 1` are dropped (the merge's floor).
   The transform is scale-free. The old recipe (`CCE_TRANSFORM=cap`: linear to the species' p99.5 of
   positive density) stays available and is compared per model in `data/cce_transform_compare.csv`.
6. **Interval and annual models.** CCE models one interval, `summer-fall`, so the **annual model is
   that interval**: `msens::density_annual(n_intervals = 1)` is the identity on the density (asserted),
   and the annual surface is the same `ud` transform of the same cells. Both keys are written
   (`cce|WORMS:{id}|summer-fall` for the species app, `cce|WORMS:{id}` for the merge) so `cce` has the
   same two-part / three-part key shape as `gm` and `nc`. They describe summer–fall conditions only;
   the annual name does not mean the model says anything about winter–spring.
7. Writes the long Parquet (`mdl_key`, `cell_id`, `val`, plus `dens`, `cv`, `frac`) to the version's
   `dist/dataset=cce/`, `model_cce.csv` beside it, and the manifest. `CCE_COG=1` also writes one
   2-band Float32 COG per species (density, CV).

::: {.callout-note}
## The CV band is an approximation

An area-weighted mean is right for a density, which is intensive: the regridded abundance equals the
source abundance. It is **not** right for a CV, because the CVs of the parts of a cell do not average
linearly. The CV of a mixed cell's density would need the covariance between its parts, which the
delivery does not carry. The `cv` column is therefore an area-weighted average of the source CVs. It is
exact only where an output cell lies inside a single source cell, and the [regrid section](#regrid)
counts how many cells do.
:::

## Taxa → WoRMS {#taxa}

Each delivered name (`SPECIES_2`) is matched exactly against the pipeline's WoRMS snapshot. Where a
name has several WoRMS records (homonyms and synonym records), the rule picks one in this order:

1. the record that is itself **accepted**;
2. otherwise, a synonym whose accepted taxon is accepted **and in the same genus**;
3. otherwise, a synonym whose accepted taxon is accepted.

The render stops if more than one record ties at the top, or if any accepted target is not itself
accepted.


- ***Delphinus capensis***, the long-beaked common dolphin, is unaccepted in WoRMS and placed under
  *Delphinus delphis*. The InPort abstract itself calls this population *Delphinus delphis bairdii*,
  but WoRMS lists that subspecies as *nomen dubium*, so no accepted WoRMS taxon is specific to the CCE
  long-beaked form.
- ***Lagenorhynchus obliquidens***, the Pacific white-sided dolphin, is a junior objective synonym of
  *Sagmatias obliquidens*.

**Key choice.** `mdl_key` and the file names use the AphiaID of the name **as delivered**

*Delphinus* layers: `r paste(acc_dup$species, collapse = " and ")` share accepted AphiaID
`r unique(acc_dup$worms_id_accepted)`. The accepted id is kept in `worms_id_accepted`. A per-taxon
merge would fold both layers into one *D. delphis* surface, and that is a decision for whoever
promotes this dataset.

## Regrid onto the 0.05° grid {#regrid}

```{r}
#| label: regrid

# exact overlap (km2) of every source cell with every 0.05-degree grid cell, once for all 13 layers
t0 <- Sys.time()
w  <- msens::poly_cell_overlap(geom, cellid_tif)
log_info("poly_cell_overlap: {nrow(w)} (polygon, cell) rows over {n_distinct(w$cell_id)} cells in {round(difftime(Sys.time(), t0, units = 'secs'), 1)} s")

# how much each output cell mixes source cells: share of its covered area from its largest polygon
mixing <- w |>
  group_by(cell_id) |>
  summarise(n_poly = n(), dom = max(area_km2) / sum(area_km2), .groups = "drop")

# per species: area-weighted density and CV (a -99999 CV would be NA, i.e. drop out of the CV only)
cells <- imap(src, \(x, l) msens::cells_area_mean(
  w, tibble(density = x$DENSITY,
            cv      = if_else(x$UNCERTAINTY <= -99999, NA_real_, x$UNCERTAINTY))))
stopifnot("layers must regrid to the same cell set" =
            all(map_lgl(cells, \(d) identical(d$cell_id, cells[[1]]$cell_id))))

n_out    <- nrow(cells[[1]])
n_single <- sum(mixing$dom >= 0.999)
pct      <- \(n) round(100 * n / n_out, 1)
med_dom  <- round(100 * median(mixing$dom[mixing$dom < 0.999]), 1)
kable(tibble(
  output_cells        = n_out,
  partial_cells       = sum(cells[[1]]$frac < 1 - 1e-6),
  frac_min            = signif(min(cells[[1]]$frac), 3),
  in_one_source_cell  = n_single,
  mixed_cells         = n_out - n_single,
  dom_median_mixed    = round(median(mixing$dom[mixing$dom < 0.999]), 4),
  dom_min             = round(min(mixing$dom), 4)),
  format.args = list(big.mark = ","),
  caption = paste(
    "Output cells. partial = covered fraction < 1 (coast, Canada/Mexico and offshore edges);",
    "in_one_source_cell = the largest source cell supplies >= 99.9 % of the covered area;",
    "dom = that share in the mixed cells (median, minimum)"))
```

The source's 0.1° lattice is regular, but its edges sit `r lon_off`° (longitude) and `r lat_off`°
(latitude) off the 0.05° grid lines. That is `r round(100 * abs(lon_off) / 0.05, 1)` % and
`r round(100 * abs(lat_off) / 0.05, 1)` % of a grid cell. So every other output column and every other
output row straddles a source edge. `r pct(n_single)` % of output cells lie inside a single source cell
and carry its values unchanged. In the other `r pct(n_out - n_single)` %, the largest source cell
supplies a median `r med_dom` % of the covered area, and the result is an area-weighted blend across
a sliver of the neighbour. That is harmless for the density, since the abundance is conserved (next
section). It is the approximation for the CV described in the callout above.

## Value transform: density → population percentile {#transform}

Per species, on the regridded cells, **after** the checks above. `val` is
`msens::density_to_suit(density, "ud", area = cell area_km2)`: 100 minus the percent of the modelled
population (density × the cell table's `area_km2`) held by cells *strictly denser* than this one. The
densest cell is 100 and `val >= 100 - p` is exactly the p % core of the population, whatever the
units or the skew of the model. Cells below `val` 1 are the tail holding the last percent of the
population and are not written (the merge's floor).

The annual surface is `msens::density_annual(n_intervals = 1)` of the one interval: the identity on the
density, asserted below, so **the annual model has exactly the interval model's cells and `val`**. The
two keys exist so `cce` has the same key shape as `gm` and `nc`; the merge reads only the annual one.

```{r}
#| label: transform

to_val <- function(dens, cell_id, how, cap = NA_real_) {
  if (how == "ud") msens::density_to_suit(dens, "ud", area = cell_area(cell_id), digits = 2)
  else             round(100 * pmin(dens / cap, 1), 2)
}

# per species: the interval surface and the annual surface (density_annual, n_intervals = 1), each
# transformed on its own cells under BOTH recipes; `val` is the selected one
surf <- imap(cells, \(d, l) {
  pos <- d$density[d$density > 0]
  cap <- as.numeric(quantile(pos, p_cap, names = FALSE))
  ann <- msens::density_annual(tibble(cell_id = d$cell_id, dens = d$density), n_intervals = 1)
  stopifnot("annual (one interval) is not the interval's density" =
              identical(ann$cell_id, d$cell_id), isTRUE(all(ann$dens == d$density)))
  mk <- \(dens) tibble(cell_id = d$cell_id, dens = dens, cv = d$cv, frac = d$frac,
                       v_ud = to_val(dens, d$cell_id, "ud"), v_cap = to_val(dens, d$cell_id, "cap", cap)) |>
    mutate(val = if (cce_transform == "ud") v_ud else v_cap)
  list(cap = cap, interval = mk(d$density), annual = mk(ann$dens))
})
stopifnot("annual val != interval val" =
            all(map_lgl(surf, \(s) identical(s$interval$val, s$annual$val))))

pop_share <- \(s, v, thr) sum((s$dens * cell_area(s$cell_id))[v >= thr]) / sum(s$dens * cell_area(s$cell_id))
```

## Write COGs (`CCE_COG=1`) {#cog}

Off by default. With `CCE_COG=1` each species gets one COG, `cce_cog/cce_<worms_id>_summer-fall.tif`
beside `dist/`: the **delivered** density, not `val`. Band 1 is `density`
(animals km⁻²) and band 2 is `cv`. Both are Float32 with nodata −9999 outside the modelled cells,
DEFLATE-compressed with the floating-point predictor, and in 256 × 256 blocks. There are no internal
overviews, because titiler decimates from full resolution. The window is cut from the cell-id raster
by row and column, so its origin and pixel size are the grid's own, including the ~5 × 10⁻⁶° float
drift. Each output pixel *is* a `global05` cell.

```{r}
#| label: cog

if (!cce_cog) {
  log_info("CCE_COG not set: no COGs written")
} else {
  # the data window in grid rows/cols (arithmetic, row-major, 1-based, top-left origin)
  ids <- as.double(cells[[1]]$cell_id)
  row <- ((ids - 1) %/% grid$nc) + 1; col <- ((ids - 1) %% grid$nc) + 1
  r0 <- min(row); r1 <- max(row); c0 <- min(col); c1 <- max(col)

  # cut that window from the cell-id raster itself: exact grid geometry, and a lookup check for free
  r_id   <- rast(cellid_tif)[r0:r1, c0:c1, drop = FALSE]
  win_id <- values(r_id, mat = FALSE)
  win_rc <- expand_grid(rr = r0:r1, cc = c0:c1)               # row-major, same order as values()
  stopifnot("cell-id window != row-major arithmetic" =
              all(win_id == (win_rc$rr - 1) * grid$nc + win_rc$cc))
  win_idx <- match(win_id, cells[[1]]$cell_id)                  # pixel -> row of cells[[l]] (NA = no data)
  log_info("COG window: rows {r0}-{r1}, cols {c0}-{c1} ({nrow(r_id)} x {ncol(r_id)} px), {sum(!is.na(win_idx))} data px")

  write_cog <- function(d, tx) {
    r <- rast(r_id, nlyrs = 2)
    values(r) <- cbind(d$density[win_idx], d$cv[win_idx])
    names(r)  <- c("density", "cv")
    tmp <- file_temp(ext = "tif"); on.exit(file_delete(tmp))
    writeRaster(r, tmp, datatype = "FLT4S", NAflag = -9999, overwrite = TRUE)
    # COG via gdal_translate: -stats writes real band statistics (terra's own COG path writes
    # STATISTICS_MEAN = -9999), -mo carries what a viewer needs to read the file on its own
    sf::gdal_utils("translate", tmp, path(dir_cog, tx$cog), options = c(
      "-of", "COG", "-co", "COMPRESS=DEFLATE", "-co", "PREDICTOR=YES", "-co", "BLOCKSIZE=256",
      "-co", "OVERVIEWS=NONE", "-stats",
      "-mo", glue("MDL_KEY={tx$mdl_key}"),
      "-mo", glue("SPECIES={tx$species}"),
      "-mo", glue("SCIENTIFIC_NAME={tx$scientific_name}"),
      "-mo", glue("WORMS_ID={tx$worms_id}"),
      "-mo", glue("WORMS_ID_ACCEPTED={tx$worms_id_accepted}"),
      "-mo", "SEASON=summer-fall",
      "-mo", "GRID=global05 (0.05 deg, -180..180; pixel = cell_id of r_cellid_global.tif)",
      "-mo", "BAND_1=density: animals per km2, area-weighted mean of the source 0.1 deg cells",
      "-mo", "BAND_2=cv: coefficient of variation of density, same weighting (an approximation for a CV)",
      "-mo", "SOURCE=Becker et al. 2020, NOAA-TM-NMFS-SWFSC-638, https://doi.org/10.25923/3znq-yx13",
      "-mo", "INPORT=https://www.fisheries.noaa.gov/inport/item/64349"))
    invisible(path(dir_cog, tx$cog))
  }
  walk(seq_len(nrow(taxa)), \(i) write_cog(cells[[taxa$layer[i]]], taxa[i, ]))

  # validate: gdalinfo says COG, 2 Float32 bands named density/cv with nodata, on the grid; then reopen
  # and compare EVERY pixel with what was written (float32 rounding only), plus a few cells by location
  set.seed(42)
  cog_chk <- map_dfr(seq_len(nrow(taxa)), \(i) {
    tx <- taxa[i, ]; f <- path(dir_cog, tx$cog); d <- cells[[tx$layer]]
    info <- fromJSON(sf::gdal_utils("info", f, options = "-json", quiet = TRUE), simplifyVector = FALSE)
    b    <- info$bands
    gt   <- unlist(info$geoTransform)
    off_x <- (gt[1] - grid$xmin) / grid$resx; off_y <- (grid$ymax - gt[4]) / grid$resy
    r <- rast(f)
    v <- values(r, mat = TRUE)
    exp_d <- d$density[win_idx]; exp_cv <- d$cv[win_idx]
    rel <- function(a, e) max(abs(a - e) / pmax(abs(e), 1e-30), na.rm = TRUE)
    # a few cells looked up by LOCATION (cell centre -> pixel), incl. the densest one
    k  <- c(which.max(d$density), sample(nrow(d), 5))
    ll <- msens::cell_lonlat(d$cell_id[k], grid)
    ex <- terra::extract(r, as.matrix(ll[, c("lon", "lat")]))
    tibble(
      cog          = tx$cog,
      layout       = info$metadata$IMAGE_STRUCTURE$LAYOUT %||% NA,
      compression  = info$metadata$IMAGE_STRUCTURE$COMPRESSION %||% NA,
      bands        = length(b),
      type         = paste(unique(map_chr(b, "type")), collapse = ","),
      descriptions = paste(map_chr(b, \(x) x$description %||% ""), collapse = ","),
      nodata       = paste(unique(map_dbl(b, \(x) x$noDataValue %||% NA_real_)), collapse = ","),
      overviews    = sum(map_int(b, \(x) length(x$overviews))),
      on_grid      = abs(off_x - round(off_x)) < 1e-6 && abs(off_y - round(off_y)) < 1e-6 &&
                     abs(gt[2] - grid$resx) < 1e-12 && abs(-gt[6] - grid$resy) < 1e-12,
      n_data_px    = sum(!is.na(v[, 1])),
      max_rel_density = rel(v[, 1], exp_d),
      max_rel_cv      = rel(v[, 2], exp_cv),
      same_na      = identical(is.na(v[, 1]), is.na(exp_d)),
      pts_rel_max  = max(abs(ex$density - d$density[k]) / pmax(d$density[k], 1e-30)))
  })
  print(kable(cog_chk, digits = 9, format.args = list(big.mark = ","),
        caption = "COG validation: gdalinfo layout/bands, alignment to the grid, and every pixel read back vs what was written (float32: relative error < 1e-6)"))
  stopifnot(
    all(cog_chk$layout == "COG"), all(cog_chk$compression == "DEFLATE"), all(cog_chk$bands == 2),
    all(cog_chk$type == "Float32"), all(cog_chk$descriptions == "density,cv"),
    all(cog_chk$nodata == "-9999"), all(cog_chk$overviews == 0), all(cog_chk$on_grid),
    all(cog_chk$n_data_px == nrow(cells[[1]])), all(cog_chk$same_na),
    all(cog_chk$max_rel_density < 1e-6), all(cog_chk$max_rel_cv < 1e-6), all(cog_chk$pts_rel_max < 1e-6))
}
```
