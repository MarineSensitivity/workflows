Build taxon global totals — each species’ denominator for the distribution share (v10)

  • Show All Code
  • Hide All Code
  • View Source
Published

2026-10-29

The v10 distribution share scores a place by the fraction of each species’ suitable habitat it holds, so every scored species needs a denominator: its total sum(val / 100 * area_km2) over its whole modelled range. This notebook builds that table, taxon_denom, by calling msens::denom_sql(), which resolves the total from three sources in precedence order: (1) a curated fallback fraction (data/us_share_fallback.csv; the US total divided by the share of the range inside the US), (2) the merged global surface (dist_merged_global), (3) AquaMaps outside the US plus the merged surface inside, for taxa that only have a US merge. Each total comes in a plain and a _strip variant (floored cells of the premultiplied sea turtles omitted) for the floor-strip sensitivity.

The base is v8’s distributions (cloned into v10) because they are global: AquaX (ax) rasters are clipped to US waters and cannot form a global share, so the notebook stops if an ax model is present (Ben, 2026-10-29).

3 Extinction-risk mode

denom_sql() reads taxon.er_mode (how the extinction-risk weight reaches the score), a column v9 added. This v10 database is a clone of the v8 base, whose taxon has none; there is_er_spatial marks exactly the premultiplied sea turtles. v8’s taxon table is NOT altered (it is part of the control the clone verified): a temporary taxon shadowing it carries er_mode for this session, and score_share_metrics.qmd does the same. The cell mode (NMFS DPS species with a per-cell ER in model_cell_er) arrives with v11, so an empty temporary model_cell_er stands in when the table is absent.

Code 
if (!"er_mode" %in% dbListFields(con, "taxon")) {

  log_info("taxon.er_mode derived from is_er_spatial in a temporary shadow of taxon (main.taxon untouched)")
}
if (!"model_cell_er" %in% dbListTables(con)) {

4 Fallback fractions

For species whose merged range is only the national (US) part, a curated fraction of the range inside the US turns the US total into a global one. The CSV is keyed by taxon_id; it is joined to this version’s taxon to get ms_merge_key. Rows for taxa absent here (v9’s CSV holds AquaX-only taxa) simply do not map. The relation denom_sql() expects is named fallback, kept as a small real table beside taxon_fallback.

Code 
fb <- read_csv(here("data/us_share_fallback.csv"), col_types = cols(taxon_id = col_character(), .default = col_guess()))
duckdb_register(con, "fb_csv", fb)
stopifnot("data/us_share_fallback.csv must have one row per taxon_id" = !anyDuplicated(fb$taxon_id),
          "fallback fractions must lie in (0, 1]" = all(fb$fraction > 0 & fb$fraction <= 1))
dbExecute(con, "CREATE OR REPLACE TABLE taxon_fallback AS
  SELECT t.ms_merge_key, f.taxon_id, f.fraction, f.method, f.basis
  FROM fb_csv f JOIN taxon t ON t.taxon_id = f.taxon_id")

5 Denominators

The expensive step reads the merged global and AquaMaps Parquet through views and aggregates over the cell table. It resumes: an existing taxon_denom is kept unless REDO_DENOM=1.

Code 
if ("taxon_denom" %in% dbListTables(con) && !redo_denom) {
  log_info("taxon_denom exists ({dbGetQuery(con, 'SELECT count(*) n FROM taxon_denom')$n} rows) - skipping (REDO_DENOM=1 to rebuild)")
} else {
  t0 <- Sys.time()
  dbExecute(con, glue("CREATE OR REPLACE TEMP VIEW mc_global AS SELECT mdl_key, cell_id, val
    FROM read_parquet('{dir_atlas}/dist_merged_global/dataset=ms_merge/**/*.parquet')"))
  dbExecute(con, glue("CREATE OR REPLACE TEMP VIEW mc_am AS SELECT mdl_key, cell_id, val
    FROM read_parquet('{dir_atlas}/dist/dataset=am/*.parquet')"))
  # the whole range includes land: a cell absent from the ocean-only `cell` table takes its latitude
  # row's area, which needs the grid's column count (see ?msens::denom_sql)
  nc <- msens::grid_spec_for(msens::grid_for_ver(ver))$nc
  dbExecute(con, paste("CREATE OR REPLACE TABLE taxon_denom AS",
                       msens::denom_sql(val_col = msens::sdm_val_col(con, "model_cell"), nc = nc)))
  n_den <- dbGetQuery(con, "SELECT count(*) n FROM taxon_denom")$n
  log_info("taxon_denom: {n_den} rows in {round(as.numeric(difftime(Sys.time(), t0, units = 'mins')), 1)} min")
}

6 Check — the P2 gate

The gate asserts that every scored taxon (valid in the US, marine, in a scored category) has a positive, finite global total no smaller than its US total, and that none was left unresolved by a missing or unsupported source. Taxa that are national-only and have no fallback fraction are reported, not stopped on: they need curation in data/us_share_fallback.csv.

  SELECT t.ms_merge_key, t.scientific_name, t.common_name, t.sp_cat, d.source, d.total_usa, d.total_global,
         d.total_usa / d.total_global AS f_us, d.n_cells_global, d.n_cells_no_area,
