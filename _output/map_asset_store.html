Read-only: nothing here writes to S3, the file host or any release

Published

2026-10-01

Not a pipeline stage — milestone M1 of .claude/plans_todo/2026-10-01 asset store — every distribution file stored once, referenced by every release.md. A release owns pointers; every distribution file lives once in an unversioned, content-addressed store (cog/{grid}/{hash}.tif, native/{ds}/{hash}.{tif|pmtiles}). This notebook computes, for every object that already sits under v8/native/ and v9/native/, the store key it would have — from the release databases and the source data, never from the object’s bytes — and writes store_migration.parquet. Nothing is copied, deleted or published. The hashing functions are msens::content_hashes() / native_vector_hash() / native_raster_rows() (unit-tested in test-asset_store.R); the vector readers are libs/native_sources.R, the same ones publish_native.qmd tiles from.

Flags: MAP_VERS (default v8,v9), MAP_TEST_N (smoke test on N objects per folder, own cache dir), REDO_ASSET_MAP=1 (recompute cached hashes), ASSET_RELIST=1 (re-list S3).

  if (file_exists(out) && !relist) return(out)
  st <- system2("aws", c("s3api", "list-objects-v2", "--bucket", bucket, "--prefix", shQuote(prefix),

  stopifnot("aws s3api list-objects-v2 failed" = identical(st, 0L))
  out
}
read_inv <- function(f) {
  ln <- readLines(f, n = 1)
  if (!length(ln) || identical(trimws(ln), "None"))                # an empty prefix prints "None"

  x[!is.na(x$bytes), ]
}

hash_glob <- function(v, name, src_glob, files = NULL) {
  cached(glue("h_{name}_{v}"), {
    con <- new_con(); on.exit(dbDisconnect(con, shutdown = TRUE))
    src <- if (is.null(files)) sprintf("read_parquet('%s')", src_glob)
           else sprintf("read_parquet([%s])", paste0("'", files, "'", collapse = ","))
    t0 <- Sys.time()
    h  <- msens::content_hashes(con, src, "mdl_key")
    log_info("{name} {v}: {nrow(h)} models, {sum(h$n)} rows, {round(as.numeric(Sys.time() - t0, units = 'mins'), 1)} min")
    as_tibble(h) |> mutate(ver = v, src = name)
  })
}

4.1 Suitability-only merged models (painted from mc_parts, not dist_merged_global)

publish_native.qmd paints a merged COG for a taxon with several AquaMaps models, or any AquaX model, as round(max(val)) per cell over its post-supersession mc_parts partition. Those rows are the content; round_even matches R’s round() (half to even), which is what the painted pixels used.

Code 
h_merged_s <- map_dfr(vers, function(v) {
  stems_have <- inv |> filter(ver == v, grp == "merged") |> pull(stem)
  need <- setdiff(stems_have, safe_key(h_merged_g$mdl_key[h_merged_g$ver == v]))
  if (!length(need)) return(NULL)
  cached(glue("h_merged_suit_{v}"), {
    con <- new_con(); on.exit(dbDisconnect(con, shutdown = TRUE))
    dbExecute(con, glue("ATTACH '{atlas_dir(v)}/merge.duckdb' AS m (READ_ONLY)"))
    mk <- dbGetQuery(con, "SELECT ms_merge_key, mkey_id FROM m.mkey_map") |> as_tibble() |>
      mutate(stem = safe_key(ms_merge_key))
    stopifnot("mkey_map: two taxa share a file stem" = !anyDuplicated(mk$stem))
    todo <- mk[mk$stem %in% need, ]
    log_info("{v}: {length(need)} merged objects not in dist_merged_global; {nrow(todo)} resolve via mkey_map")
    out <- map_dfr(split(todo, ceiling(seq_len(nrow(todo)) / 200)), function(b) {
      ids <- paste(b$mkey_id, collapse = ",")
      q <- glue("(SELECT mkey_id, cell_id, round_even(max(val), 0) AS val
                  FROM read_parquet('{atlas_dir(v)}/mc_parts/mkey_id=*/*.parquet', hive_partitioning = true)
                  WHERE mkey_id IN ({ids}) GROUP BY mkey_id, cell_id) q")
      msens::content_hashes(con, q, "mkey_id") |> as_tibble()
    })
    todo |> inner_join(out |> mutate(mkey_id = as.numeric(mkey_id)), by = "mkey_id") |>
      transmute(mdl_key = ms_merge_key, n, content_hash, ver = v, src = "merged_suit")
  })
})
log_info("suitability-only merged hashes: {nrow(h_merged_s)}")

h_am_nat <- cached("h_am_native", {

9.3 (b⁺) EVERY raster object against the rows it should hold

The 20-per-folder sample above found a few percent of am COGs that differ from the current dist/ rows by a handful of threshold cells. Cause: dist/dataset=am files were rewritten on 2026-07-13, two days after the COGs were painted (2026-07-11), and v9 inherited both. So the current rows (what scoring used, and what the key hashes) are not always the rows the existing object was painted from. This pass decides it for every object: decode the COG, hash its pixels; hash the same quantised current rows (trunc — what terra writes into INT1U — preceded by round for ax; pixels < 1 are nodata); an object is consistent when the two agree. > **Not a pipeline stage** — milestone **M1** of
> `.claude/plans_todo/2026-10-01 asset store — every distribution file stored once, referenced by every release.md`.
> A release owns *pointers*; every distribution file lives once in an unversioned, content-addressed
> store (`cog/{grid}/{hash}.tif`, `native/{ds}/{hash}.{tif|pmtiles}`). This notebook computes, for
> every object that already sits under `v8/native/` and `v9/native/`, the store key it **would** have —
> from the release databases and the source data, never from the object's bytes — and writes
> `store_migration.parquet`. Nothing is copied, deleted or published. The hashing functions are
> `msens::content_hashes()` / `native_vector_hash()` / `native_raster_rows()` (unit-tested in
> `test-asset_store.R`); the vector readers are `libs/native_sources.R`, the same ones
> `publish_native.qmd` tiles from.
>
> Flags: `MAP_VERS` (default `v8,v9`), `MAP_TEST_N` (smoke test on N objects per folder, own cache dir),
> `REDO_ASSET_MAP=1` (recompute cached hashes), `ASSET_RELIST=1` (re-list S3).

### (b⁺) EVERY raster object against the rows it should hold

The 20-per-folder sample above found a few percent of `am` COGs that differ from the current `dist/` rows by a
handful of threshold cells. Cause: `dist/dataset=am` files were rewritten on 2026-07-13, two days **after**
the COGs were painted (2026-07-11), and v9 inherited both. So the *current rows* (what scoring used, and what
the key hashes) are not always the rows the existing object was painted from. This pass decides it for every
object: decode the COG, hash its pixels; hash the same quantised current rows (`trunc` — what terra writes
into INT1U — preceded by `round` for ax; pixels < 1 are nodata); an object is **consistent** when the two agree.
An inconsistent object must be **repainted** from its current rows at M2, never copied under the new key.

  # its RAM with a browser and other sessions) loses at most the batches in flight, never the whole pass

  dec_batch <- function(b, id, dir_obs, grid_g05, grid_half) {
    suppressMessages({library(terra); library(msens); library(arrow)})
    rows <- lapply(seq_len(nrow(b)), function(i) {
      r <- native_raster_rows(terra::rast(b$path[i]), if (b$grp[i] == "am_native") grid_half else grid_g05)
      r$key <- paste(b$grp[i], b$file[i], b$etag[i], sep = "\r"); r })
    h <- content_hashes_df(do.call(rbind, rows), by = "key")
    arrow::write_parquet(h, file.path(dir_obs, paste0(id, ".parquet.tmp"))); file.rename(file.path(dir_obs, paste0(id, ".parquet.tmp")), file.path(dir_obs, paste0(id, ".parquet")))
    invisible(id)
  }
  gh <- grid_spec(rast(nrows = 360, ncols = 720, xmin = -180, xmax = 180, ymin = -90, ymax = 90, crs = "EPSG:4326"))

  # `am` (13 billion pixels, the heaviest family) is opt-in here: MAP_VERIFY_AM=1. It is the family with known
  # inconsistent objects (see above), so M2 re-verifies it object by object as the gate on each copy; this
  # notebook samples it (60 per release) and verifies every OTHER family exhaustively.
  skip_b <- if (nzchar(Sys.getenv("MAP_VERIFY_AM"))) rep(FALSE, length(ids)) else grepl("^am-", ids)
  left <- which(!file_exists(glue("{dir_obs}/{ids}.parquet")) & !skip_b)
  log_info("decode: {length(bs)} batches of <= 30 objects; {length(bs) - length(left)} already done, {length(left)} to do (3 workers)")
  plan(multisession, workers = 3); on.exit(plan(sequential), add = TRUE)
  t0 <- Sys.time()
  for (g in split(left, ceiling(seq_along(left) / 60))) {
    future_walk2(bs[g], ids[g], dec_batch, dir_obs = dir_obs, grid_g05 = grid_g05, grid_half = gh,
                 .options = furrr_options(seed = TRUE, packages = c("terra", "msens", "arrow")))
    log_info("decode: {sum(file_exists(glue('{dir_obs}/{ids}.parquet')))} / {length(bs)} batches done, {round(as.numeric(Sys.time() - t0, units = 'mins'), 1)} min")
  }
  stopifnot("some decode batches did not finish" = all(file_exists(glue("{dir_obs}/{ids}.parquet")) | skip_b))
  map_dfr(glue("{dir_obs}/{ids}.parquet")[file_exists(glue("{dir_obs}/{ids}.parquet"))], read_parquet) |>
    transmute(grp = sapply(strsplit(key, "\r"), `[`, 1), file = sapply(strsplit(key, "\r"), `[`, 2), etag = sapply(strsplit(key, "\r"), `[`, 3), n_obs = n, q_obs = content_hash)
})

## 10 · For M3: v7 `rng_iucn` inputs that can take an original

v7 keys IUCN ranges by scientific NAME (`rng_iucn:Name`), v8/v9 by IUCN `id_no`, so there is no key join.
The only honest link is an **exact** name match that is **unambiguous** (one v7 model, one v9 model of that
name), kept only if the original agrees with the surface v7 already draws: every cell of the v7 gridded
surface (US waters only, `usa05`, 0–360° longitude) must fall inside the original PMTiles' header bounds
