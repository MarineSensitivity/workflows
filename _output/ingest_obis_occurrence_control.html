v11 Q1: one OBIS snapshot (marinebon/obisindicators export, global 0.05° cells) for every record count, and the occurrence-buffer range dataset

Published

2026-10-29

v11 counts every record from one OBIS snapshot: the monthly H3 store that marinebon/obisindicators refreshes on the Mac mini and publishes beside its indicator layers as obis-h3/vYYYYMMDD/. The MST-facing export in that folder is

  • obis_cell.parquet — aphiaid, cell_id, date_year, records: every OBIS species-level record count per MST global05 cell (the cell holding the centroid of its H3 res-7 hexagon, ~5 km² against the cell’s ~25 km²), date_year NULL where the record has no year;
  • worms_taxon.parquet — the WoRMS taxonomy of the same release (read by ingest_worms.qmd under WORMS_SOURCE=obisindicators);
  • release.json — whose mst block records obis_snapshot and worms_version.

The release is OBIS_H3_RELEASE (default v20261012), read from {obis_h3_dir}/{release} (~/_big/obis/obis-h3 on the laptop and the Mac mini) and, when that folder is absent, over HTTPS from obis_h3_url.

This notebook writes two things:

  1. obs_obis — the occurrence-count table, kept whole (all 170,174 AphiaIDs, ~99 MB) as Parquet at marine-atlas/obs/dataset=obs_obis/obis_cell.parquet beside a copy of worms_taxon.parquet and the release’s provenance. It is not in dist/, which is for (mdl_key, cell_id, val) model surfaces. Every v11 count (the occurrence rule, the R2 fallbacks, effort proxies) reads this one file.
  2. rng_occ — for a configured species list (data/v11/occ_species.csv: the six sea turtles and the North Atlantic right whale; OCC_SPECIES=137205,159023 selects a subset) the cells within d km of any cell with ≥ 1 record, as dist/dataset=rng_occ/{aphiaid}_d{d}km.parquet — (mdl_key, cell_id, val), mdl_key = "rng_occ|{aphiaid}", val = the species’ extinction-risk score. One d per run (OCC_BUFFER_KM, default 100, libs/vars.R), recorded in the file name, in model_rng_occ.csv and in the manifest; a run at another d, another release or another species set clears the files it supersedes (the merge input globs dist/*/*.parquet, so a stale d must never survive beside a new one).

The gate at the end is the Q1 acceptance: for the six turtles and the right whale, the OBIS records per BOEM ecoregion counted from obis_cell.parquet × the ecoregion zone cells must reproduce the v7c evidence table (data/v7c/records_species_ecoregion.csv, channel obis_all, taken from the 2025-03-18 OBIS export) within the snapshot difference.

6 rng_occ — the cells within d km of a record

A cell is within d km when the great-circle distance between its centre and the centre of a record cell is ≤ d (msens::cells_within_sql(), unit-tested against a brute-force scan: haversine, R = 6371.0088 km, in DuckDB on the cell_id arithmetic — no spatial extension, no raster). The column index wraps modulo 7200, so the antimeridian needs no special case (the Aleutians and Fiji are one contiguous neighbourhood), and the longitude reach of the cap widens with latitude (asin(sin(d/R)/cos(lat)), every longitude when the cap holds a pole). The whole grid is buffered, land cells included: this is a range dataset, and “how marine” is derived at the merge. The self-test below checks the SQL against a brute-force scan of all 25.9 M cells.

# brute force over ALL 25.9 M cells (test-only; the rule itself is msens::cells_within_sql)
occ_buffer_brute_sql <- function(cell_id, d_km, ncol = 7200L, nrow = 3600L, deg = 0.05) {
  R_km <- 6371.0088
  glue::glue("
    WITH a AS (
      SELECT 90 - (({cell_id} - 1) // {ncol} + 0.5) * {deg} AS lat0,
             -180 + (({cell_id} - 1) % {ncol} + 0.5) * {deg} AS lon0),
    g AS (
      SELECT (i + 1)::INTEGER AS cell_id, 90 - (i // {ncol} + 0.5) * {deg} AS lat1, -180 + (i % {ncol} + 0.5) * {deg} AS lon1
      FROM range(0, {ncol * nrow}) t(i))
    SELECT g.cell_id FROM g, a
    WHERE 2 * {R_km} * asin(sqrt(least(1,
            pow(sin(radians(lat1 - lat0) / 2), 2) +
            cos(radians(lat0)) * cos(radians(lat1)) * pow(sin(radians(lon1 - lon0) / 2), 2)))) <= {d_km}
    ORDER BY g.cell_id", .trim = TRUE)
}

8 Gate — records per ecoregion against the v7c evidence

For the six turtles and the right whale: the OBIS records per BOEM ecoregion counted here (obis_cell.parquet × the shared ecoregion zone cells of the global05 grid) against data/v7c/records_species_ecoregion.csv, channel obis_all (the OBIS export of 2025-03-18, build_v7c_exclusions.qmd).

Assignment follows the v7c count so the two are comparable: a cell goes to the ecoregion covering most of it (pct_covered, ties to the first key — msens::cell_zone_major_sql()’s rule), and a cell in no ecoregion (a beach or harbour record) goes to the nearest ecoregion cell within 5 cells (0.25°, ≈ 25 km), searched on the grid. Records without a year count.

Resolution caveat. v7c located each record by its coordinates, to its 0.05° cell; here the record is the centroid cell of its H3 res-7 hexagon (≤ ~2.5 km from the point), so a record within a hex of an ecoregion edge or of the 25-km search radius can fall on the other side. And v7c intersected cells with the v7 ecoregion vintage on the usa05 grid; the zone cells here are the global05 extract of the same polygons. Counts near an edge therefore move by a few records either way.

Rules (per species × ecoregion; old = the v7c count, new = this snapshot):

  • zero: old = 0 ⇒ new = 0 — a place v7c found never recorded must still be so, else the v7c exclusions (turtles out of the East Bering Sea, the right whale out of the Gulf of America) lose their evidence;
  • lower: new ≥ old − max(5, 2 % of old) — OBIS only grows between snapshots; the slack is the edge effect above;
  • upper: new ≤ 1.5 × old + 5 — the growth the snapshot difference can account for.

A deviation passes only when data/v11/obis_gate_reviewed.csv lists the pair and rule with status = accepted and a reason; anything else stops the render (OBIS_GATE=warn logs it instead, for a look at the table).

v11 counts every record from **one OBIS snapshot**: the monthly H3 store that
[marinebon/obisindicators](https://github.com/marinebon/obisindicators) refreshes on the Mac mini and
publishes beside its indicator layers as `obis-h3/vYYYYMMDD/`. The MST-facing export in that folder is

- `obis_cell.parquet` — `aphiaid, cell_id, date_year, records`: every OBIS species-level record count per
  MST `global05` cell (the cell holding the centroid of its H3 res-7 hexagon, ~5 km² against the cell's
  ~25 km²), `date_year` NULL where the record has no year;
- `worms_taxon.parquet` — the WoRMS taxonomy of the same release (read by `ingest_worms.qmd` under
  `WORMS_SOURCE=obisindicators`);
- `release.json` — whose `mst` block records `obis_snapshot` and `worms_version`.

The release is `OBIS_H3_RELEASE` (default `v20261012`), read from `{obis_h3_dir}/{release}` (`~/_big/obis/obis-h3`
on the laptop and the Mac mini) and, when that folder is absent, over HTTPS from `obis_h3_url`.

This notebook writes two things:

1. **`obs_obis`** — the occurrence-count table, kept whole (all 170,174 AphiaIDs, ~99 MB) as Parquet at
   `marine-atlas/obs/dataset=obs_obis/obis_cell.parquet` beside a copy of `worms_taxon.parquet` and the
   release's provenance. It is not in `dist/`, which is for `(mdl_key, cell_id, val)` model surfaces. Every
   v11 count (the occurrence rule, the R2 fallbacks, effort proxies) reads this one file.
2. **`rng_occ`** — for a configured species list (`data/v11/occ_species.csv`: the six sea turtles and the
   North Atlantic right whale; `OCC_SPECIES=137205,159023` selects a subset) the **cells within `d` km of any
   cell with ≥ 1 record**, as `dist/dataset=rng_occ/{aphiaid}_d{d}km.parquet` — `(mdl_key, cell_id, val)`,
   `mdl_key = "rng_occ|{aphiaid}"`, `val` = the species' extinction-risk score. One `d` per run
   (`OCC_BUFFER_KM`, default 100, `libs/vars.R`), recorded in the file name, in `model_rng_occ.csv` and in the
   manifest; a run at another `d`, another release or another species set clears the files it supersedes
   (the merge input globs `dist/*/*.parquet`, so a stale `d` must never survive beside a new one).

The **gate** at the end is the Q1 acceptance: for the six turtles and the right whale, the OBIS records per BOEM
ecoregion counted from `obis_cell.parquet` × the ecoregion zone cells must reproduce the v7c evidence table
(`data/v7c/records_species_ecoregion.csv`, channel `obis_all`, taken from the 2025-03-18 OBIS export) within the
snapshot difference.

## `rng_occ` — the cells within d km of a record

A cell is within `d` km when the great-circle distance between its **centre** and the centre of a record cell is
≤ `d` (`msens::cells_within_sql()`, unit-tested against a brute-force scan: haversine, R = 6371.0088 km, in DuckDB on the `cell_id`
arithmetic — no spatial extension, no raster). The column index wraps modulo 7200, so the **antimeridian
needs no special case** (the Aleutians and Fiji are one contiguous neighbourhood), and the longitude reach of
the cap widens with latitude (`asin(sin(d/R)/cos(lat))`, every longitude when the cap holds a pole). The
whole grid is buffered, land cells included: this is a range dataset, and "how marine" is derived at the merge.
The self-test below checks the SQL against a brute-force scan of all 25.9 M cells.

```{r}
occ_buffer_brute_sql <- function(cell_id, d_km, ncol = 7200L, nrow = 3600L, deg = 0.05) {

    WITH a AS (
      SELECT 90 - (({cell_id} - 1) // {ncol} + 0.5) * {deg} AS lat0,
             -180 + (({cell_id} - 1) % {ncol} + 0.5) * {deg} AS lon0),

      FROM range(0, {ncol * nrow}) t(i))

            pow(sin(radians(lat1 - lat0) / 2), 2) +
```

## Gate — records per ecoregion against the v7c evidence

For the six turtles and the right whale: the OBIS records per BOEM ecoregion counted here (`obis_cell.parquet`
× the shared ecoregion zone cells of the `global05` grid) against `data/v7c/records_species_ecoregion.csv`,
channel `obis_all` (the OBIS export of 2025-03-18, `build_v7c_exclusions.qmd`).

**Assignment follows the v7c count so the two are comparable:** a cell goes to the ecoregion covering most of it
(`pct_covered`, ties to the first key — `msens::cell_zone_major_sql()`'s rule), and a cell in no ecoregion (a
beach or harbour record) goes to the nearest ecoregion cell within 5 cells (0.25°, ≈ 25 km), searched on the
grid. Records without a year count.

**Resolution caveat.** v7c located each record by its coordinates, to its 0.05° cell; here the record is the
centroid cell of its H3 res-7 hexagon (≤ ~2.5 km from the point), so a record within a hex of an ecoregion edge
or of the 25-km search radius can fall on the other side. And v7c intersected cells with the v7 ecoregion
vintage on the `usa05` grid; the zone cells here are the `global05` extract of the same polygons. Counts near an
edge therefore move by a few records either way.

**Rules** (per species × ecoregion; `old` = the v7c count, `new` = this snapshot):

- *zero*: `old = 0` ⇒ `new = 0` — a place v7c found never recorded must still be so, else the v7c exclusions
  (turtles out of the East Bering Sea, the right whale out of the Gulf of America) lose their evidence;
- *lower*: `new ≥ old − max(5, 2 % of old)` — OBIS only grows between snapshots; the slack is the edge effect above;
- *upper*: `new ≤ 1.5 × old + 5` — the growth the snapshot difference can account for.

A deviation passes only when `data/v11/obis_gate_reviewed.csv` lists the pair and rule with `status = accepted`
and a reason; anything else stops the render (`OBIS_GATE=warn` logs it instead, for a look at the table).

```{r}
#| label: gate

gate_mode <- match.arg(Sys.getenv("OBIS_GATE", "stop"), c("stop", "warn"))
f_zc  <- path.expand(glue("{dir_derived}/zones/ecoregion_2025-06/global05/zone_cell.parquet"))
f_v7c <- here("data/v7c/records_species_ecoregion.csv")
stopifnot("ecoregion zone_cell (global05) missing: build_zone_sets.qmd" = file_exists(f_zc), file_exists(f_v7c))

old <- read_csv(f_v7c) |> filter(channel == "obis_all") |>
  transmute(common, aphia = as.integer(aphia), eco, old = as.integer(n))
g_ids <- unique(old$aphia)

dbExecute(con, glue("
  CREATE OR REPLACE TEMP TABLE cz AS
  SELECT cell_id, zone_key FROM (
    SELECT cell_id, zone_key, row_number() OVER (PARTITION BY cell_id ORDER BY pct_covered DESC, zone_key) AS r
    FROM read_parquet('{f_zc}')) WHERE r = 1"))
dbExecute(con, glue("
  CREATE OR REPLACE TEMP TABLE g_ids AS
  SELECT w.taxonID AS aphiaid, coalesce(w.acceptedNameUsageID, w.taxonID) AS sp_aphia
  FROM read_parquet('{f_worms}') w WHERE coalesce(w.acceptedNameUsageID, w.taxonID) IN ({paste(g_ids, collapse = ',')})"))
dbExecute(con, glue("
  CREATE OR REPLACE TEMP TABLE g_oc AS
  SELECT g.sp_aphia AS aphia, o.cell_id, sum(o.records)::BIGINT AS n
  FROM read_parquet('{f_cell}') o JOIN g_ids g ON o.aphiaid = g.aphiaid WHERE o.records >= 1 GROUP BY 1, 2"))
# cells in no ecoregion -> the nearest ecoregion cell within 5 cells (distance in cells, circular offsets), column wrap at 7200
dbExecute(con, "
  CREATE OR REPLACE TEMP TABLE g_un AS SELECT DISTINCT cell_id FROM g_oc WHERE cell_id NOT IN (SELECT cell_id FROM cz)")
dbExecute(con, "
  CREATE OR REPLACE TEMP TABLE g_off AS
  SELECT dr, dc, dr * dr + dc * dc AS d2 FROM range(-5, 6) a(dr), range(-5, 6) b(dc) WHERE dr * dr + dc * dc <= 25")
dbExecute(con, "
  CREATE OR REPLACE TEMP TABLE g_near AS
  SELECT cell_id, zone_key AS eco_near FROM (
    SELECT u.cell_id, cz.zone_key,
           row_number() OVER (PARTITION BY u.cell_id ORDER BY o.d2, cz.zone_key) AS r
    FROM g_un u CROSS JOIN g_off o
    JOIN cz ON cz.cell_id = (((u.cell_id - 1) // 7200 + o.dr) * 7200 + ((u.cell_id - 1) % 7200 + o.dc + 7200) % 7200 + 1)
    WHERE (u.cell_id - 1) // 7200 + o.dr BETWEEN 0 AND 3599) WHERE r = 1")
new <- dbGetQuery(con, "
  SELECT o.aphia, coalesce(cz.zone_key, n.eco_near) AS eco,
         sum(o.n)::BIGINT AS new, (sum(o.n) FILTER (WHERE cz.zone_key IS NOT NULL))::BIGINT AS new_in_cells
  FROM g_oc o LEFT JOIN cz USING (cell_id) LEFT JOIN g_near n USING (cell_id)
  WHERE coalesce(cz.zone_key, n.eco_near) IS NOT NULL GROUP BY 1, 2") |> as_tibble() |>
  mutate(aphia = as.integer(aphia))

cmp <- old |>
  left_join(new, by = c("aphia", "eco")) |>
  mutate(across(c(new, new_in_cells), \(x) coalesce(as.integer(x), 0L)),
         lower_ok = new >= old - pmax(5, 0.02 * old),
         upper_ok = new <= 1.5 * old + 5,
         rule     = case_when(old == 0L & new > 0L ~ "zero",
                              !lower_ok            ~ "lower",
                              !upper_ok            ~ "upper",
                              TRUE                 ~ NA_character_),
         verdict  = if_else(is.na(rule), "ok", paste("DEVIATES:", rule)),
         ratio    = round(if_else(old > 0L, new / old, NA_real_), 2)) |>
  arrange(factor(aphia, g_ids), eco)
msens::report_table(
  cmp |> select(species = common, aphia, eco, `v7c obis_all (2025-03-18)` = old, `this snapshot` = new,
                `of which in-ecoregion cells` = new_in_cells, ratio, verdict),
  caption = glue("OBIS records per ecoregion: v7c evidence vs {info$obis_snapshot} snapshot ",
                 "({nrow(cmp)} species x ecoregion pairs)"))

f_rev <- here("data/v11/obis_gate_reviewed.csv")
reviewed <- if (file_exists(f_rev)) read_csv(f_rev) else tibble(aphia = integer(), eco = character(), rule = character(), status = character(), reason = character())
dev   <- cmp |> filter(!is.na(rule)) |>
  left_join(mutate(reviewed, aphia = as.integer(aphia)), by = c("aphia", "eco", "rule"))
unreviewed <- dev |> filter(is.na(status) | status != "accepted")
n_zero_kept <- cmp |> filter(old == 0L, new == 0L) |> nrow()
log_info("gate: {nrow(cmp)} pairs; {sum(cmp$old == 0L)} zero in v7c ({n_zero_kept} still zero); ",
         "{nrow(dev)} deviate ({nrow(unreviewed)} not accepted in obis_gate_reviewed.csv)")
if (nrow(unreviewed)) {
  print(msens::report_table(unreviewed |> select(common, aphia, eco, old, new, rule, status),
                            caption = "Gate deviations that no accepted row in data/v11/obis_gate_reviewed.csv covers"))
  msg <- glue("OBIS gate: {nrow(unreviewed)} species x ecoregion pair(s) deviate from the v7c evidence beyond the ",
              "snapshot tolerance and are not accepted in data/v11/obis_gate_reviewed.csv (OBIS_GATE=warn to log instead)")
  if (gate_mode == "stop") stop(msg) else log_warn(msg)
}
```
