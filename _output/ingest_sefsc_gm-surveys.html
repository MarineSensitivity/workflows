Vessel 2003–2024 and aerial 2011–2018 line-transect effort + marine-mammal sightings, and the 19 NCEI 0256800 v2.2 density models, on their one native 40 km² hexagon grid

Published

2026-11-13

Lance Garrison (NOAA SEFSC, Marine Mammal and Turtle Division) delivered on 2026-11-12 the broadscale vessel (2003–2024, including the 2023 and 2024 surveys) and aerial (2011–2018) line-transect survey effort and marine-mammal sightings in the Gulf that went into the GoMMAPPS spatial density models, together with the 40 km² model hexagons. This notebook prepares them, with the 19 density models of NCEI accession 0256800 v2.2 (the same hexagons, matched by HEXID), as the inputs of the OceanMetrics Atlas collection sefsc_gm version 2. That collection is unlisted and shared by link for review with the provider first. Version 1 is the MarineSensitivity v8 external collection (?c=msens-v8-gm, the annual densities as a 0–100 index on the 0.05° grid).

This is a preview input, not a MarineSensitivity dataset: there is no ds_key, nothing is written under dist/, and the scored ingest ingest_sdm-gm.qmd is untouched. Its workflow_type is publish, so the release DAG’s [auto] dependency never pulls it in. The atlas builder (oceanmetrics/atlas pipeline/atlas_pipeline/sefsc_gm.py) reads the output folder and refuses to stage it without the DONE marker this notebook writes last.

1 Source

sefsc_src in libs/paths.R (~/_big/msens/raw/sefsc.noaa.gov/2026-11-12; SEFSC_SRC overrides) holds the delivery unchanged: four R spatial data frames (.rds, the full field names) and shapefiles of the same names (field names abbreviated), the hexagon shapefile GoMex_Hexagons_40km.shp, and Lance’s SEFSC Line Transect Survey Data ReadMe.txt. The density models are the 19 shapefiles of gm_shp_dir (NCEI 0256800 v2.2) with ../spp_gmx.xlsx beside them. They carry {Mon}_n (abundance per hexagon), {Mon}_se and {Mon}_cv for each modelled month, with -9999 for no data.

2 What this notebook does

  1. Reads the four .rds files, the hexagons and the 19 density tables, and asserts what it relies on: row counts, CRSs, unique keys, every HEXID of the effort, sightings and density tables in the hexagon set.
  2. Builds the sighting → density model crosswalk (data/sefsc_gm_sighting_taxa.csv, one row per distinct delivered name per platform). A sighting belongs to every model whose species set contains every candidate of its identification; a higher taxon or a species no model covers belongs to none. AphiaIDs come from spp.duckdb’s WoRMS snapshot (offline).
  3. Links each sighting to its effort segment and measures, per sighting, whether it lies in its own HEXID hexagon and how far it is from its segment.
  4. Writes per-hexagon survey totals onto the hexagons, and one wide values table: per hexagon, the density and CV of every model and month plus the annual density, and the survey effort, groups and individuals per platform and month.
  5. Writes every layer as GeoParquet and FlatGeobuf in EPSG:4326, the tables layers.csv, models.csv, taxa.csv and checks.csv, then DONE, then the manifest.

read_xlsx_sheet1 <- function(path) {   # spp_gmx.xlsx, one sheet, header row 1 (the reader of ingest_sdm-gm.qmd)
  td <- tempfile(); dir_create(td); on.exit(dir_delete(td))
  utils::unzip(path, exdir = td)
  ns <- c(d = "http://schemas.openxmlformats.org/spreadsheetml/2006/main")
  ss <- read_xml(file.path(td, "xl/sharedStrings.xml")) |> xml_find_all("//d:si", ns) |>
    map_chr(\(x) paste(xml_text(xml_find_all(x, ".//d:t", ns)), collapse = ""))
  cells <- read_xml(file.path(td, "xl/worksheets/sheet1.xml")) |> xml_find_all("//d:sheetData/d:row/d:c", ns)
  typ <- xml_attr(cells, "t")
  v   <- map_chr(cells, \(x) { n <- xml_find_first(x, "d:v", ns); if (inherits(n, "xml_missing")) NA_character_ else xml_text(n) })
  is_s <- !is.na(typ) & typ == "s" & !is.na(v)
  v[is_s] <- ss[as.integer(v[is_s]) + 1L]
  ref <- xml_attr(cells, "r")
  d <- tibble(col = sub("[0-9]+$", "", ref), row = as.integer(sub("^[A-Z]+", "", ref)), v = v)
  hdr <- d |> filter(row == 1) |> select(col, name = v)
  d |> filter(row > 1) |> left_join(hdr, by = "col") |> select(row, name, v) |>
    pivot_wider(names_from = name, values_from = v) |> select(-row)
}

6 Sighting → model crosswalk

The delivered names are many higher taxa and “X or Y” / “X/Y” / “X | Y” combinations. The curation below gives each distinct name its resolved name, its candidate species (or taxa) and its density models; the code then checks the rule: a sighting belongs to every model whose species set contains every candidate of its identification. The one deliberate exception (Ben, 2026-11-13) is the Balaenoptera combinations, which go to the Rice’s whale model with id_certain = FALSE although sei, fin and Bryde’s whales are not modelled. models is a |-delimited string of model keys with a leading and trailing | (|rices_whale|), empty for none, so a filter can match |key|.

# in_own_hex: the point lies in the hexagon its HEXID names (planar, in the hexagons' own CRS)
in_own <- function(pts, hexid) {
  p <- st_transform(st_geometry(pts), crs_lcc)
  h <- st_geometry(hex)[match(hexid, hex$HEXID)]
  ok <- !is.na(match(hexid, hex$HEXID))
  out <- rep(NA, length(p))
  out[ok] <- map2_lgl(p[ok], h[ok], \(a, b) st_intersects(a, b, sparse = FALSE)[1, 1])
  out
}

# dist_to_segment_m: geodesic distance (s2, EPSG:4326) from the sighting to its own segment; NA when unlinked
seg_dist <- function(pts, seg_geom_4326, idx) {
  d <- rep(NA_real_, nrow(pts))
  ok <- !is.na(idx)
  d[ok] <- as.numeric(st_distance(st_geometry(pts)[ok], seg_geom_4326[idx[ok]], by_element = TRUE))
  d
}

9 Values per hexagon

Per hexagon, one double column per (layer × month × variable), named {layer}__{month}__{variable}:

  • Density models (19 layers): density = {Mon}_n / Area_km2 (animals per km²) and cv as delivered, for each month the model covers, -9999 as NULL; and annual__density, the day-weighted mean of the twelve monthly densities with a month the model does not cover counting as 0 (msens::density_annual(..., n_intervals = 12, weights = msens::month_day_weights()), the annual of ingest_sdm-gm.qmd). There is no annual CV.
  • Surveys (survey_vessel, survey_aerial, survey_all): effort_km (sum of the segment length field / 1000 by the segment’s HEXID), groups (number of sightings by the sighting’s HEXID), individuals (sum of group.size), per month of the segment or sighting and annual (all months). A hexagon with no effort is NULL, not 0 (it was not surveyed), except that groups / individuals are 0 where effort_km > 0, and a sighting whose hexagon has no effort that month still counts.

A column with no value in any hexagon is not written.

## What this notebook does

1. Reads the four `.rds` files, the hexagons and the 19 density tables, and asserts what it relies on: row counts,

   identification; a higher taxon or a species no model covers belongs to none. AphiaIDs come from `spp.duckdb`'s

3. Links each sighting to its effort segment and measures, per sighting, whether it lies in its own `HEXID` hexagon

   CV of every model and month plus the annual density, and the survey effort, groups and individuals per platform
   and month.
5. Writes every layer as GeoParquet and FlatGeobuf in EPSG:4326, the tables `layers.csv`, `models.csv`, `taxa.csv`

## Values per hexagon

Per hexagon, one double column per (layer × month × variable), named `{layer}__{month}__{variable}`:

- **Density models** (19 layers): `density` = `{Mon}_n / Area_km2` (animals per km²) and `cv` as delivered, for each
  month the model covers, `-9999` as NULL; and `annual__density`, the **day-weighted** mean of the twelve monthly
  densities with a month the model does not cover counting as 0 (`msens::density_annual(..., n_intervals = 12,
  weights = msens::month_day_weights())`, the annual of `ingest_sdm-gm.qmd`). There is no annual CV.
- **Surveys** (`survey_vessel`, `survey_aerial`, `survey_all`): `effort_km` (sum of the segment length field / 1000
  by the segment's `HEXID`), `groups` (number of sightings by the sighting's `HEXID`), `individuals` (sum of
  `group.size`), per month of the segment or sighting and `annual` (all months). A hexagon with no effort is NULL,
  not 0 (it was not surveyed), except that `groups` / `individuals` are 0 where `effort_km` > 0, and a sighting whose
  hexagon has no effort that month still counts.

A column with no value in any hexagon is not written.

# GeoParquet 1.1 (WKB geometry, CRS = OGC:CRS84 by omission, i.e. EPSG:4326 lon/lat) from arrow; the R GDAL build has no
# Parquet driver
write_geoparquet <- function(x, path) {
  x <- st_transform(x, 4326)
  g <- st_geometry(x)
  tbl <- arrow::arrow_table(st_drop_geometry(x) |> as_tibble(),
                            geometry = arrow::Array$create(unclass(st_as_binary(g, EWKB = FALSE)), type = arrow::binary()))
  types <- unique(as.character(st_geometry_type(g))) |> str_to_title() |>
    str_replace("Linestring", "LineString") |> str_replace("Multilinestring", "MultiLineString") |>
    str_replace("Multipolygon", "MultiPolygon") |> str_replace("Multipoint", "MultiPoint")
  geo <- list(version = "1.1.0", primary_column = "geometry",
              columns = list(geometry = list(encoding = "WKB", geometry_types = as.list(types),
                                             bbox = round(as.numeric(st_bbox(g)), 7))))
  md <- tbl$metadata; md$r <- NULL; md$geo <- as.character(jsonlite::toJSON(geo, auto_unbox = TRUE, digits = NA))
  tbl$metadata <- md
  arrow::write_parquet(tbl, path, compression = "zstd")
}
