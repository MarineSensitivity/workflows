2026-10-29

v10 adds one scoring stage to the v8 build and changes nothing upstream of it. The published (“within ecoregion”) metrics of v8 — extrisk_{cat} → ecoregional min–max → equal-weight composite — are kept in cell_metric / zone_metric unchanged and are the control: with SHARE_METRICS=0 this notebook writes nothing and only proves that the five scoring tables still digest to v8’s checkpoints. With SHARE_METRICS=1 it adds the “across the nation” family of the method page (Sensitivity Across Regions, 2026-09-11, rev 14; plan 2026-10-29 §2), computed by msens::share_run() — the rule lives in msens::share_sql() and is asserted by test-share.R:

  • share_s,c = v_s,c · A_c / Σ_range(s) v · A — each species’ share of its WHOLE modelled range per cell (taxon_denom, built by build_taxon_global_total);
  • share_c,g = Σ_s w_s · share_s,c / 100 and share_z,g = Σ_c share_c,g · p_zc — risk-weighted, summed per category and zone;
  • v10_z,g = 100 · (share_z,g / share_USA,g) / (A_z / A_USA) — a location quotient: 100 = the national average concentration, the same reference for every area and component;
  • pct_world (the percent of the world’s risk-weighted importance at stake) and pct_nation beside it; a component is reportable only where its cells cover ≥ κ of the zone, else no score, never zero; primprod_v10 = 100 · mean_z(npp) / mean_USA(npp); the composite is the equal-weight mean of the reportable components.

Three denominators are computed as columns (plan D2; SHARE_DENOM names the headline): global (the species’ whole range — the headline), usa (its US cells: Tim White’s 2026-09-11 brief, the same score with species weight w instead of w · f_us), pooled (no per-species normalization, the RESA-style sum). The floored turtle cells are kept by default and stripped as a sensitivity column (D4). Nothing here touches the v8 rows: the gate below digests them before and after.

3 The control: v8’s rows are v8’s, before anything is written

The clone verified at bootstrap hashes the whole tables (checkpoints_v8.json). This stage adds rows to three of them, so its own gate is on the v8 subset — the metric keys and zone_taxon columns v8 wrote — digested the same way before and after the share rows land. The reference values are recorded on the first run and asserted on every later one; BUILD_REFERENCE=1 is the only way to move them. Zone-level surfaces are digested as FLOAT (as build_v7c does); the per-cell shares at four significant digits, because their parallel sums differ in the last double bits between two correct runs.

4 The share family (SHARE_METRICS=1)

msens::share_run() is called once per denominator (and once more for the floor-strip sensitivity under the global denominator); each call returns the zone table, the per-cell table, the per-zone per-species table and the composite, and asserts the rule’s own invariants (a positive denominator for every species, cell shares summing to 1 / f_us, the national pseudo-zone present). Inputs: taxon_denom (from build_taxon_global_total), a temporary taxon shadow carrying er_mode for the v8 schema, an empty temporary model_cell_er, and primprod_cell from v8’s own primprod metric. The national reference is the study area (cell.in_usa), not the USA pseudo-zone (see ?msens::share_sql).

# idempotent metric_seq: fetch or insert the key, then wipe the prior rows of this key at the ONE level
# being written. A metric key is shared by cell_metric and zone_metric by design (v8's
# extrisk_{cat}_ecoregion_rescaled lives at both levels), so a writer must never clear the other
# level: the first render of this stage deleted the zone-level headline rows while writing the
# per-cell rasters of the same keys.
mseq <- function(key, desc = "", level = c("zone", "cell")) {
  level <- match.arg(level)
  ex <- dbGetQuery(con, glue("SELECT metric_seq FROM metric WHERE metric_key = '{key}'"))
  s  <- if (nrow(ex)) ex$metric_seq[1] else {
    s0 <- dbGetQuery(con, "SELECT coalesce(max(metric_seq),0)+1 s FROM metric")$s
    dbExecute(con, glue("INSERT INTO metric VALUES ({s0}, '{key}', '{gsub(\"'\",\"\",desc)}')")); s0 }
  dbExecute(con, glue("DELETE FROM {level}_metric WHERE metric_seq = {s}"))
  s
}
written <- list()   # key -> rows written per level, re-read from the database at the end
write_zone <- function(d, key, desc, col = "val") {
  s <- mseq(key, desc, "zone")
  d <- d |> filter(!is.na(.data[[col]])) |> transmute(zone_seq, metric_seq = s, val = .data[[col]])
  if (nrow(d)) { duckdb_register(con, "tmp_zm", d); dbExecute(con, glue("INSERT INTO zone_metric SELECT * FROM tmp_zm")); duckdb_unregister(con, "tmp_zm") }
  written[[paste0("zone:", key)]] <<- nrow(d)
  nrow(d)
}
write_cell <- function(d, key, desc, col = "val") {
  s <- mseq(key, desc, "cell")
  d <- d |> filter(!is.na(.data[[col]])) |> transmute(cell_id, metric_seq = s, val = .data[[col]])
  duckdb_register(con, "tmp_cm", d); dbExecute(con, glue("INSERT INTO cell_metric SELECT * FROM tmp_cm")); duckdb_unregister(con, "tmp_cm")
  written[[paste0("cell:", key)]] <<- nrow(d)
  nrow(d)
}

if (share_metrics) {
  stopifnot("run build_taxon_global_total first (taxon_denom missing)" = "taxon_denom" %in% dbListTables(con))
  # v8's taxon has no er_mode and no model_cell_er: a temporary shadow carries them (main.taxon untouched,
  # as in build_taxon_global_total); is_er_spatial marks exactly the premultiplied sea turtles

    SELECT cm.cell_id, cm.val AS npp FROM cell_metric cm JOIN metric m USING (metric_seq) WHERE m.metric_key = 'primprod'")
  zones <- dbGetQuery(con, "SELECT zone_seq, fld, val AS zone_key FROM zone")

  runs <- c(setNames(as.list(denoms), denoms), list(global_alt = "global"))

      z <- r$zone |> filter(sp_cat == cat)

        write_zone(z, glue("extrisk_{cat}_mean_share_{sfx}"), glue("zone total divided by the number of {cat} species present ({d} denominator)"), "mean_share")
      if (nm == "global") n_written <- n_written +
        write_zone(z, glue("extrisk_{cat}_pct_world"), glue("percent of the world's risk-weighted {cat} importance in the zone"), "pct_world") +
        write_zone(z, glue("extrisk_{cat}_coverage"), glue("area-weighted fraction of the zone's cells carrying a scored {cat} species (reportable iff >= kappa)"), "coverage") +
        write_zone(z, glue("extrisk_{cat}_n_species"), glue("number of scored {cat} species with cells in the zone"), "n_species")
    }
    if (nm == "global") n_written <- n_written +
      write_zone(r$primprod, "primprod_v10", "v10 across the nation, primary productivity: 100 x the zone's area-weighted mean npp over the national mean; absent where coverage < kappa", "v10") +
      write_zone(r$primprod, "primprod_coverage", "area-weighted fraction of the zone's cells with a productivity value", "coverage")
    n_written <- n_written +
      write_zone(r$composite, glue("score_v10_equalweights_{sfx}"), glue("v10 composite: equal-weight mean of the reportable components ({LAB[[d]]})"), "score") +
      write_zone(r$composite, glue("score_v10_n_components_{sfx}"), "number of reportable components in the composite", "n_components")
    # cell rasters (headline denominators only) ----
    if (nm %in% cell_denoms) {
      for (cat in sp_cats) {
        cc <- r$cell |> filter(sp_cat == cat)
        n_written <- n_written +
          write_cell(cc, glue("extrisk_{cat}_share_{sfx}"), glue("per-cell sum of risk-weighted {LAB[[d]]}, {cat}"), "share") +
          write_cell(cc, glue("extrisk_{cat}_v10_{sfx}"), glue("v10 per cell, {cat}: 100 = the national average cell ({d} denominator)"), "v10")
      }
      # per-cell composite: the equal-weight mean of the components present in the cell, with the
      # productivity quotient as one more component (no coverage floor at cell level)
      comp_cell <- dbGetQuery(con, "SELECT cell_id, npp FROM primprod_cell") |>
        transmute(cell_id, v10 = 100 * npp / r$primprod$mean_usa[1]) |>
        bind_rows(r$cell |> select(cell_id, v10)) |>
        group_by(cell_id) |> summarise(val = mean(v10), .groups = "drop")
      n_written <- n_written + write_cell(comp_cell, glue("score_v10_equalweights_{sfx}"), glue("v10 composite per cell: equal-weight mean of the components present ({LAB[[d]]})"), "val")
    }
  }
  # zone_taxon: the per-species shares that explain a zone's score (treemap leaf = w x share) ----
  for (col in c("share_global", "share_usa", "share_v10_contrib"))
    if (!col %in% dbListFields(con, "zone_taxon")) dbExecute(con, glue("ALTER TABLE zone_taxon ADD COLUMN {col} DOUBLE"))

    transmute(zone_fld = fld, zone_value = zone_key, mdl_key = ms_merge_key, share_global, share_usa, share_v10_contrib = contrib)

  dbExecute(con, "UPDATE zone_taxon SET share_global = NULL, share_usa = NULL, share_v10_contrib = NULL")

    FROM tmp_zt t WHERE t.zone_fld = z.zone_fld AND t.zone_value = z.zone_value AND t.mdl_key = z.mdl_key")
  duckdb_unregister(con, "tmp_zt")
  log_info("zone_taxon: share columns set on {n_zt} rows ({share_denom} headline)")
  log_info("share family: {n_written} metric rows written")
  # what was written is what the database holds: every key re-read at its level
  held <- dbGetQuery(con, "SELECT 'zone:' || m.metric_key AS k, count(*) n FROM zone_metric zm JOIN metric m USING (metric_seq) GROUP BY 1
    UNION ALL SELECT 'cell:' || m.metric_key, count(*) FROM cell_metric cm JOIN metric m USING (metric_seq) GROUP BY 1")
  chk <- tibble(k = names(written), n_written = unlist(written)) |> left_join(held, by = "k") |> mutate(n = coalesce(n, 0L), ok = n == n_written)
  stopifnot("a written metric does not hold the rows written (a writer cleared another level's rows)" = all(chk$ok))
  stopifnot("the headline composite has no Program-Area rows" = held$n[held$k == glue("zone:score_v10_equalweights_{share_denom}")] >= 20)
  log_info("re-read check: {nrow(chk)} key x level pairs hold exactly the rows written")
} else log_info("SHARE_METRICS unset — control run: nothing written")

v10 adds **one scoring stage** to the v8 build and changes nothing upstream of it. The published
("within ecoregion") metrics of v8 — `extrisk_{cat}` → ecoregional min–max → equal-weight composite —
are kept in `cell_metric` / `zone_metric` unchanged and are the **control**: with `SHARE_METRICS=0`
this notebook writes nothing and only proves that the five scoring tables still digest to v8's
checkpoints. With `SHARE_METRICS=1` it adds the **"across the nation"** family of the method page
(*Sensitivity Across Regions*, 2026-09-11, rev 14; plan 2026-10-29 §2), computed by
`msens::share_run()` — the rule lives in `msens::share_sql()` and is asserted by `test-share.R`:

- `share_s,c = v_s,c · A_c / Σ_range(s) v · A` — each species' share of its WHOLE modelled range
  per cell (`taxon_denom`, built by `build_taxon_global_total`);
- `share_c,g = Σ_s w_s · share_s,c / 100` and `share_z,g = Σ_c share_c,g · p_zc` — risk-weighted,
  summed per category and zone;
- `v10_z,g = 100 · (share_z,g / share_USA,g) / (A_z / A_USA)` — a location quotient: **100 = the
  national average concentration**, the same reference for every area and component;
- `pct_world` (the percent of the world's risk-weighted importance at stake) and `pct_nation` beside
  it; a component is **reportable** only where its cells cover ≥ κ of the zone, else no score, never
  zero; `primprod_v10 = 100 · mean_z(npp) / mean_USA(npp)`; the composite is the equal-weight mean
  of the reportable components.

Three denominators are computed as columns (plan D2; `SHARE_DENOM` names the headline): `global`
(the species' whole range — the headline), `usa` (its US cells: Tim White's 2026-09-11 brief, the same
score with species weight `w` instead of `w · f_us`), `pooled` (no per-species normalization, the
RESA-style sum). The floored turtle cells are kept by default and stripped as a sensitivity column
(D4). Nothing here touches the v8 rows: the gate below digests them before and after.

## The share family (`SHARE_METRICS=1`)

`msens::share_run()` is called once per denominator (and once more for the floor-strip sensitivity
under the global denominator); each call returns the zone table, the per-cell table, the per-zone
per-species table and the composite, and asserts the rule's own invariants (a positive denominator
for every species, cell shares summing to 1 / `f_us`, the national pseudo-zone present). Inputs:
`taxon_denom` (from `build_taxon_global_total`), a temporary `taxon` shadow carrying `er_mode` for the v8
schema, an empty temporary `model_cell_er`, and `primprod_cell` from v8's own `primprod` metric. The
national reference is the study area (`cell.in_usa`), not the `USA` pseudo-zone (see `?msens::share_sql`).

```{r}
# being written. A metric key is shared by cell_metric and zone_metric by design (v8's

mseq <- function(key, desc = "", level = c("zone", "cell")) {
  level <- match.arg(level)
  ex <- dbGetQuery(con, glue("SELECT metric_seq FROM metric WHERE metric_key = '{key}'"))
  s  <- if (nrow(ex)) ex$metric_seq[1] else {
    s0 <- dbGetQuery(con, "SELECT coalesce(max(metric_seq),0)+1 s FROM metric")$s
    dbExecute(con, glue("INSERT INTO metric VALUES ({s0}, '{key}', '{gsub(\"'\",\"\",desc)}')")); s0 }
  dbExecute(con, glue("DELETE FROM {level}_metric WHERE metric_seq = {s}"))

}

      # productivity quotient as one more component (no coverage floor at cell level)
      comp_cell <- dbGetQuery(con, "SELECT cell_id, npp FROM primprod_cell") |>
        transmute(cell_id, v10 = 100 * npp / r$primprod$mean_usa[1]) |>
        bind_rows(r$cell |> select(cell_id, v10)) |>
        group_by(cell_id) |> summarise(val = mean(v10), .groups = "drop")
      n_written <- n_written + write_cell(comp_cell, glue("score_v10_equalweights_{sfx}"), glue("v10 composite per cell: equal-weight mean of the components present ({LAB[[d]]})"), "val")
    }
  }
  # zone_taxon: the per-species shares that explain a zone's score (treemap leaf = w x share) ----
  for (col in c("share_global", "share_usa", "share_v10_contrib"))
    if (!col %in% dbListFields(con, "zone_taxon")) dbExecute(con, glue("ALTER TABLE zone_taxon ADD COLUMN {col} DOUBLE"))
  zt <- results[[share_denom]]$zone_taxon |> inner_join(zones, by = "zone_seq") |>
    transmute(zone_fld = fld, zone_value = zone_key, mdl_key = ms_merge_key, share_global, share_usa, share_v10_contrib = contrib)
  duckdb_register(con, "tmp_zt", zt)
  dbExecute(con, "UPDATE zone_taxon SET share_global = NULL, share_usa = NULL, share_v10_contrib = NULL")
  n_zt <- dbExecute(con, "UPDATE zone_taxon z SET share_global = t.share_global, share_usa = t.share_usa, share_v10_contrib = t.share_v10_contrib
    FROM tmp_zt t WHERE t.zone_fld = z.zone_fld AND t.zone_value = z.zone_value AND t.mdl_key = z.mdl_key")
  duckdb_unregister(con, "tmp_zt")
  log_info("zone_taxon: share columns set on {n_zt} rows ({share_denom} headline)")
  log_info("share family: {n_written} metric rows written")
  # what was written is what the database holds: every key re-read at its level
  held <- dbGetQuery(con, "SELECT 'zone:' || m.metric_key AS k, count(*) n FROM zone_metric zm JOIN metric m USING (metric_seq) GROUP BY 1
    UNION ALL SELECT 'cell:' || m.metric_key, count(*) FROM cell_metric cm JOIN metric m USING (metric_seq) GROUP BY 1")
  chk <- tibble(k = names(written), n_written = unlist(written)) |> left_join(held, by = "k") |> mutate(n = coalesce(n, 0L), ok = n == n_written)
  stopifnot("a written metric does not hold the rows written (a writer cleared another level's rows)" = all(chk$ok))
  stopifnot("the headline composite has no Program-Area rows" = held$n[held$k == glue("zone:score_v10_equalweights_{share_denom}")] >= 20)
  log_info("re-read check: {nrow(chk)} key x level pairs hold exactly the rows written")
} else log_info("SHARE_METRICS unset — control run: nothing written")
```

Program Areas must hold the nation's turtle concentration, the Aleutian Arc almost none, St. George
Basin's turtles must not be reportable, Kemp's ridley must carry the Gulf's turtle column, the Arctic
