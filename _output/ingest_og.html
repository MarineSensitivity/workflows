v11 Q3: ensemble habitat suitability for the six sea turtles (and, when named, the right whale), fitted with the OBIS / MPA Europe SDM pipeline on the global05 grid

Published

2026-10-29

og is our own SDM, fitted with the OBIS / MPA Europe pipeline (iobis/mpaeu_sdm, our msens-patches branch) to the same global 0.05° grid the atlas uses. The fitted ensemble’s prediction for the present day (model=ogm, method=ensemble, scen=current) is a two-band COG per species:

  • band 1 current — the ensemble median habitat suitability, Byte 0–100 (probability × 100), NoData 255;
  • band 2 current_sd — the spread among the algorithms (not ingested here).

The grid is global05 exactly (7200 × 3600, −180..180, −90..90), up to a ~6e-6° float drift in the origin, so cell_id is the pixel index (asserted; no resample), as for AquaX.

What this notebook does, and does not do:

  1. Position map, val = band 1 as delivered. No rescale (already [0,100]); NoData 255 → NA. Cells with val ≥ 1 are kept (min_value = 1): a pixel at 0 is absent from the Parquet, the same threshold every suitability dataset gets. For a Byte raster that means the pixel’s probability is at least 1 %.
  2. Thresholds are recorded, not applied. thr_p10 (the ensemble’s training P10, from the model’s what=thresholds.parquet) and thr_heldout (the held-out threshold of _obis_range_constraint.qmd, scorecard table og_thr) go into model_og.csv. Values stay continuous; a footprint option (like AquaX’s cutoff) can use them later.
  3. The ingest does not depend on TURTLE_SUIT. The dataset must exist for the control (am) and the treatment (ogm) alike; the flag acts in merge_models_prep / merge_models.
  4. No COGs and no supersession here. publish_native.qmd paints and keys the COGs; which dataset a merge uses for a taxon is the merge’s job.
  5. Acceptance gate (a proposal). The ensemble’s evaluation AUC / TSS per species are printed against OG_AUC_MIN (0.80) and OG_TSS_MIN (0.60); a species below is warned about, not stopped. The floor is one of the three decisions the plan leaves open.

Species: env OG_SPECIES (comma-separated AphiaIDs), default the six sea turtles — loggerhead 137205, green 137206, hawksbill 137207, Kemp’s ridley 137208, leatherback 137209, olive ridley 220293. The North Atlantic right whale (159023) is plan item D9b: not in the default, but allowed when named. Other env: REDO_INGEST (rebuild dist/dataset=og/), OG_DIR (default ~/_big/sdm/og), OG_SCORECARD (default ~/_big/sdm/scorecard/ogm.duckdb), OG_AUC_MIN, OG_TSS_MIN. Runs on the laptop / Mac mini (the only hosts with the TIFs).

rc       <- rast(cellid_tif)
cell_ids <- values(rc, mat = FALSE)                                    # read ONCE (100 MB); reused below
stopifnot(
  "cell-id COG is not 7200 x 3600" = ncell(rc) == 7200 * 3600,
  "cell_id != pixel index on this grid — the position map does not hold" =
    all(cell_ids[!is.na(cell_ids)] == which(!is.na(cell_ids))))

inv <- map_dfr(og_ids, function(id) {
  f <- tif_of(id); r <- rast(f)
  g <- describe(f)
  must(identical(names(r), c("current", "current_sd")), glue("{id}: bands are not (current, current_sd)"))
  must(compareGeom(r, rc, stopOnError = FALSE, tolerance = 1e-3), glue("{id}: not the global05 grid (compareGeom vs cellid_tif)"))
  must(ncell(r) == 7200 * 3600, glue("{id}: ncell != 7200 x 3600"))
  must(any(str_detect(g, "Band 1 .*Type=Byte")), glue("{id}: band 1 is not Byte"))
  must(sum(str_detect(g, "NoData Value=255")) >= 1, glue("{id}: NoData is not 255"))
  v <- values(r[[1]], mat = FALSE)                                     # GDAL NoData 255 -> NA on read
  must(all(v[!is.na(v)] >= 0 & v[!is.na(v)] <= 100), glue("{id}: band 1 outside [0,100]"))
  tibble(sp_id = id, tif = f,
         n_px = length(v), n_nodata = sum(is.na(v)), pct_nodata = round(100 * mean(is.na(v)), 1),
         n_zero = sum(v == 0, na.rm = TRUE), n_ge1 = sum(v >= threshold, na.rm = TRUE),
         n_ge1_no_cellid = sum(!is.na(v) & v >= threshold & is.na(cell_ids)),
         src_max = max(v, na.rm = TRUE))
})

4 Species crosswalk → model_og.csv

mdl_key = og|{AphiaID}, worms_id = AphiaID (used directly by merge_models_prep, no match_taxa). Taxonomy from the WoRMS snapshot; sp_cat from msens::sp_cat_from_taxonomy() with is_turtle = WoRMS order Testudines (WoRMS leaves the turtles’ class empty). Thresholds are the model’s own: thr_p10 = the ensemble’s training P10 (what=thresholds.parquet, × 100) and thr_heldout = the held-out threshold of the scorecard (og_thr, [0,100]). Evaluation metrics are the ensemble’s, from data/og/cv_metrics.csv (origin = eval: the held-out evaluation records; cv: cross-validation).

pq_of <- \(sp) glue("{dir_dist}/{sp}.parquet")
todo  <- model_og |> select(sp_id, mdl_key) |> left_join(inv |> select(sp_id, tif), by = "sp_id")

t0 <- Sys.time()
for (i in which(!done)) {
  sp <- todo$sp_id[i]
  # band 1 only; val = probability x 100 as delivered (scale 1), pixels < 1 dropped, NoData 255 -> NA
  d  <- msens::cells_from_aligned_raster(rast(todo$tif[i], lyrs = 1), cell_ids, scale = 1, min_value = threshold)
  # write to a temp name then rename: a crash mid-write must not leave a truncated file that a
  # resumed run mistakes for done
  tmp <- glue("{pq_of(sp)}.tmp")
  msens::write_atlas_parquet(tibble(mdl_key = as.character(todo$mdl_key[i]), cell_id = d$cell_id, val = d$val), tmp)
  file_move(tmp, pq_of(sp))
  log_info("  {sp}: {nrow(d)} cells, val {min(d$val)}..{max(d$val)}")
}
log_info("ingest done in {round(as.numeric(Sys.time() - t0, units = 'mins'), 1)} min")

# ROUND TRIP, every species: re-rasterise the Parquet by pixel position and compare with the TIF.
# Pixels >= 1 must come back with the same value; every other pixel (0 or NoData) must be absent.
for (id in model_og$sp_id) {
  v <- values(rast(inv$tif[inv$sp_id == id], lyrs = 1), mat = FALSE)
  d <- dbGetQuery(con, glue("SELECT cell_id, val FROM read_parquet('{pq_of(id)}')"))
  w <- rep(NA_real_, length(v)); w[d$cell_id] <- d$val                   # cell_id == pixel index (asserted above)
  must(isTRUE(all.equal(w[!is.na(v) & v >= threshold], v[!is.na(v) & v >= threshold])),
       glue("{id}: round-trip mismatch — Parquet re-rasterised != TIF band 1 where >= 1"))
  must(all(is.na(w[is.na(v) | v < threshold])), glue("{id}: Parquet has cells where the TIF is 0 / NoData"))
}

7 Acceptance gate (proposed floor)

The plan leaves the floor open; this prints the ensemble’s held-out evaluation AUC and TSS (at the training P10) beside OG_AUC_MIN = 0.8 and OG_TSS_MIN = 0.6 and warns, does not stop, on any species below. CBI and the cross-validation figures are shown for context (a species that passes on evaluation but fails on cross-validation is warned about separately). n_eval is small (about 11–24 held-out records per species), so a single metric is a coarse judge.

`og` is **our own SDM**, fitted with the OBIS / MPA Europe pipeline (`iobis/mpaeu_sdm`, our
`msens-patches` branch) to the same global 0.05° grid the atlas uses. The fitted ensemble's
prediction for the present day (`model=ogm`, `method=ensemble`, `scen=current`) is a two-band
COG per species:

- band 1 `current` — the ensemble **median** habitat suitability, **Byte 0–100** (probability × 100),
  NoData 255;
- band 2 `current_sd` — the spread among the algorithms (not ingested here).

The grid is `global05` exactly (7200 × 3600, −180..180, −90..90), up to a ~6e-6° float drift in the
origin, so `cell_id` is the **pixel index** (asserted; no resample), as for AquaX.

What this notebook does, and does not do:

1. **Position map, `val` = band 1 as delivered.** No rescale (already [0,100]); NoData 255 → NA.
   Cells with `val ≥ 1` are kept (`min_value = 1`): a pixel at 0 is **absent** from the Parquet, the
   same threshold every suitability dataset gets. For a Byte raster that means the pixel's
   probability is at least 1 %.
2. **Thresholds are recorded, not applied.** `thr_p10` (the ensemble's training P10, from the
   model's `what=thresholds.parquet`) and `thr_heldout` (the held-out threshold of
   `_obis_range_constraint.qmd`, scorecard table `og_thr`) go into `model_og.csv`. Values stay
   continuous; a footprint option (like AquaX's cutoff) can use them later.
3. **The ingest does not depend on `TURTLE_SUIT`.** The dataset must exist for the control (`am`) and
   the treatment (`ogm`) alike; the flag acts in `merge_models_prep` / `merge_models`.
4. **No COGs and no supersession here.** `publish_native.qmd` paints and keys the COGs; which dataset
   a merge uses for a taxon is the merge's job.
5. **Acceptance gate (a proposal).** The ensemble's evaluation AUC / TSS per species are printed against
   `OG_AUC_MIN` (0.80) and `OG_TSS_MIN` (0.60); a species below is **warned about, not stopped**. The floor
   is one of the three decisions the plan leaves open.

Species: env `OG_SPECIES` (comma-separated AphiaIDs), default the six sea turtles — loggerhead 137205, green
137206, hawksbill 137207, Kemp's ridley 137208, leatherback 137209, olive ridley 220293. The North
Atlantic right whale (159023) is plan item D9b: **not** in the default, but allowed when named. Other
env: `REDO_INGEST` (rebuild `dist/dataset=og/`), `OG_DIR` (default `~/_big/sdm/og`), `OG_SCORECARD`
(default `~/_big/sdm/scorecard/ogm.duckdb`), `OG_AUC_MIN`, `OG_TSS_MIN`. Runs on the **laptop / Mac mini**
(the only hosts with the TIFs).

## Acceptance gate (proposed floor)

The plan leaves the floor open; this prints the ensemble's **held-out evaluation** AUC and TSS (at the
training P10) beside `OG_AUC_MIN` = `r og_auc_min` and `OG_TSS_MIN` = `r og_tss_min` and **warns, does not stop**,
on any species below. CBI and the cross-validation figures are shown for context (a species that passes on evaluation but fails on cross-validation is warned about separately). `n_eval` is small
(about 11–24 held-out records per species), so a single metric is a coarse judge.

```{r}

  transmute(mdl_key, common_name, n_fit, n_eval = n_eval_eval, auc_eval, cbi_eval, tss_eval, auc_cv, tss_cv,

            pass_tss = !is.na(tss_eval) & tss_eval >= og_tss_min,
            pass = pass_auc & pass_tss,
            pass_cv = !is.na(auc_cv) & !is.na(tss_cv) & auc_cv >= og_auc_min & tss_cv >= og_tss_min)   # context only: not part of the gate
kable(gate, caption = glue("Ensemble evaluation metrics vs the proposed floor (AUC >= {og_auc_min}, TSS >= {og_tss_min})"))
for (i in which(!gate$pass))
  log_warn("{gate$mdl_key[i]} ({gate$common_name[i]}) is BELOW the proposed floor: eval AUC {gate$auc_eval[i]} (min {og_auc_min}), eval TSS {gate$tss_eval[i]} (min {og_tss_min})")
# cross-validation is the harsher judge for a thinly fitted species (Kemp's ridley: 155 fit points); say so
for (i in which(gate$pass & !gate$pass_cv))
  log_warn("{gate$mdl_key[i]} ({gate$common_name[i]}) passes on held-out evaluation but its CROSS-VALIDATION is below the floor: AUC {gate$auc_cv[i]}, TSS {gate$tss_cv[i]} (n_fit {gate$n_fit[i]})")
log_info("acceptance gate: {sum(gate$pass)} of {nrow(gate)} species at or above the proposed floor")
```
