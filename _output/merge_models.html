Merge models — combine each taxon’s models per cell (max-merge + range mask; turtles ×)

  • Show All Code
  • Hide All Code
  • View Source
Published

2026-07-14 08:36:07

Combine every taxon’s per-dataset models into one merged model_cell (mdl_key = ms_merge|WORMS:… / BOTW:…), reproducing v7’s logic at the v8 global scale (~13B am cell-rows), so it must stream + spill rather than materialize:

  • Default = max-merge, masked to the range footprint. A taxon’s merged cells are its range cells if it has any (rng_*/ch_*/ca_*/bl), else its full am footprint; at each kept cell val = max across the taxon’s models. Streamed straight to Parquet via a single COPY (one grouped scan), so no 13B-row table.
  • Turtles = multiplicative. val = pmax(1, round(er × suit / 100)) with critical-habitat max-override — computed from only the 6 turtle taxa’s files (never a full am scan, which is what OOM’d the naive version).

# A single GROUP BY over the dense am produces ~600M near-unique (taxon,cell) groups
# that won't fit even spilling. Decompose so we NEVER group dense am:
#   Part 1 am-only taxa  -> stream cells (dense, but no aggregate)
#   Part 2 range-only    -> group-by (sparse ranges, small)
#   Part 3 both (am+range) -> range footprint + am AT those cells via JOIN (no am group)
#   Part 4 turtles        -> mc_turtle (done)
dbExecute(con, "CREATE OR REPLACE TABLE taxon_flags AS
  SELECT ms_merge_key, bool_or(ds_key='am') AS has_am, bool_or(ds_key<>'am') AS has_range
  FROM model_cell_all GROUP BY ms_merge_key")

Combine every taxon's per-dataset models into one **merged `model_cell`**
(`mdl_key = ms_merge|WORMS:…` / `BOTW:…`), reproducing v7's logic at the v8 global
scale (~13B am cell-rows), so it must stream + spill rather than materialize:

- **Default = max-merge, masked to the range footprint.** A taxon's merged cells are
  its **range** cells if it has any (`rng_*`/`ch_*`/`ca_*`/`bl`), else its full `am`
  footprint; at each kept cell `val = max` across the taxon's models. Streamed
  straight to Parquet via a single `COPY` (one grouped scan), so no 13B-row table.
- **Turtles = multiplicative.** `val = pmax(1, round(er × suit / 100))` with
  critical-habitat max-override — computed from **only the 6 turtle taxa's files**
  (never a full am scan, which is what OOM'd the naive version).

## Max-merge (masked) + turtles → streamed to Parquet

```{r}
#| label: merge_write

# A single GROUP BY over the dense am produces ~600M near-unique (taxon,cell) groups
# that won't fit even spilling. Decompose so we NEVER group dense am:
#   Part 1 am-only taxa  -> stream cells (dense, but no aggregate)
#   Part 2 range-only    -> group-by (sparse ranges, small)
#   Part 3 both (am+range) -> range footprint + am AT those cells via JOIN (no am group)
#   Part 4 turtles        -> mc_turtle (done)
dbExecute(con, "CREATE OR REPLACE TABLE taxon_flags AS
  SELECT ms_merge_key, bool_or(ds_key='am') AS has_am, bool_or(ds_key<>'am') AS has_range
  FROM model_cell_all GROUP BY ms_merge_key")

if (dir_exists(dir_merged)) dir_delete(dir_merged)
dir_create(dir_merged)

# Part 1: am-only taxa -> stream US am cells directly (no aggregate)
msens::copy_atlas_parquet(con,
  "SELECT mc.ms_merge_key AS mdl_key, mc.cell_id, mc.val FROM model_cell_all mc
    WHERE mc.ms_merge_key IN (SELECT ms_merge_key FROM taxon_flags WHERE has_am AND NOT has_range)",
  glue("{dir_merged}/p_amonly"), per_thread = TRUE)

# ER RECONCILIATION (the "fitting point"): a range presence cell carries the taxon's
# GOVERNING er_score (US-national/floored, from merge_models_prep) — NOT the raw
# per-dataset source ER the ingest layer held. So Part 2/3 val the range footprint
# by taxon.er_score, matching v7. (Turtles keep their spatially-varying DPS ER surface.)

# Part 2: range-only taxa -> governing er_score over their range footprint
dbExecute(con, glue("CREATE OR REPLACE TABLE mc_rangeonly AS
    SELECT DISTINCT mc.ms_merge_key AS mdl_key, mc.cell_id, t.er_score::DOUBLE AS \"val\"
    FROM model_cell_all mc JOIN taxon t ON mc.ms_merge_key = t.ms_merge_key
    WHERE mc.ms_merge_key IN (SELECT ms_merge_key FROM taxon_flags WHERE has_range AND NOT has_am)
      AND mc.ms_merge_key NOT IN ({tkeys_sql})"))

# Part 3: both taxa -> range footprint (er), then am AT those cells via a join that
# builds the small range set and probes am (never a dense-am group-by)
dbExecute(con, glue("CREATE OR REPLACE TABLE both_range AS
    SELECT DISTINCT mc.ms_merge_key, mc.cell_id, t.er_score AS er
    FROM model_cell_all mc JOIN taxon t ON mc.ms_merge_key = t.ms_merge_key
    WHERE mc.ms_merge_key IN (SELECT ms_merge_key FROM taxon_flags WHERE has_am AND has_range)
      AND mc.ds_key <> 'am' AND mc.ms_merge_key NOT IN ({tkeys_sql})"))
dbExecute(con, "CREATE OR REPLACE TABLE both_am AS
    SELECT am.ms_merge_key, am.cell_id, max(am.val) am_value
    FROM model_cell_all am JOIN both_range br USING (ms_merge_key, cell_id)
    WHERE am.ds_key='am' GROUP BY am.ms_merge_key, am.cell_id")
dbExecute(con, "CREATE OR REPLACE TABLE mc_both AS
    SELECT br.ms_merge_key AS mdl_key, br.cell_id,
           greatest(br.er, coalesce(ba.am_value, 0))::DOUBLE AS \"val\"
    FROM both_range br LEFT JOIN both_am ba USING (ms_merge_key, cell_id)")
log_info("range-only {dbGetQuery(con,'SELECT count(*) n FROM mc_rangeonly')$n}, both {dbGetQuery(con,'SELECT count(*) n FROM mc_both')$n} cells")

# write parts 2+3+turtles alongside the streamed part 1
msens::copy_atlas_parquet(con,
  "SELECT mdl_key, cell_id, val FROM mc_rangeonly
    UNION ALL SELECT mdl_key, cell_id, val FROM mc_both
    UNION ALL SELECT mdl_key, cell_id, val FROM mc_turtle",
```
