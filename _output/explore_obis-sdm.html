1 Why

AquaMaps 2.0 (the AquaX pipeline, ingested as ax in v9) cannot be redistributed: the FishBase consortium keeps the rasters, and BOEM-funded products are expected to be open. OBIS’s MPA Europe contribution (iobis/mpaeu_sdm, docs at iobis.github.io/mpaeu_docs) is a fully open alternative: an ensemble SDM framework (obissdm, Maxent + random forest + XGBoost; “ESM” ensembles of small models for 10–29 records) fitted on global OBIS + GBIF occurrences and predicted to the whole globe on exactly our global05 grid (7200 × 3600, 0.05°, −180..180), published as COGs on s3://obis-maps/sdm/species/taxonid={AphiaID}/ with a STAC catalogue.

This notebook answers three questions with numbers, all reproducible from public sources plus the local OBIS snapshot:

  1. What species coverage does the OBIS/MPA Europe SDM set give us compared to AquaMaps 1.0 (am) and 2.0 (ax)?
  2. What is the minimum number of OBIS records the framework needs, and how many US species clear it (so the same framework could fill the gaps)?
  3. Does an OBIS model clipped to the IUCN range (our merge rule) look like AquaX? (walrus test)

4 Walrus test: OBIS ensemble vs IUCN range vs AquaX

The OBIS models are predicted to the whole globe and only carry a marine-realm mask (native_ecoregions = Costello realms with records), which for the walrus admits most of the US Pacific. Our merge rule masks suitability to the range dataset, so the useful comparison is the OBIS surface inside the IUCN range against AquaX.

## Why

AquaMaps 2.0 (the AquaX pipeline, ingested as `ax` in v9) cannot be redistributed: the FishBase
consortium keeps the rasters, and BOEM-funded products are expected to be open. OBIS's MPA Europe
contribution ([iobis/mpaeu_sdm](https://github.com/iobis/mpaeu_sdm), docs at
[iobis.github.io/mpaeu_docs](https://iobis.github.io/mpaeu_docs/)) is a fully open alternative: an
ensemble SDM framework (`obissdm`, Maxent + random forest + XGBoost; "ESM" ensembles of small models
for 10–29 records) fitted on **global** OBIS + GBIF occurrences and predicted to the **whole globe on
exactly our `global05` grid** (7200 × 3600, 0.05°, −180..180), published as COGs on
`s3://obis-maps/sdm/species/taxonid={AphiaID}/` with a STAC catalogue.

This notebook answers three questions with numbers, all reproducible from public sources plus the
local OBIS snapshot:

1. What species coverage does the OBIS/MPA Europe SDM set give us compared to AquaMaps 1.0 (`am`) and
   2.0 (`ax`)?
2. What is the minimum number of OBIS records the framework needs, and how many US species clear it
   (so the same framework could fill the gaps)?
3. Does an OBIS model clipped to the IUCN range (our merge rule) look like AquaX? (walrus test)

the standard model and `model_species_esm.R` sets `minptslim <- 10` for the ensemble-of-small-models
path; a model is kept when its cross-validated continuous Boyce index is ≥ 0.3
(`codes/model_fit.R`: `tg_metric <- "cbi"; tg_threshold <- 0.3`). The published species list
(`sdm_list_iss_cons_20250903.csv`) records the outcome per species.

## OBIS occurrences onto the 0.05° cell grid

Species-rank records (`speciesid` = accepted WoRMS AphiaID) are binned to the `global05` cell whose
pixel index is `cell_id` (asserted against the `cell` table), then joined to `in_usa`.

```{r}
#| label: obis-grid
con <- dbConnect(duckdb(), obis_grid_db)
dbExecute(con, glue("attach '{sdm_db}' as sdm (read_only)"))
occ_sql <- if (file_exists(obis_occ) && !is_dir(obis_occ)) {
  dbExecute(con, glue("attach '{obis_occ}' as ob (read_only)")); "ob.occ"
} else {
  glue("read_parquet('{obis_occ}/*.parquet')")
}
if (!"occ_cell" %in% dbListTables(con)) {
  dbExecute(con, glue("
    create table occ_cell as
    select speciesid::int aphia, any_value(species) species, any_value(phylum) phylum, any_value(\"class\") \"class\",
      (floor((90 - decimalLatitude)/0.05)::bigint * 7200 + floor((decimalLongitude+180)/0.05)::bigint + 1) cell_id,
      count(*) records, min(date_year) min_year, max(date_year) max_year
    from {occ_sql}
    where speciesid is not null and decimalLongitude is not null and decimalLatitude is not null
    group by 1, 5"))
}
# the pixel-index formula must reproduce cell_id exactly
chk <- dbGetQuery(con, "select count(*) n, sum((cell_id = floor((90 - lat)/0.05)::bigint * 7200 + floor((lon+180)/0.05)::bigint + 1)::int) n_ok from sdm.cell")
stopifnot(chk$n == chk$n_ok)

dbExecute(con, "create or replace table occ_usa as select o.* from occ_cell o join sdm.cell c using (cell_id) where c.in_usa")
dbExecute(con, glue("
  create or replace table spp as
  with g as (select aphia, any_value(species) species, any_value(phylum) phylum, any_value(\"class\") \"class\",
               sum(records) rec_global, count(*) cells_global from occ_cell group by 1),
       u as (select aphia, sum(records) rec_usa, count(*) cells_usa, min(min_year) min_year_usa, max(max_year) max_year_usa
             from occ_usa group by 1),
       v as (select try_cast(replace(t.taxon_id,'WORMS:','') as int) aphia, t.is_valid_usa, t.sp_cat,
               bool_or(m.ds_key='am') has_am, bool_or(m.ds_key='ax') has_ax, bool_or(m.ds_key like 'rng%') has_rng
             from sdm.taxon t left join sdm.taxon_model tm using (taxon_id) left join sdm.model m using (mdl_key)
             where t.taxon_authority='worms' group by all),
       b as (select distinct scientific_name from sdm.taxon where taxon_authority='botw'),
       mp as (select taxonID aphia, SDM mp_sdm, SDMinfo mp_info, availableRecords mp_rec from read_csv('{mp_list_csv}'))
  select g.*, coalesce(u.rec_usa,0) rec_usa, coalesce(u.cells_usa,0) cells_usa, u.min_year_usa, u.max_year_usa,
    v.aphia is not null in_v9, coalesce(v.is_valid_usa,false) is_valid_usa, v.sp_cat,
    coalesce(v.has_am,false) has_am, coalesce(v.has_ax,false) has_ax, coalesce(v.has_rng,false) has_rng,
    (g.\"class\" = 'Aves' or b.scientific_name is not null) is_bird,
    mp.mp_sdm, mp.mp_info, mp.mp_rec
  from g left join u using (aphia) left join v using (aphia)
    left join b on b.scientific_name = g.species left join mp using (aphia)"))
q <- \(sql) dbGetQuery(con, sql)
q("select count(*) n_spp, sum(rec_global) records, count(*) filter (where rec_usa>0) n_spp_usa, sum(rec_usa) records_usa from spp") |>
  kable(caption = "OBIS snapshot: species-rank records, globally and inside in_usa cells")
```

## Walrus test: OBIS ensemble vs IUCN range vs AquaX

The OBIS models are predicted to the whole globe and only carry a marine-realm mask
(`native_ecoregions` = Costello realms with records), which for the walrus admits most of the US
Pacific. Our merge rule masks suitability to the range dataset, so the useful comparison is the OBIS
surface inside the IUCN range against AquaX.

```{r}
#| label: walrus
aphia_w <- 137077   # Odobenus rosmarus
u <- glue("https://obis-maps.s3.amazonaws.com/sdm/species/taxonid={aphia_w}/model=mpaeu")
d_w <- glue("{dir_obismap}/taxonid={aphia_w}"); dir_create(d_w)
get <- \(rel, f) { p <- glue("{d_w}/{f}"); if (!file_exists(p)) download.file(glue("{u}/{rel}"), p, quiet = T, mode = "wb"); p }
f_ens  <- get(glue("predictions/taxonid={aphia_w}_model=mpaeu_method=ensemble_scen=current_cog.tif"), "ensemble_current.tif")
f_mask <- get(glue("predictions/taxonid={aphia_w}_model=mpaeu_what=mask_cog.tif"), "mask.tif")
f_thr  <- get(glue("metrics/taxonid={aphia_w}_model=mpaeu_what=thresholds.parquet"), "thresholds.parquet")
f_log  <- get(glue("taxonid={aphia_w}_model=mpaeu_what=log.json"), "log.json")
lg  <- fromJSON(f_log)
thr <- read_parquet(f_thr); p10 <- thr$p10[thr$model == "ensemble"] * 100
r   <- rast(f_ens); m <- rast(f_mask)
stopifnot(ncol(r) == 7200, nrow(r) == 3600, max(abs(as.vector(ext(r)) - c(-180, 180, -90, 90))) < 1e-4)
v <- values(r[[1]])[, 1]; mv <- values(m)

D <- glue("{dir_big_v}/marine-atlas/dist")
iucn <- q(glue("select cell_id from read_parquet('{D}/dataset=rng_iucn/*.parquet', hive_partitioning=false) where mdl_key = 'rng_iucn|15106'"))$cell_id
axd  <- q(glue("select cell_id, val from read_parquet('{D}/dataset=ax/*.parquet', hive_partitioning=false) where mdl_key = 'ax|{aphia_w}'"))
amd  <- q(glue("select cell_id, val from read_parquet('{D}/dataset=am/*.parquet', hive_partitioning=false) where mdl_key = 'am|ITS-Mam-180639'"))
usa  <- q("select cell_id from sdm.cell where in_usa")$cell_id
in_iucn <- usa %in% iucn; in_ax <- usa %in% axd$cell_id; in_am <- usa %in% amd$cell_id
ens <- v[usa]
r_shared <- \(d, sel) cor(ens[sel & !is.na(ens)], setNames(d$val, d$cell_id)[as.character(usa[sel & !is.na(ens)])])
jacc <- \(a, b) sum(a & b) / sum(a | b)
obis_p10 <- !is.na(ens) & ens >= p10
tibble(
  fit_points = unlist(lg$model_fit_points), good_models = paste(unlist(lg$model_good), collapse = "+"), p10 = p10,
  us_cells_iucn = sum(in_iucn), us_cells_am = sum(in_am), us_cells_ax = sum(in_ax),
  am_cells_outside_iucn = sum(in_am & !in_iucn), ax_cells_outside_iucn = sum(in_ax & !in_iucn),
  us_cells_obis_gt0 = sum(ens > 0, na.rm = T), us_cells_obis_ge_p10 = sum(obis_p10),
  obis_ge_p10_in_iucn = sum(obis_p10 & in_iucn),
  obis_ge_p10_in_native_realm = sum(obis_p10 & mv[usa, "native_ecoregions"] == 1, na.rm = T),
  jaccard_obis_p10_vs_am = jacc(obis_p10, in_am), jaccard_obis_p10_vs_ax = jacc(obis_p10, in_ax),
  r_obis_vs_am_shared = r_shared(amd, in_am), r_obis_vs_ax_shared = r_shared(axd, in_ax),
  r_am_vs_ax_shared = cor(setNames(amd$val, amd$cell_id)[as.character(usa[in_am & in_ax])], setNames(axd$val, axd$cell_id)[as.character(usa[in_am & in_ax])])) |>
  t() |> kable(caption = "Walrus: OBIS ensemble (current) in US cells vs IUCN range, AquaMaps 1.0 (am) and AquaMaps 2.0 (ax)")
dbDisconnect(con, shutdown = T)
```

Reading: unmasked, the OBIS walrus surface is nonzero over most US cells; at its own P10 threshold it
shrinks to the Bering/Chukchi and almost entirely inside the IUCN range. Against AquaMaps 1.0 the
question is improvement (the trapezoid envelope over-predicts outside the range); against AquaMaps 2.0
it is agreement on the shared cells. The realm mask is not a substitute for the range mask.
