Published

2026-10-14

v7.2 is a second surgical patch of the public v7 release — same usa05 grid, same mdl_seq/value schema, same 20 Program Areas — built exactly as v7.1 (build_v7b.qmd) was: clone v7’s DuckDB copy-on-write, change only the merged models the rules touch under their EXISTING mdl_seq, then re-execute v7’s own scoring chunks verbatim. It supersedes v7.1 for review. Three rules, nothing else:

  1. Turtle record rule. A sea-turtle species is dropped from an ecoregion where it has never been recorded in any observational channel (NOAA Alaska sightings, strandings and bycatch 1963–2020, OBIS, GBIF incl. iNaturalist, WDFW, STSSN). On v7 that is the East Bering Sea for loggerhead, green, leatherback and olive ridley; the Gulf of Alaska, where all four are recorded, keeps them at their v7 values. v7.1’s suitability threshold (P ≥ 0.5, floor-of-1 fill dropped) is NOT carried: v7’s turtle models are kept exactly as they are everywhere the record rule does not reach, because the threshold removed loggerhead, green and olive ridley from the Gulf of Alaska where all three have been recorded.
  2. Right whale Gulf rule. The North Atlantic right whale (mdl_seq 54252) is dropped from the two Gulf of America ecoregions (EGOA, WCGOA), outside its range.
  3. Coverage floor κ = 5 %, carried from v7.1 unchanged (msens::coverage_sql() / coverage_floor()): a Program-Area component whose scored cells cover < 5 % of the area is not reportable — no row, never a zero.

Rules 1 and 2 are one mechanism: a taxon × ecoregion exclusion read from the evidence table data/v7c/zone_exclusions.csv, written and justified by build_v7c_exclusions.qmd, and applied by msens::zone_exclude_sql(). A cell belongs to the ecoregion covering most of it (msens::cell_zone_major_sql()), and critical habitat is never excluded: a cell the taxon holds under a designated ch_* / ca_* dataset survives inside an excluded ecoregion. The notebook asserts that the cells it removes per (model, ecoregion) are exactly the evidence table’s n_cells_v7.

Each rule is a flag whose control value is off, so the same code path reproduces v7 exactly. That is the first gate below, and it is what makes every other number here attributable.

Not in v7.2: productivity, the distribution-share / national score, anything of v10. Every primprod* row of v7c must equal v7’s, and a gate asserts it in every run.

get_chunk <- function(label) {
  lab <- grep(glue("^#\\|\\s*label:\\s*{label}\\s*$"), qmd_lines)
  stopifnot("chunk label not found exactly once in old/calc_scores_v7.qmd" = length(lab) == 1)

  code  <- qmd_lines[(open + 1):(close - 1)]
  paste(code[!grepl("^#\\|", code)], collapse = "\n")
}

# `IUCN:TN` is a v1-v7 data artifact: an ESA "Threatened" code stamped with the IUCN
# authority, on 11 taxa (1 mammal -- the Arctic ringed seal -- and 10 birds). The msens that
# built v7 did not validate the code, so it fell through `score_iucn`'s `.default = 1L` and
# scored **1**; that is what `taxon.er_score` still stores for all 11. msens >= 0.19 ERRORS
# on it, which stops `calc_cell_metric_redlist` dead. Reproducing v7 means reproducing that
# 1 -- recoding those taxa is a data question, and it belongs to v10, not to a patch that
# must reproduce its predecessor exactly. The IUCN branch also ignores `is_mmpa` (the same
# documented quirk that made `IUCN:LC + MMPA` score 1); that too is v7's behavior and stays.
ER_LEGACY <- c("IUCN:TN" = 1L)
er_score_v7 <- function(extrisk_code, is_mmpa = FALSE, is_mbta = FALSE) {
  n   <- length(extrisk_code)
  out <- rep(NA_integer_, n)
  leg <- !is.na(extrisk_code) & extrisk_code %in% names(ER_LEGACY)
  if (any(leg))  out[leg]  <- unname(ER_LEGACY[extrisk_code[leg]])
  if (any(!leg)) out[!leg] <- msens::compute_er_score(
    extrisk_code[!leg],
    is_mmpa = rep_len(is_mmpa, n)[!leg],
    is_mbta = rep_len(is_mbta, n)[!leg])
  out
}

# copy-on-write clone: APFS `cp -c` on the laptop, `cp --reflink=auto` on Linux. A 3.6 GB
# release database clones in milliseconds and only the pages the patch rewrites cost space.
clone_db <- function(src, dst) {
  if (file_exists(dst))               file_delete(dst)
  if (file_exists(glue("{dst}.wal"))) file_delete(glue("{dst}.wal"))
  dir_create(path_dir(dst))
  flag <- if (is_server) "--reflink=auto" else "-c"
  rc   <- system2("cp", c(flag, shQuote(src), shQuote(dst)))
  stopifnot("copy-on-write clone failed" = identical(as.integer(rc), 0L))
  log_info("cloned {src} -> {dst}")
}

# the record rule: DELETE the evidence table's (model x ecoregion) cells under the EXISTING
# merged ids. Re-merging would RENUMBER mdl_seq and break every published ?mdl_seq= deep link;
# a delete leaves every surviving cell at its v7 value, which is the point -- outside the
# excluded ecoregions the species is exactly v7's.
apply_exclusions <- function(con, excl, label) {
  if (!nrow(excl)) {
    log_info("[{label}] no exclusion applied -- the merged models stay v7's")
    return(invisible(tibble(mdl_seq = integer(), zone_key = character(),
                            n_cells_v7 = integer(), n_deleted = integer())))
  }
  seqs    <- sort(unique(excl$mdl_seq))
  seq_sql <- paste(seqs, collapse = ", ")
  stopifnot("an exclusion names a model outside v7's six turtles and the right whale" =
    all(seqs %in% c(MDL_TURTLE_V7, MDL_WHALE)))

  # each cell's ONE ecoregion: the one covering most of it (1,125 cells straddle two)
  dbExecute(con, glue(
    "CREATE OR REPLACE TEMP TABLE cell_zone AS {msens::cell_zone_major_sql('ecoregion_key')}"))

  # critical habitat is never excluded: the cells each excluded taxon carries under any
  # designation dataset (ch_* / ca_*), keyed by the taxon's MERGED mdl_seq. A table, not a
  # view: it reads model_cell, which the delete below changes.
  dbExecute(con, glue(
    "CREATE OR REPLACE TEMP TABLE ch_src AS
     SELECT DISTINCT t.mdl_seq, mc.cell_id
     FROM taxon t
     JOIN taxon_model tm ON tm.taxon_id = t.taxon_id
     JOIN model_cell  mc ON mc.mdl_seq  = tm.mdl_seq
     WHERE t.mdl_seq IN ({seq_sql})
       AND (tm.ds_key LIKE 'ch\\_%' ESCAPE '\\' OR tm.ds_key LIKE 'ca\\_%' ESCAPE '\\')"))

  # materialize the rows to delete, so the count per (model, ecoregion) is asserted against
  # the evidence table BEFORE anything is removed
  sql <- msens::zone_exclude_sql(
    excl |> select(mdl_seq, zone_key),
    src = "model_cell", cell_zone = "cell_zone", ch_src = "ch_src")
  dbExecute(con, glue("CREATE OR REPLACE TEMP TABLE excl_del AS {sql}"))

  d_n <- dbGetQuery(con,
    "SELECT d.mdl_seq, cz.zone_key, count(*) AS n_deleted
     FROM excl_del d JOIN cell_zone cz USING (cell_id) GROUP BY ALL")
  d_chk <- excl |>
    select(mdl_seq, zone_key, n_cells_v7) |>
    left_join(d_n |> mutate(mdl_seq = as.integer(mdl_seq)), by = c("mdl_seq", "zone_key")) |>
    mutate(n_deleted = coalesce(as.integer(n_deleted), 0L))
  stopifnot(
    "cells selected per (mdl_seq, ecoregion) must equal the evidence table's n_cells_v7 exactly" =
      all(d_chk$n_deleted == d_chk$n_cells_v7),
    "the exclusion selected cells outside the evidence table's (mdl_seq, ecoregion) pairs" =
      sum(d_n$n_deleted) == sum(d_chk$n_deleted))

  n <- dbExecute(con,
    "DELETE FROM model_cell WHERE (mdl_seq, cell_id) IN (SELECT mdl_seq, cell_id FROM excl_del)")
  stopifnot("DELETE removed a different number of rows than the exclusion selected" =
    n == sum(d_chk$n_cells_v7))

  # the rule, stated on the model it changed; idempotent (any previous v7.2 clause is stripped)
  d_z <- excl |> group_by(mdl_seq) |>
    summarize(zones = paste(sort(zone_key), collapse = ", "), .groups = "drop")
  for (i in seq_len(nrow(d_z)))
    dbExecute(con, glue(
      "UPDATE model SET description =
         regexp_replace(coalesce(description, ''), ' \\| v7\\.2 record rule.*$', '') ||
         ' | v7.2 record rule: excluded from {d_z$zones[i]}'
       WHERE mdl_seq = {d_z$mdl_seq[i]}"))

  log_info("[{label}] excluded {format(n, big.mark = ',')} cells: ",
           "{paste(glue('{d_chk$mdl_seq} x {d_chk$zone_key} = {d_chk$n_deleted}'), collapse = '; ')}")
  invisible(d_chk)
}

# kappa: a ZONE reporting rule. Cell-level rasters are untouched; only the Program-Area
# component row of a pair below the floor is deleted (its raw and _prepctareaweighting rows
# stay, so the diagnostic remains readable), and the composite then averages one fewer
# component -- exactly as it already does for an area with no turtles at all.
apply_kappa <- function(con, tbl_pra, component_keys, kappa, f_csv) {
  if (is.na(kappa) || kappa <= 0) {
    log_info("COVERAGE_FLOOR off -- no _coverage metrics written, no component dropped")
    return(invisible(NULL))
  }
  d <- dbGetQuery(con, msens::coverage_sql(
        tbl_pra, component_keys, weight = "pct_covered",
        val_col = msens::sdm_val_col(con, "cell_metric"))) |>
    msens::coverage_floor(kappa = kappa)

  z_seqs <- dbGetQuery(con, glue(
    "SELECT zone_seq FROM zone WHERE tbl = '{tbl_pra}'"))$zone_seq
  z_sql  <- paste(z_seqs, collapse = ", ")

  for (k in component_keys) {
    k_cov <- glue("{k}_coverage")
    if (!nrow(dbGetQuery(con, glue("SELECT 1 FROM metric WHERE metric_key = '{k_cov}'"))))
      dbExecute(con, glue(
        "INSERT INTO metric (metric_key, description) VALUES
         ('{k_cov}', 'Percent of the zone covered by cells carrying {k} (coverage floor input)')"))
    s_cov <- dbGetQuery(con, glue(
      "SELECT metric_seq FROM metric WHERE metric_key = '{k_cov}'"))$metric_seq
    dbExecute(con, glue(
      "DELETE FROM zone_metric WHERE metric_seq = {s_cov} AND zone_seq IN ({z_sql})"))
    dd <- d |> filter(metric_key == k)
    if (nrow(dd))
      dbExecute(con, glue(
        "INSERT INTO zone_metric (zone_seq, metric_seq, value) VALUES {vals}",
        vals = paste(glue("({dd$zone_seq}, {s_cov}, {dd$coverage * 100})"), collapse = ", ")))
  }

  d_drop <- d |> filter(!reportable)
  for (i in seq_len(nrow(d_drop)))
    dbExecute(con, glue(
      "DELETE FROM zone_metric
       WHERE zone_seq = {d_drop$zone_seq[i]}
         AND metric_seq = (SELECT metric_seq FROM metric WHERE metric_key = '{d_drop$metric_key[i]}')"))

  d_out <- d |>
    left_join(dbGetQuery(con, glue(
      "SELECT zone_seq, value AS programarea_key FROM zone WHERE tbl = '{tbl_pra}'")),
      by = "zone_seq") |>
    arrange(coverage) |>
    select(programarea_key, metric_key, coverage, reportable)
  write_csv(d_out |> filter(!reportable), f_csv)
  log_info("kappa={kappa}: {nrow(d_drop)} of {nrow(d)} (zone x component) pairs not reportable")
  invisible(d_out)
}

6 Comparing a build against v7

One function, used for v7c and for each control. It compares the touched merged models and the three surfaces that carry the release — cell_metric (~22.0 M rows), zone_metric and zone_taxon — by key, exactly, and reports the largest value movement per metric.

A note on “exactly”. model_cell.value is INTEGER, so the six turtle models and the right whale are compared bit-for-bit and the only admissible answers are 0 diffs (flag off) or exactly the evidence table’s cells (flag on). The scored surfaces are DOUBLE and every zone value is a SUM() over up to 662,075 cells: IEEE addition is not associative, and DuckDB’s parallel aggregate does not fix the reduction order, so re-running v7’s own SQL on v7’s own data reproduces zone_metric to about 5 ULP (measured: max 8.9e-15 on values near 10) rather than bit-identically. The gate is therefore exact on keys (no row gained, none lost, none renamed) and bounded on values at 1e-9 relative — four orders of magnitude tighter than the smallest change either method makes, and six orders looser than reassociation noise. n_moved below counts values outside that bound; it is the number the gates assert.

# rel difference guard: |a-b| / max(|b|, 1) -- absolute for small values, relative for large
REL_TOL <- 1e-9

# an INTEGER model surface vs v7's: exact multiset difference, both directions
surface_cmp <- function(cc, ms) dbGetQuery(cc, glue(
  "SELECT
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms})
        EXCEPT ALL SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS new_not_prev,
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms})
        EXCEPT ALL SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms}))) AS prev_not_new,
     (SELECT count(*) FROM model_cell      WHERE mdl_seq IN ({ms})) AS n_new,
     (SELECT count(*) FROM prev.model_cell WHERE mdl_seq IN ({ms})) AS n_prev,
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id FROM model_cell WHERE mdl_seq IN ({ms})
        EXCEPT SELECT mdl_seq, cell_id FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS n_gained"))

compare_build <- function(db_path) {
  cc <- dbConnect(duckdb(dbdir = db_path, read_only = TRUE))
  on.exit(dbDisconnect(cc, shutdown = TRUE), add = TRUE)
  duckdb_tune(cc, glue("{path_dir(db_path)}/duckdb_tmp"))
  # ATTACH is per DATABASE INSTANCE, not per connection: comparing the release this notebook
  # already holds open would otherwise fail with `database with name "prev" already exists`.
  if (!nrow(dbGetQuery(cc, "SELECT 1 FROM duckdb_databases() WHERE database_name = 'prev'")))
    dbExecute(cc, glue("ATTACH '{sdm_db_prev}' AS prev (READ_ONLY)"))

  turtle <- surface_cmp(cc, paste(MDL_TURTLE, collapse = ", "))
  whale  <- surface_cmp(cc, MDL_WHALE)

  cell <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM cell_metric cm JOIN metric m USING (metric_seq)),
          b AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM prev.cell_metric cm JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.k = b.k AND a.cid = b.cid)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  zone <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)),
          b AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM prev.zone_metric zm JOIN prev.zone z USING (zone_seq)
                JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.k = b.k)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  # zone_taxon: key = (zone_fld, zone_value, mdl_seq); zone_tbl differs by the _v7c rename
  ztx <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM zone_taxon),
          b AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM prev.zone_taxon),
          j AS (SELECT coalesce(a.sp_cat, b.sp_cat) AS sp_cat,
                       a.area_km2 aa, b.area_km2 ba, a.avg_suit sa, b.avg_suit sb,
                       a.suit_rl ra, b.suit_rl rb, a.pct_cat pa, b.pct_cat pb,
                       a.f AS af, b.f AS bf
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.mdl_seq = b.mdl_seq)
     -- named `metric_key` so moved_keys() reads the real column: it looked for metric_key,
     -- found nothing on a frame keyed by sp_cat, and the zone_taxon gate passed vacuously
     SELECT sp_cat AS metric_key,
            count(*) FILTER (WHERE bf IS NULL) AS n_only_new,
            count(*) FILTER (WHERE af IS NULL) AS n_only_prev,
            coalesce(greatest(
              max(abs(aa - ba) / greatest(abs(ba), 1.0)),
              max(abs(sa - sb) / greatest(abs(sb), 1.0)),
              max(abs(ra - rb) / greatest(abs(rb), 1.0)),
              max(abs(pa - pb) / greatest(abs(pb), 1.0))), 0) AS max_rel,
            count(*) FILTER (WHERE
              greatest(abs(aa - ba) / greatest(abs(ba), 1.0),
                       abs(sa - sb) / greatest(abs(sb), 1.0),
                       abs(ra - rb) / greatest(abs(rb), 1.0),
                       abs(pa - pb) / greatest(abs(pb), 1.0)) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  pra <- dbGetQuery(cc, glue(
    "SELECT z.value AS programarea_key, m.metric_key, zm.value
     FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)
     WHERE z.fld = 'programarea_key'"))

  list(turtle = turtle, whale = whale, cell = cell, zone = zone, ztx = ztx, pra = pra)
}

# the invariant that must hold in EVERY run, whatever the flags: the productivity fix is
# v10's. `{key}_coverage` is a NEW zone-only key, not a primprod row -- it says how much of
# the zone the component covers and never touches primprod's values.
moved_keys <- function(d) {
  # a check that reads a column that is not there returns character(0) and passes forever
  stopifnot("comparison frame has no metric_key column" = "metric_key" %in% names(d))
  sort(d$metric_key[d$n_moved > 0 | d$n_only_new > 0 | d$n_only_prev > 0])
}
primprod_ok <- function(cmp) {
  k <- c(moved_keys(cmp$cell), moved_keys(cmp$zone))
  !any(grepl("^primprod", k) & !grepl("_coverage$", k))
}

10 Manifest

Digests of the surfaces P4 must reproduce on the server: the six turtle models, the right whale, cell_metric, zone_metric and zone_taxon. msens::hash_query() is an order-independent reduction (count + bit_xor + sum), so it does not care how DuckDB partitioned the scan.

It DOES care about the last bit of a DOUBLE, and Section 6 measured that the zone sums are not bit-reproducible (parallel SUM() reassociates; ~5 ULP). A digest of the raw doubles would therefore differ between two correct builds, and the server-equals-laptop gate would be red for no reason. So the INTEGER model surfaces are digested as they are (exact), and every DOUBLE is digested as CAST(... AS FLOAT): ~7 significant digits at every magnitude (area_km2 runs to 1e6, a score to 100), nine orders coarser than the noise and far finer than anything either rule moves.

The committed manifest is the reference. A build with the same flags on any machine must reproduce its digests, and this chunk stops if it does not – that is P4’s “server build equals the laptop’s” gate, run by the render itself rather than by eye. A changed evidence table (zone_exclusions_hash) under the same flags moves the digests too, so it also stops here. BUILD_REFERENCE=1 is the only way to move the reference, and says so in the log.

v7.2 is a **second surgical patch of the public v7 release** — same `usa05` grid, same
`mdl_seq`/`value` schema, same 20 Program Areas — built exactly as v7.1 (`build_v7b.qmd`) was: clone
v7's DuckDB copy-on-write, change only the merged models the rules touch under their EXISTING
`mdl_seq`, then re-execute v7's own scoring chunks verbatim. It supersedes v7.1 for review. Three
rules, nothing else:

1. **Turtle record rule.** A sea-turtle species is dropped from an ecoregion where it has **never
   been recorded** in any observational channel (NOAA Alaska sightings, strandings and bycatch
   1963–2020, OBIS, GBIF incl. iNaturalist, WDFW, STSSN). On v7 that is the East Bering Sea for
   loggerhead, green, leatherback and olive ridley; the Gulf of Alaska, where all four are recorded,
   keeps them at their v7 values. **v7.1's suitability threshold (P ≥ 0.5, floor-of-1 fill dropped)
   is NOT carried**: v7's turtle models are kept exactly as they are everywhere the record rule does
   not reach, because the threshold removed loggerhead, green and olive ridley from the Gulf of
   Alaska where all three have been recorded.
2. **Right whale Gulf rule.** The North Atlantic right whale (`mdl_seq` 54252) is dropped from the
   two Gulf of America ecoregions (EGOA, WCGOA), outside its range.
3. **Coverage floor κ = 5 %**, carried from v7.1 unchanged (`msens::coverage_sql()` /
   `coverage_floor()`): a Program-Area component whose scored cells cover < 5 % of the area is not
   reportable — no row, never a zero.

Rules 1 and 2 are one mechanism: a **taxon × ecoregion exclusion** read from the evidence table
`data/v7c/zone_exclusions.csv`, written and justified by `build_v7c_exclusions.qmd`, and applied by
`msens::zone_exclude_sql()`. A cell belongs to the ecoregion covering most of it
(`msens::cell_zone_major_sql()`), and **critical habitat is never excluded**: a cell the taxon holds
under a designated `ch_*` / `ca_*` dataset survives inside an excluded ecoregion. The notebook asserts
that the cells it removes per (model, ecoregion) are exactly the evidence table's `n_cells_v7`.

Each rule is a flag whose **control value is off**, so the same code path reproduces v7 exactly.
That is the first gate below, and it is what makes every other number here attributable.

Not in v7.2: productivity, the distribution-share / national score, anything of v10. **Every
`primprod*` row of v7c must equal v7's**, and a gate asserts it in every run.

```{r}
#| label: build_fns

# copy-on-write clone: APFS `cp -c` on the laptop, `cp --reflink=auto` on Linux. A 3.6 GB
# release database clones in milliseconds and only the pages the patch rewrites cost space.
clone_db <- function(src, dst) {
  if (file_exists(dst))               file_delete(dst)
  if (file_exists(glue("{dst}.wal"))) file_delete(glue("{dst}.wal"))
  dir_create(path_dir(dst))
  flag <- if (is_server) "--reflink=auto" else "-c"
  rc   <- system2("cp", c(flag, shQuote(src), shQuote(dst)))
  stopifnot("copy-on-write clone failed" = identical(as.integer(rc), 0L))
  log_info("cloned {src} -> {dst}")
}

# the record rule: DELETE the evidence table's (model x ecoregion) cells under the EXISTING
# merged ids. Re-merging would RENUMBER mdl_seq and break every published ?mdl_seq= deep link;
# a delete leaves every surviving cell at its v7 value, which is the point -- outside the
# excluded ecoregions the species is exactly v7's.
apply_exclusions <- function(con, excl, label) {
  if (!nrow(excl)) {
    log_info("[{label}] no exclusion applied -- the merged models stay v7's")
    return(invisible(tibble(mdl_seq = integer(), zone_key = character(),
                            n_cells_v7 = integer(), n_deleted = integer())))
  }
  seqs    <- sort(unique(excl$mdl_seq))
  seq_sql <- paste(seqs, collapse = ", ")
  stopifnot("an exclusion names a model outside v7's six turtles and the right whale" =
    all(seqs %in% c(MDL_TURTLE_V7, MDL_WHALE)))

  # each cell's ONE ecoregion: the one covering most of it (1,125 cells straddle two)
  dbExecute(con, glue(
    "CREATE OR REPLACE TEMP TABLE cell_zone AS {msens::cell_zone_major_sql('ecoregion_key')}"))

  # critical habitat is never excluded: the cells each excluded taxon carries under any
  # designation dataset (ch_* / ca_*), keyed by the taxon's MERGED mdl_seq. A table, not a
  # view: it reads model_cell, which the delete below changes.
  dbExecute(con, glue(
    "CREATE OR REPLACE TEMP TABLE ch_src AS
     SELECT DISTINCT t.mdl_seq, mc.cell_id
     FROM taxon t
     JOIN taxon_model tm ON tm.taxon_id = t.taxon_id
     JOIN model_cell  mc ON mc.mdl_seq  = tm.mdl_seq
     WHERE t.mdl_seq IN ({seq_sql})
       AND (tm.ds_key LIKE 'ch\\_%' ESCAPE '\\' OR tm.ds_key LIKE 'ca\\_%' ESCAPE '\\')"))

  # materialize the rows to delete, so the count per (model, ecoregion) is asserted against
  # the evidence table BEFORE anything is removed
  sql <- msens::zone_exclude_sql(
    excl |> select(mdl_seq, zone_key),
    src = "model_cell", cell_zone = "cell_zone", ch_src = "ch_src")
  dbExecute(con, glue("CREATE OR REPLACE TEMP TABLE excl_del AS {sql}"))

  d_n <- dbGetQuery(con,
    "SELECT d.mdl_seq, cz.zone_key, count(*) AS n_deleted
     FROM excl_del d JOIN cell_zone cz USING (cell_id) GROUP BY ALL")
  d_chk <- excl |>
    select(mdl_seq, zone_key, n_cells_v7) |>
    left_join(d_n |> mutate(mdl_seq = as.integer(mdl_seq)), by = c("mdl_seq", "zone_key")) |>
    mutate(n_deleted = coalesce(as.integer(n_deleted), 0L))
  stopifnot(
    "cells selected per (mdl_seq, ecoregion) must equal the evidence table's n_cells_v7 exactly" =
      all(d_chk$n_deleted == d_chk$n_cells_v7),
    "the exclusion selected cells outside the evidence table's (mdl_seq, ecoregion) pairs" =
      sum(d_n$n_deleted) == sum(d_chk$n_deleted))

  n <- dbExecute(con,
    "DELETE FROM model_cell WHERE (mdl_seq, cell_id) IN (SELECT mdl_seq, cell_id FROM excl_del)")
  stopifnot("DELETE removed a different number of rows than the exclusion selected" =
    n == sum(d_chk$n_cells_v7))

  # the rule, stated on the model it changed; idempotent (any previous v7.2 clause is stripped)
  d_z <- excl |> group_by(mdl_seq) |>
    summarize(zones = paste(sort(zone_key), collapse = ", "), .groups = "drop")
  for (i in seq_len(nrow(d_z)))
    dbExecute(con, glue(
      "UPDATE model SET description =
         regexp_replace(coalesce(description, ''), ' \\| v7\\.2 record rule.*$', '') ||
         ' | v7.2 record rule: excluded from {d_z$zones[i]}'
       WHERE mdl_seq = {d_z$mdl_seq[i]}"))

  log_info("[{label}] excluded {format(n, big.mark = ',')} cells: ",
           "{paste(glue('{d_chk$mdl_seq} x {d_chk$zone_key} = {d_chk$n_deleted}'), collapse = '; ')}")
  invisible(d_chk)
}

# kappa: a ZONE reporting rule. Cell-level rasters are untouched; only the Program-Area
# component row of a pair below the floor is deleted (its raw and _prepctareaweighting rows
# stay, so the diagnostic remains readable), and the composite then averages one fewer
# component -- exactly as it already does for an area with no turtles at all.
apply_kappa <- function(con, tbl_pra, component_keys, kappa, f_csv) {
  if (is.na(kappa) || kappa <= 0) {
    log_info("COVERAGE_FLOOR off -- no _coverage metrics written, no component dropped")
    return(invisible(NULL))
  }
  d <- dbGetQuery(con, msens::coverage_sql(
        tbl_pra, component_keys, weight = "pct_covered",
        val_col = msens::sdm_val_col(con, "cell_metric"))) |>
    msens::coverage_floor(kappa = kappa)

  z_seqs <- dbGetQuery(con, glue(
    "SELECT zone_seq FROM zone WHERE tbl = '{tbl_pra}'"))$zone_seq
  z_sql  <- paste(z_seqs, collapse = ", ")

  for (k in component_keys) {
    k_cov <- glue("{k}_coverage")
    if (!nrow(dbGetQuery(con, glue("SELECT 1 FROM metric WHERE metric_key = '{k_cov}'"))))
      dbExecute(con, glue(
        "INSERT INTO metric (metric_key, description) VALUES
         ('{k_cov}', 'Percent of the zone covered by cells carrying {k} (coverage floor input)')"))
    s_cov <- dbGetQuery(con, glue(
      "SELECT metric_seq FROM metric WHERE metric_key = '{k_cov}'"))$metric_seq
    dbExecute(con, glue(
      "DELETE FROM zone_metric WHERE metric_seq = {s_cov} AND zone_seq IN ({z_sql})"))
    dd <- d |> filter(metric_key == k)
    if (nrow(dd))
      dbExecute(con, glue(
        "INSERT INTO zone_metric (zone_seq, metric_seq, value) VALUES {vals}",
        vals = paste(glue("({dd$zone_seq}, {s_cov}, {dd$coverage * 100})"), collapse = ", ")))
  }

  d_drop <- d |> filter(!reportable)
  for (i in seq_len(nrow(d_drop)))
    dbExecute(con, glue(
      "DELETE FROM zone_metric
       WHERE zone_seq = {d_drop$zone_seq[i]}
         AND metric_seq = (SELECT metric_seq FROM metric WHERE metric_key = '{d_drop$metric_key[i]}')"))

  d_out <- d |>
    left_join(dbGetQuery(con, glue(
      "SELECT zone_seq, value AS programarea_key FROM zone WHERE tbl = '{tbl_pra}'")),
      by = "zone_seq") |>
    arrange(coverage) |>
    select(programarea_key, metric_key, coverage, reportable)
  write_csv(d_out |> filter(!reportable), f_csv)
  log_info("kappa={kappa}: {nrow(d_drop)} of {nrow(d)} (zone x component) pairs not reportable")
  invisible(d_out)
}

# the methods a release actually used, as data -- backfill_versions.qmd stages this table and
# manifest_build() carries it as `methods`, so the docs state the rules from the release itself
write_release_method <- function(con, ex_turtles, ex_whale, kappa) {
  onoff <- function(x) if (isTRUE(x)) "on" else "off"
  d <- tibble(
    method_key  = c("turtle_record_rule", "right_whale_gulf_rule", "coverage_floor_pct",
                    "zone_exclusions_hash", "prev"),
    value       = c(
      onoff(ex_turtles),
      onoff(ex_whale),
      as.character(if (is.na(kappa)) 0 else kappa * 100),
      EXCL_HASH,
      ver_prev),
    description = c(
      "A sea-turtle species is dropped from an ecoregion where it has never been recorded in any observational channel; critical habitat is never dropped (v7: off)",
      "The North Atlantic right whale is dropped from the Gulf of America ecoregions (EGOA, WCGOA), outside its range; critical habitat is never dropped (v7: off)",
      "A Program-Area component is reportable only if its scored cells cover at least this percent of the area (v7: 0)",
      "msens::hash_query digest of data/v7c/zone_exclusions.csv (mdl_seq, zone_fld, zone_key, n_cells_v7), the evidence table the record rules apply",
      "The release this one patches"))
  dbWriteTable(con, "release_method", d, overwrite = TRUE)
  d
}
```

```{r}
#| label: build_release

build_release <- function(db_path, out_dir, ex_turtles, ex_whale, kappa, label) {
  t0 <- Sys.time()
  dir_create(out_dir)
  clone_db(sdm_db_prev, db_path)

  con <- dbConnect(duckdb(dbdir = db_path, read_only = FALSE))
  # v7's zone / metric / model / dataset tables carry `DEFAULT CURRENT_DATE`, which DuckDB binds
  # to the icu extension -- so EVERY write to them needs it, the zone-table rename included.
  # A laptop autoloads icu from ~/.duckdb; the server's rstudio container has no copy for
  # uid 1000 and halted here on its first UPDATE. Declared, as the other notebooks declare httpfs.
  dbExecute(con, "INSTALL icu; LOAD icu;")
  on.exit(dbDisconnect(con, shutdown = TRUE), add = TRUE)
  duckdb_tune(con, glue("{out_dir}/duckdb_tmp"))

  # the server's clone inherits a cell_model VIEW whose read_parquet path is absolute and
  # points at {ver_prev}: left in place it would serve the PREVIOUS release's cells under
  # this release's name. Dropped, then asserted gone.
  dbExecute(con, "DROP VIEW IF EXISTS cell_model")
  v_bad <- dbGetQuery(con, glue(
    "SELECT view_name FROM duckdb_views() WHERE sql LIKE '%/{ver_prev}/%'"))
  stopifnot("a view still references the previous release's path" = nrow(v_bad) == 0)

  # zone tbl suffix _v7 -> _v7c (dev/build_v7.R:55-61)
  for (old_tbl in dbGetQuery(con, glue(
      "SELECT DISTINCT tbl FROM zone WHERE tbl LIKE '%\\_{ver_prev}' ESCAPE '\\'"))$tbl) {
    new_tbl <- str_replace(old_tbl, glue("_{ver_prev}$"), glue("_{ver}"))
    dbExecute(con, glue("UPDATE zone       SET tbl = '{new_tbl}'      WHERE tbl = '{old_tbl}'"))
    dbExecute(con, glue("UPDATE zone_taxon SET zone_tbl = '{new_tbl}' WHERE zone_tbl = '{old_tbl}'"))
    log_info("renamed zone tbl: {old_tbl} -> {new_tbl}")
  }

  # the ids the rules may touch, asserted on the clone: the merged ids never move
  seq_turtle <- dbGetQuery(con,
    "SELECT mdl_seq FROM taxon WHERE sp_cat = 'turtle' ORDER BY mdl_seq")$mdl_seq
  d_whale <- dbGetQuery(con, glue(
    "SELECT sp_cat, common_name FROM taxon WHERE mdl_seq = {MDL_WHALE}"))
  stopifnot(
    "expected v7's six merged turtle models at 54238-54243" =
      identical(as.integer(seq_turtle), MDL_TURTLE_V7),
    "expected v7's merged North Atlantic right whale at mdl_seq 54252" =
      nrow(d_whale) == 1 && d_whale$sp_cat == "mammal" &&
        d_whale$common_name == "North Atlantic Right Whale")

  # split the evidence table by flag: turtle rows = the turtle taxa's merged ids, whale rows = 54252
  excl <- bind_rows(
    d_excl |> filter(ex_turtles, mdl_seq %in% seq_turtle),
    d_excl |> filter(ex_whale,   mdl_seq == MDL_WHALE))
  d_ex <- apply_exclusions(con, excl, label)

  # v7's scoring chunks need these names; a child of globalenv() keeps the chunk code's own
  # assignments out of the session while still resolving library functions
  env <- new.env(parent = globalenv())
  env$con_sdm <- con
  env$tbl_pra <- glue("ply_programareas_2026_{ver}")
  env$tbl_sr  <- glue("ply_subregions_2026_{ver}")
  env$tbl_er  <- "ply_ecoregions_2025"
  env$component_pct_pra_csv <- file.path(out_dir, glue("tbl_component_pct_programarea_{ver}.csv"))
  env$zone_taxon_csv        <- file.path(out_dir, glue("zone_taxon_{ver}.csv"))
  # NEVER narrow sp_cats: the pct-area and composite chunks enumerate every component from it
  env$sp_cats <- dbGetQuery(con,
    "SELECT DISTINCT sp_cat FROM taxon WHERE is_ok ORDER BY sp_cat")$sp_cat
  stopifnot("sp_cats lost a category" = length(env$sp_cats) == 7)

  run <- function(labels)
    for (lbl in labels) {
      log_info("[{label}] chunk: {lbl}")
      eval(parse(text = chunk_fix(get_chunk(lbl))), envir = env)
    }

  run(CHUNKS_PRE)
  d_cov <- apply_kappa(
    con, env$tbl_pra,
    c(glue("extrisk_{env$sp_cats}_ecoregion_rescaled"), "primprod_ecoregion_rescaled"),
    kappa, file.path(out_dir, glue("tbl_component_not_reportable_programarea_{ver}.csv")))
  run(CHUNKS_POST)

  write_release_method(con, ex_turtles, ex_whale, kappa)

  log_info("[{label}] built in {round(as.numeric(difftime(Sys.time(), t0, units = 'mins')), 1)} min")
  invisible(list(excl = d_ex, coverage = d_cov))
}
```

## Comparing a build against v7 {#sec-compare}

One function, used for `v7c` and for each control. It compares the touched merged models and the
three surfaces that carry the release — `cell_metric` (~22.0 M rows), `zone_metric` and
`zone_taxon` — **by key, exactly**, and reports the largest value movement per metric.

A note on "exactly". `model_cell.value` is INTEGER, so the six turtle models and the right whale are
compared bit-for-bit and the only admissible answers are 0 diffs (flag off) or exactly the evidence
table's cells (flag on). The scored surfaces are DOUBLE and every zone value is a `SUM()` over up to
662,075 cells: IEEE addition is not associative, and DuckDB's parallel aggregate does not fix the
reduction order, so re-running v7's own SQL on v7's own data reproduces `zone_metric` to about 5 ULP
(measured: max 8.9e-15 on values near 10) rather than bit-identically. The gate is therefore
**exact on keys** (no row gained, none lost, none renamed) and **bounded on values at 1e-9
relative** — four orders of magnitude tighter than the smallest change either method makes, and six
orders looser than reassociation noise. `n_moved` below counts values outside that bound; it is the
number the gates assert.

```{r}
#| label: compare_fn

# rel difference guard: |a-b| / max(|b|, 1) -- absolute for small values, relative for large
REL_TOL <- 1e-9

# an INTEGER model surface vs v7's: exact multiset difference, both directions
surface_cmp <- function(cc, ms) dbGetQuery(cc, glue(
  "SELECT
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms})
        EXCEPT ALL SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS new_not_prev,
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id, value FROM prev.model_cell WHERE mdl_seq IN ({ms})
        EXCEPT ALL SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq IN ({ms}))) AS prev_not_new,
     (SELECT count(*) FROM model_cell      WHERE mdl_seq IN ({ms})) AS n_new,
     (SELECT count(*) FROM prev.model_cell WHERE mdl_seq IN ({ms})) AS n_prev,
     (SELECT count(*) FROM (SELECT mdl_seq, cell_id FROM model_cell WHERE mdl_seq IN ({ms})
        EXCEPT SELECT mdl_seq, cell_id FROM prev.model_cell WHERE mdl_seq IN ({ms}))) AS n_gained"))

compare_build <- function(db_path) {
  cc <- dbConnect(duckdb(dbdir = db_path, read_only = TRUE))
  on.exit(dbDisconnect(cc, shutdown = TRUE), add = TRUE)
  duckdb_tune(cc, glue("{path_dir(db_path)}/duckdb_tmp"))
  # ATTACH is per DATABASE INSTANCE, not per connection: comparing the release this notebook
  # already holds open would otherwise fail with `database with name "prev" already exists`.
  if (!nrow(dbGetQuery(cc, "SELECT 1 FROM duckdb_databases() WHERE database_name = 'prev'")))
    dbExecute(cc, glue("ATTACH '{sdm_db_prev}' AS prev (READ_ONLY)"))

  turtle <- surface_cmp(cc, paste(MDL_TURTLE, collapse = ", "))
  whale  <- surface_cmp(cc, MDL_WHALE)

  cell <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM cell_metric cm JOIN metric m USING (metric_seq)),
          b AS (SELECT m.metric_key AS k, cm.cell_id AS cid, cm.value AS v
                FROM prev.cell_metric cm JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.k = b.k AND a.cid = b.cid)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  zone <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)),
          b AS (SELECT z.fld AS f, z.value AS zv, m.metric_key AS k, zm.value AS v
                FROM prev.zone_metric zm JOIN prev.zone z USING (zone_seq)
                JOIN prev.metric m USING (metric_seq)),
          j AS (SELECT coalesce(a.k, b.k) AS metric_key, a.v AS va, b.v AS vb
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.k = b.k)
     SELECT metric_key,
            count(*) FILTER (WHERE vb IS NULL) AS n_only_new,
            count(*) FILTER (WHERE va IS NULL) AS n_only_prev,
            coalesce(max(abs(va - vb) / greatest(abs(vb), 1.0)), 0) AS max_rel,
            count(*) FILTER (WHERE abs(va - vb) / greatest(abs(vb), 1.0) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  # zone_taxon: key = (zone_fld, zone_value, mdl_seq); zone_tbl differs by the _v7c rename
  ztx <- dbGetQuery(cc, glue(
    "WITH a AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM zone_taxon),
          b AS (SELECT zone_fld f, zone_value zv, mdl_seq, sp_cat, area_km2, avg_suit,
                       suit_rl, suit_rl_area, cat_suit_rl_area, pct_cat FROM prev.zone_taxon),
          j AS (SELECT coalesce(a.sp_cat, b.sp_cat) AS sp_cat,
                       a.area_km2 aa, b.area_km2 ba, a.avg_suit sa, b.avg_suit sb,
                       a.suit_rl ra, b.suit_rl rb, a.pct_cat pa, b.pct_cat pb,
                       a.f AS af, b.f AS bf
                FROM a FULL JOIN b ON a.f = b.f AND a.zv = b.zv AND a.mdl_seq = b.mdl_seq)
     -- named `metric_key` so moved_keys() reads the real column: it looked for metric_key,
     -- found nothing on a frame keyed by sp_cat, and the zone_taxon gate passed vacuously
     SELECT sp_cat AS metric_key,
            count(*) FILTER (WHERE bf IS NULL) AS n_only_new,
            count(*) FILTER (WHERE af IS NULL) AS n_only_prev,
            coalesce(greatest(
              max(abs(aa - ba) / greatest(abs(ba), 1.0)),
              max(abs(sa - sb) / greatest(abs(sb), 1.0)),
              max(abs(ra - rb) / greatest(abs(rb), 1.0)),
              max(abs(pa - pb) / greatest(abs(pb), 1.0))), 0) AS max_rel,
            count(*) FILTER (WHERE
              greatest(abs(aa - ba) / greatest(abs(ba), 1.0),
                       abs(sa - sb) / greatest(abs(sb), 1.0),
                       abs(ra - rb) / greatest(abs(rb), 1.0),
                       abs(pa - pb) / greatest(abs(pb), 1.0)) > {REL_TOL}) AS n_moved
     FROM j GROUP BY 1 ORDER BY 1"))

  pra <- dbGetQuery(cc, glue(
    "SELECT z.value AS programarea_key, m.metric_key, zm.value
     FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)
     WHERE z.fld = 'programarea_key'"))

  list(turtle = turtle, whale = whale, cell = cell, zone = zone, ztx = ztx, pra = pra)
}

# the invariant that must hold in EVERY run, whatever the flags: the productivity fix is
# v10's. `{key}_coverage` is a NEW zone-only key, not a primprod row -- it says how much of
# the zone the component covers and never touches primprod's values.
moved_keys <- function(d) {
  # a check that reads a column that is not there returns character(0) and passes forever
  stopifnot("comparison frame has no metric_key column" = "metric_key" %in% names(d))
  sort(d$metric_key[d$n_moved > 0 | d$n_only_new > 0 | d$n_only_prev > 0])
}
primprod_ok <- function(cmp) {
  k <- c(moved_keys(cmp$cell), moved_keys(cmp$zone))
  !any(grepl("^primprod", k) & !grepl("_coverage$", k))
}
```

Four clones in a scratch directory, each through `build_release()` with a different flag set, then

## Manifest

Digests of the surfaces P4 must reproduce on the server: the six turtle models, the right whale,
`cell_metric`, `zone_metric` and `zone_taxon`. `msens::hash_query()` is an order-independent
reduction (`count + bit_xor + sum`), so it does not care how DuckDB partitioned the scan.

It DOES care about the last bit of a DOUBLE, and @sec-compare measured that the zone sums are
not bit-reproducible (parallel `SUM()` reassociates; ~5 ULP). A digest of the raw doubles would
therefore differ between two correct builds, and the server-equals-laptop gate would be red for
no reason. So the INTEGER model surfaces are digested as they are (exact), and every DOUBLE is
digested as `CAST(... AS FLOAT)`: ~7 significant digits at every magnitude (`area_km2` runs to
1e6, a score to 100), nine orders coarser than the noise and far finer than anything either
rule moves.

**The committed manifest is the reference.** A build with the same flags on any machine must
reproduce its digests, and this chunk stops if it does not -- that is P4's "server build equals
the laptop's" gate, run by the render itself rather than by eye. A changed evidence table
(`zone_exclusions_hash`) under the same flags moves the digests too, so it also stops here.
`BUILD_REFERENCE=1` is the only way to move the reference, and says so in the log.

```{r}

    "SELECT mdl_seq, cell_id, value FROM model_cell WHERE mdl_seq = {MDL_WHALE}")),

    "SELECT m.metric_key, cm.cell_id, CAST(cm.value AS FLOAT) AS value
     FROM cell_metric cm JOIN metric m USING (metric_seq)"),
  zone_metric = msens::hash_query(con,
    "SELECT z.fld, z.value AS zone_value, m.metric_key, CAST(zm.value AS FLOAT) AS value
     FROM zone_metric zm JOIN zone z USING (zone_seq) JOIN metric m USING (metric_seq)"),
  zone_taxon = msens::hash_query(con,
    "SELECT zone_fld, zone_value, mdl_seq, CAST(area_km2 AS FLOAT) AS area_km2,
            CAST(avg_suit AS FLOAT) AS avg_suit, CAST(suit_rl AS FLOAT) AS suit_rl,
```
