Seasonal seabird density (#/km²) → population-percentile suitability [1,100] on the global 0.05° grid

Published

2026-10-31

NCCOS at-sea seabird density models, Atlantic (Winship et al. 2018) + Pacific (Leirness et al. 2021), as seasonal COGs (n_per_km2, 2-km, oblique-mercator). v11 rasterizes each (species × season × region) onto the global 0.05° cell grid and maps the heavy-tailed density onto the merge’s [1,100] scale by the population-percentile transform (msens::density_to_suit(method = "ud")), plus an annual surface for scoring.

  • Source COGs (in-repo): data/sdm/raw/nc_atl_birds_dens/*.tif (140) + nc_pac_birds_dens/*.tif (135); band 1 = n_per_km2 (bands 2/3 = CV/CI). Also public at file.marinesensitivity.org/cog/sdm/raw/{ds}/{sp_code}_{season}.tif (served natively via titiler).
  • mdl_key: seasonal nc|{sp_id}|{season} + annual nc|{sp_id}. sp_id is GBIF:… for a species and GUILD:{sp_code} for the 13 multi-species guilds (these used to land under the genus/family GBIF id with is_guild = FALSE, and three of them shared an id with a real species). Regions (atl/pac) are spatially disjoint and unioned per sp_id.
  • Value transform (v11 Q6, D12). Per model (species × season × region), AFTER regridding: val = density_to_suit(d, "ud", area = cell area_km2) — 100 minus the percent of the modelled population in cells strictly denser than this one, so the densest cell is 100 and the cells with val >= 100 - p are exactly the p % core. Cells with val < 1 are dropped (the merge’s floor). It is scale-free, which is why the Atlantic 2018 index and the Pacific densities are treated alike. The old recipe (NC_TRANSFORM=cap: linear to the species’ pooled p99.5 of positive density, which left most cells near 0) stays available and is compared with it below.
  • Annual = msens::density_annual(n_intervals = 4) on the DENSITIES — a season NCCOS did not model counts as zero — and THEN the same transform. The v8 ingest averaged the transformed values over the seasons a cell was present in, biasing the annual upward for the sparsest species.
  • Crosswalk (data/nc_taxon_crosswalk.csv, written HERE): common name first, then scientific name, then explicit overrides, resolved to the BirdLife sisid (the bl model table) and the WoRMS AphiaID (spp.duckdb). model_nc.csv carries sisid, worms_id, is_guild, response_type; merge_models_prep.qmd excludes is_guild rows.

Not yet folded into merge/scoring (a flagged scoring change, FOLD_DENSITY).

1 The Atlantic source: NC_ATL_SOURCE (2018 default = control, 2023)

The Pacific half (Leirness et al. 2021, seasonal) is the same under both. The Atlantic half has two sources, selected by NC_ATL_SOURCE; the control is 2018, which reproduces v10 / the pre-2023 ingest exactly, and only one Atlantic source is ever ingested in a run (the 2018 Atlantic models leave the dataset when 2023 is on).

Under 2023: each species’ 12 monthly rasters are reprojected bilinearly to EPSG:4326 and regridded to the 0.05 degree cells exactly as the Pacific COGs are (cells_from_raster(digits = NULL, min_value = 1e-12)), transformed month by month with density_to_suit("ud") (cell-area weighted), and the annual is OUR integration of the twelve densities, day-weighted: density_annual(n_intervals = 12, interval = <month>, weights = msens::month_day_weights()) (msens >= 0.65.1; February counts 28/365), then transformed. The package’s own delivered Annual layer is the day-weighted mean of its twelve months (checked here on the native grid to float precision), so the two should now agree to the regrid’s rounding; it is regridded the same way and compared per species (data/nc_atl2023_annual_compare.csv), with the plain 12-month mean kept as a sensitivity (it differs by up to 8 % in a cell). The Pacific seasons stay equal-weighted (4 seasons, as the 2018 control). The package carries no “no survey effort” raster: the hatched mask of the MDAT map services is an overlay that is not part of the download, and every one of the 637 density rasters is strictly positive on the same 13,419 modelled cells (NaN elsewhere; no zeros, no -9999). The provenance columns source, accession, citation of the 2023 models come from SOURCE.json; the front matter above cannot be conditional, so it describes both sources and model_nc.csv / the manifest say which one ran.

Smoke test (writes nothing to the version’s dist/). NC_SMOKE_DIR=<scratch dir> redirects the dataset partition, model_nc.csv, the crosswalk and both comparison tables to that directory and skips the manifest; NC_TEST_SP=ATPU,BLTE,COMU (or NC_TEST_N=<n>) restricts the regridding to those species. It refuses a directory inside the big-data root.

4 The 2023 Atlantic package (NC_ATL_SOURCE=2023)

MDAT Avian Relative Density v3.0 (MDAT_Avian_Relative_Density.zip, 289 MB; Duke MGEL, distributing the NCCOS models of Winship et al. 2023). # download (what is missing), verify the pinned hash, write SOURCE.json once, unzip (the ZIP is kept)
mdat_acquire <- function() {
  dir_create(mdat_dir)
  dest <- path(mdat_dir, path_file(mdat_urls))
  old  <- options(timeout = 3600); on.exit(options(old), add = TRUE)
  for (i in seq_along(mdat_urls)) if (!file_exists(dest[i])) {
    log_info("downloading {mdat_urls[[i]]}")
    download.file(mdat_urls[[i]], dest[i], mode = "wb", quiet = TRUE)
  }
  sha <- digest::digest(dest[1], algo = "sha256", file = TRUE)
  stopifnot("the MDAT ZIP differs from the package this ingest was written against (sha256) -- re-inspect before ingesting" =
              identical(sha, mdat_zip_sha256))
  sj <- path(mdat_dir, "SOURCE.json")
  if (!file_exists(sj)) {
    lm <- \(u) { h <- curlGetHeaders(u); sub("^[Ll]ast-[Mm]odified: *", "", trimws(grep("^[Ll]ast-[Mm]odified", h, value = TRUE)[1])) }
    files <- imap(mdat_urls, \(u, k) list(url = u, file = path_file(u), sha256 = digest::digest(path(mdat_dir, path_file(u)), algo = "sha256", file = TRUE),
                                          bytes = file_size(path(mdat_dir, path_file(u))) |> as.numeric(), last_modified = lm(u), downloaded = as.character(Sys.Date())))
    write_json(list(url = mdat_urls[["zip"]], sha256 = sha, bytes = as.numeric(file_size(dest[1])), last_modified = lm(mdat_urls[["zip"]]),
                    downloaded = as.character(Sys.Date()), cited_report = "BOEM 2023-060",
                    product = "MDAT Avian Relative Density v3.0 (Duke MGEL; NOAA NCCOS models)",
                    citation = "Winship AJ, Leirness JB, Coyne M, Howell J, Saba VS, Christensen J. 2023. Modeling the distributions of marine birds at sea to inform planning of energy development on the US Atlantic Outer Continental Shelf. Sterling (VA): U.S. Department of the Interior, Bureau of Ocean Energy Management. 413 p. Report No.: OCS Study BOEM 2023-060. https://espis.boem.gov/Final%20Reports/BOEM_2023-060.pdf",
                    accession = NULL, files = unname(files)), sj, auto_unbox = TRUE, pretty = TRUE, null = "null")
  }
  if (!dir_exists(mdat_root)) {
    log_info("unzipping {dest[1]}")
    unzip(dest[1], exdir = path(mdat_dir, "unzipped/relative_density"))
  }
  stopifnot(dir_exists(mdat_root))
  read_json(sj, simplifyVector = FALSE)
}

# species + files from the package itself: the .mapx layer list carries the common names; the files carry the AOU-style code
mdat_index <- function() {
  lay <- read_json(path(mdat_root, "esri_mapfile/Avian_Relative_Density.mapx"), simplifyVector = FALSE)$layerDefinitions
  idx <- map_dfr(lay, \(l) tibble(name = l$name, file = l$dataConnection$dataset %||% NA_character_)) |> filter(!is.na(file)) |>
    mutate(code = str_extract(file, "^[a-z]+(?=_predicted_density)"), interval = str_extract(file, "[0-9a-z]+(?=\\.tiff$)"),
           common = str_remove(name, ", (January|February|March|April|May|June|July|August|September|October|November|December|Annual) relative density$"))
  fl  <- dir_ls(path(mdat_root, "commondata"), recurse = TRUE, glob = "*.tiff")
  stopifnot("a basename occurs twice in the package" = !anyDuplicated(path_file(fl)))
  idx <- idx |> mutate(path = fl[match(file, path_file(fl))])
  stopifnot("a layer of the map file has no GeoTIFF" = !anyNA(idx$path),
            "expected 49 species x 13 rasters" = nrow(idx) == 637, n_distinct(idx$code) == 49,
            "each species needs the 12 months and the annual" = all(table(idx$code, idx$interval %in% c(sprintf("%02d", 1:12), "annual"))[, "TRUE"] == 13),
            "one common name per code" = nrow(distinct(idx, code, common)) == 49)
  idx
}

# a source model's density on the 0.05° cells: bilinear reprojection of the omerc COG to EPSG:4326, then
# cells_from_raster() (bilinear onto the cell grid, zero-filled so the surface fades to 0 at its edge).
# digits = NULL: the raster holds NATIVE density, which rounds to 0 at 2 decimals; min_value is a
# positive epsilon, i.e. "any positive density" (the default 1 would drop every cell of a density < 1).
# The 2023 Atlantic rasters (Hotine oblique Mercator, 10 km, NaN nodata) take exactly this path.
src_path <- function(region_ds, sp_code, season) {
  if (region_ds == mdat_ds) mdat_files$path[mdat_files$code == str_to_lower(sp_code) & mdat_files$interval == season]
  else here(glue("data/sdm/raw/{region_ds}/{sp_code}_{season}.tif"))
}
dens_cells <- function(region_ds, sp_code, season) {
  f <- src_path(region_ds, sp_code, season)
  if (length(f) != 1 || !file_exists(f)) return(NULL)
  r <- terra::project(terra::rast(f, lyrs = 1), "EPSG:4326", method = "bilinear")
  msens::cells_from_raster(r, cellid_tif, min_value = 1e-12, digits = NULL) |> rename(dens = val)
}

NCCOS at-sea seabird **density** models, Atlantic [@winship2018] + Pacific [@leirness2021], as
seasonal COGs (`n_per_km2`, 2-km, oblique-mercator). v11 rasterizes each (species × season × region)
onto the global 0.05° cell grid and maps the heavy-tailed density onto the merge's **[1,100]** scale
by the **population-percentile** transform (`msens::density_to_suit(method = "ud")`), plus an
**annual** surface for scoring.

- **Source COGs** (in-repo): `data/sdm/raw/nc_atl_birds_dens/*.tif` (140) + `nc_pac_birds_dens/*.tif`
  (135); band 1 = `n_per_km2` (bands 2/3 = CV/CI). Also public at
  `file.marinesensitivity.org/cog/sdm/raw/{ds}/{sp_code}_{season}.tif` (served natively via titiler).
- **`mdl_key`**: seasonal `nc|{sp_id}|{season}` + annual `nc|{sp_id}`. `sp_id` is `GBIF:…` for a
  species and `GUILD:{sp_code}` for the 13 multi-species guilds (these used to land under the
  genus/family GBIF id with `is_guild = FALSE`, and three of them shared an id with a real species).
  Regions (atl/pac) are spatially disjoint and **unioned** per `sp_id`.
- **Value transform (v11 Q6, D12).** Per model (species × season × region), AFTER regridding:
  `val = density_to_suit(d, "ud", area = cell area_km2)` — 100 minus the percent of the modelled
  population in cells strictly denser than this one, so the densest cell is 100 and the cells with
  `val >= 100 - p` are exactly the p % core. Cells with `val < 1` are dropped (the merge's floor). It is
  scale-free, which is why the Atlantic 2018 index and the Pacific densities are treated alike.
  The old recipe (`NC_TRANSFORM=cap`: linear to the species' pooled p99.5 of positive density, which left
  most cells near 0) stays available and is compared with it below.
- **Annual** = `msens::density_annual(n_intervals = 4)` on the DENSITIES — a season NCCOS did not
  model counts as zero — and THEN the same transform. The v8 ingest averaged the transformed values
  over the seasons a cell was *present* in, biasing the annual upward for the sparsest species.
- **Crosswalk** (`data/nc_taxon_crosswalk.csv`, written HERE): common name first, then scientific
  name, then explicit overrides, resolved to the BirdLife `sisid` (the `bl` model table) and the WoRMS
  AphiaID (`spp.duckdb`). `model_nc.csv` carries `sisid`, `worms_id`, `is_guild`, `response_type`;
  `merge_models_prep.qmd` excludes `is_guild` rows.

> **Not yet folded into merge/scoring** (a flagged scoring change, `FOLD_DENSITY`).

## The Atlantic source: `NC_ATL_SOURCE` (`2018` default = control, `2023`)

The Pacific half (Leirness et al. 2021, seasonal) is the same under both. The Atlantic half has two
sources, selected by `NC_ATL_SOURCE`; **the control is `2018`**, which reproduces v10 / the pre-2023
ingest exactly, and **only one Atlantic source is ever ingested in a run** (the 2018 Atlantic models leave
the dataset when `2023` is on).

| | `2018` (default, control) | `2023` |
|---|---|---|
| model | Winship et al. 2018 [@winship2018], OCS Study BOEM 2018-010 | Winship et al. 2023 [@winship2023], OCS Study BOEM 2023-060 |
| product | in-repo COGs `data/sdm/raw/nc_atl_birds_dens/` | MDAT **Avian Relative Density v3.0** (Duke MGEL, April 2024 release) [@curtice2018] |
| species | 47 (140 seasonal models) | 49 (incl. black tern, Forster's tern, lesser black-backed gull; bridled tern dropped) |
| intervals | 4 seasons (+ annual) | 12 months `01`..`12` (+ annual) |
| grid | 2 km, Hotine oblique Mercator | 10 km, Hotine oblique Mercator (NAD83, azimuth 40, centre 75W 35N, k 0.9996) |
| observations | 1978-2016 | 1998-2019 (the files are named `1993_2019`) |
| download | -- | `raw/seamap.env.duke.edu/mdat/v3/` (this notebook downloads it, pins the sha256, records `SOURCE.json`) |

Under `2023`: each species' 12 monthly rasters are reprojected bilinearly to EPSG:4326 and regridded to the
0.05 degree cells exactly as the Pacific COGs are (`cells_from_raster(digits = NULL, min_value = 1e-12)`),
transformed month by month with `density_to_suit("ud")` (cell-area weighted), and the **annual** is OUR
integration of the twelve densities, **day-weighted**: `density_annual(n_intervals = 12, interval = <month>,
weights = msens::month_day_weights())` (msens >= 0.65.1; February counts 28/365), then transformed. The package's own
**delivered Annual** layer is the day-weighted mean of its twelve months (checked here on the native grid to float
precision), so the two should now agree to the regrid's rounding; it is regridded the same way and compared per
species (`data/nc_atl2023_annual_compare.csv`), with the plain 12-month mean kept as a sensitivity (it differs by
up to 8 % in a cell). The Pacific seasons stay equal-weighted (4 seasons, as the 2018 control). The package carries no
"no survey effort" raster: the hatched mask of the MDAT map services is an overlay that is not part of
the download, and every one of the 637 density rasters is strictly positive on the same 13,419 modelled
cells (NaN elsewhere; no zeros, no -9999). The provenance columns `source`, `accession`, `citation` of the
2023 models come from `SOURCE.json`; the front matter above cannot be conditional, so it describes both
sources and `model_nc.csv` / the manifest say which one ran.

**Smoke test (writes nothing to the version's `dist/`).** `NC_SMOKE_DIR=<scratch dir>` redirects the dataset
partition, `model_nc.csv`, the crosswalk and both comparison tables to that directory and skips the
manifest; `NC_TEST_SP=ATPU,BLTE,COMU` (or `NC_TEST_N=<n>`) restricts the regridding to those species.
It refuses a directory inside the big-data root.

The `ud` transform weights each cell by its area (the population in a cell is density × area). The
`cell` table is a property of the grid, not of the release: this version's `sdm.duckdb` is used when
`build_cell_grid` has written it, else `ver_prev`'s (which `build_cell_grid` copies unchanged).

### Crosswalk: common name → scientific name → override, to BirdLife `sisid` and WoRMS AphiaID

The AOU codes are defined by common name, so a common name is the strongest key; the NCCOS scientific
names follow an older taxonomy (`Puffinus gravis` vs *Ardenna gravis*), which is why a name-only match

## Regrid + transform

```{r}
#| label: functions

# a source model's density on the 0.05° cells: bilinear reprojection of the omerc COG to EPSG:4326, then
# cells_from_raster() (bilinear onto the cell grid, zero-filled so the surface fades to 0 at its edge).
# digits = NULL: the raster holds NATIVE density, which rounds to 0 at 2 decimals; min_value is a
# positive epsilon, i.e. "any positive density" (the default 1 would drop every cell of a density < 1).
# The 2023 Atlantic rasters (Hotine oblique Mercator, 10 km, NaN nodata) take exactly this path.
src_path <- function(region_ds, sp_code, season) {
  if (region_ds == mdat_ds) mdat_files$path[mdat_files$code == str_to_lower(sp_code) & mdat_files$interval == season]
  else here(glue("data/sdm/raw/{region_ds}/{sp_code}_{season}.tif"))
}
dens_cells <- function(region_ds, sp_code, season) {
  f <- src_path(region_ds, sp_code, season)
  if (length(f) != 1 || !file_exists(f)) return(NULL)
  r <- terra::project(terra::rast(f, lyrs = 1), "EPSG:4326", method = "bilinear")
  msens::cells_from_raster(r, cellid_tif, min_value = 1e-12, digits = NULL) |> rename(dens = val)
}

# intervals per year: 4 seasons, or the 12 months of the 2023 Atlantic package
n_int <- function(region) if (src_2023 && region == "Atlantic") 12L else 4L

# the annual DENSITY of one region's (cell_id, interval, dens) rows: the mean over ALL intervals, an unmodelled one = 0.
# 2023 Atlantic = the DAY-WEIGHTED mean of the 12 months (what the package's own Annual layer is; msens >= 0.65.1);
# the Pacific seasons (and the whole 2018 control) stay equal-weighted, 4 seasons, exactly as before
annual_of <- function(x, region, plain = FALSE) {
  if (src_2023 && region == "Atlantic" && !plain)
    msens::density_annual(x, n_intervals = 12, interval = "interval", weights = msens::month_day_weights())
  else msens::density_annual(x, n_intervals = n_int(region))
}
if (src_2023) stopifnot("NC_ATL_SOURCE=2023 needs msens >= 0.65.1 (density_annual weights / month_day_weights)" =
                          utils::packageVersion("msens") >= "0.65.1")

# density -> [0,100]: the v11 population percentile (ud, area-weighted by the cell table), or the v8
# recipe (cap: linear to the species' pooled p99.5 of positive density, clamped)
to_val <- function(dens, cell_id, how, cap = NA_real_) {
  if (how == "ud") msens::density_to_suit(dens, "ud", area = cell_area(cell_id), digits = 2)
  else             round(100 * pmin(dens / cap, 1), 2)
}

# a species' models in one region as (cell_id, interval, dens)
region_dens <- function(sp_code, region) {
  mi <- m |> filter(sp_code == !!sp_code, region == !!region)
  map2_dfr(mi$region_ds, mi$season, \(rd, s) dens_cells(rd, sp_code, s) |> mutate(interval = s))
}
```

### The annual surface is the mean over ALL intervals of the year

An unmodelled interval counts as zero (NCCOS fits a season only where the species was sighted enough to
model; the 2023 Atlantic package models every species in all twelve months). Checked on the densities, before
any transform, on hand-picked species: with every interval modelled the annual equals the mean of the
intervals (plain for the 4 seasons; DAY-WEIGHTED for the 12 months of the 2023 Atlantic); a species missing a season has a LOWER annual than the
present-only mean (by exactly n_present / 4).

```{r}
annual_compare <- function(code, ours, deliv, plain) {
  stat <- \(a, b) {

         p95 = quantile(both$a / both$b, .95, names = FALSE), sum = sum(j$a) / sum(j$b), n_both = nrow(both))
  }
  d <- stat(ours, deliv); p <- stat(plain, deliv)

  M <- vapply(sprintf("%02d", 1:12), nat, numeric(terra::ncell(terra::rast(src_path(mdat_ds, code, "01")))))
  A <- nat("annual"); ok <- !is.na(A)
  pl <- rowMeans(M); dw <- as.vector(M %*% (days_in_month / sum(days_in_month)))
  tibble(sp_code = code, n_cells_ours = nrow(ours), n_cells_deliv = nrow(deliv), n_both = d$n_both,
         r_pearson = d$r, median_ratio = d$med, p05_ratio = d$p05, p95_ratio = d$p95, sum_ratio = d$sum,

}
```
