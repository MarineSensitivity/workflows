Monthly hexagon abundance (#/40 km²) → density → population-percentile suitability [1,100] on the global 0.05° grid

Published

2026-10-29

NOAA SEFSC Gulf-of-Mexico cetacean & sea-turtle spatial density models (NCEI 0256800 v2.2) — 19 hexagon shapefiles, one per species/population, each carrying monthly abundance {Mon}_n (individuals per 40 km² hexagon, -9999 = no data). Like the nc seabird ingest (ingest_sdm-nc.qmd), v11 rasterizes each (species × month) onto the global 0.05° cell grid and maps the heavy-tailed density onto the merge’s [1,100] scale by the population-percentile transform (msens::density_to_suit(method = "ud")), plus an annual surface for scoring. Two dolphins are modelled as split Oceanic + Shelf populations; each population is rasterized on its own geometry (the Oceanic hexagons are clipped, the Shelf ones “Unclipped”) and the densities are summed per cell.

  • Inputs are local (gm_shp_dir in libs/paths.R, GM_SHP_DIR overrides): the 19 shapefiles and ../spp_gmx.xlsx under {dir_raw}/sdm/gm/0256800/2.2/data/0-data/, hydrated by scripts/pull_from_laptop.sh --drive.
  • mdl_key: monthly gm|{sp_id}|{01..12} + annual gm|{sp_id}; sp_id = WORMS:{AphiaID} of taxa_sci, resolved offline from spp.duckdb’s worms table (no API call).
  • Density = {Mon}_n / 40 individuals km⁻², regridded with cells_from_raster(digits = NULL, min_value = 1e-12). The v8 ingest left digits at its default 2, which rounded the RAW densities (0.001–0.01 individuals km⁻² for the rare species) to 0.00 / 0.01 before dividing by the cap: Rice’s whale (gm|WORMS:1576133) and the beaked-whale model (gm|WORMS:137035) came out flat 100 over their range.
  • Value transform (v11 Q6, D12). Per model (species × month) AFTER regridding: val = density_to_suit(d, "ud", area = cell area_km2) — 100 minus the percent of the modelled population in cells strictly denser than this one, so the densest cell is 100 and val >= 100 - p is exactly the p % core. Cells with val < 1 are dropped (the merge’s floor). The old recipe (GM_TRANSFORM=cap: linear to the species’ pooled p99.5 of positive density, now applied to the regridded densities) stays available and is compared below.
  • Annual = msens::density_annual(n_intervals = 12) on the DENSITIES — a month the model does not cover counts as zero — and THEN the same transform. The v8 ingest averaged the transformed values over the months a cell was present in; the Kogia model covers April–November only, so its annual was biased upward by 12/8.
  • Guilds (is_guild): a sp_id whose WoRMS rank is not Species (Delphinidae for the blackfish, Ziphius for all beaked whales, Globicephala, Kogia), or whose spp_gmx row names several species. They keep their gm|WORMS:{id} keys, so nothing downstream is renamed, and merge_models_prep.qmd excludes is_guild rows.
  • The sea turtles in this dataset are real species and are ingested like any other; the merge gives turtles their own rule.

Not yet folded into merge/scoring unless FOLD_DENSITY is set (merge_models_prep.qmd).

4 Regrid + transform

Code 
# one shapefile (one population) -> long (cell_id, interval, dens) on the 0.05° cells: density = {Mon}_n / 40
# individuals km-2, each month rasterized on a template cropped from the cell-id COG, then cells_from_raster()
# (zero-filled; digits = NULL because the raster holds NATIVE density, which rounds to 0 at 2 decimals; min_value is
# a positive epsilon, i.e. "any positive density"). A month with no modelled hexagon (-9999 everywhere) is absent.
dens_cells_shp <- function(path) {
  x   <- read_sf(path) |> st_transform(4326)
  mos <- intersect(glue("{month.abb}_n"), names(x))
  v   <- terra::vect(x |> select(all_of(mos)))
  tmpl <- terra::crop(r_grid, terra::ext(v), snap = "out")
  map_dfr(mos, \(mo) {
    f  <- as.numeric(v[[mo]][, 1])
    ok <- which(f != NA_VAL & !is.na(f))
    if (!length(ok)) return(NULL)
    vv <- v[ok]; vv$dens <- f[ok] / 40
    r  <- terra::rasterize(vv, tmpl, field = "dens")
    msens::cells_from_raster(r, cellid_tif, min_value = 1e-12, digits = NULL) |> rename(dens = val) |>
      mutate(interval = sprintf("%02d", match(str_remove(mo, "_n$"), month.abb)))
  })
}

# a sp_id's models as (cell_id, interval, dens): populations summed per cell and month
sp_dens <- function(sid) {
  paths <- m$path_shp[m$sp_id == sid]
  map_dfr(paths, dens_cells_shp) |>
    group_by(cell_id, interval) |> summarise(dens = sum(dens), .groups = "drop")
}

# density -> [0,100]: the v11 population percentile (ud, area-weighted by the cell table), or the v8
# recipe (cap: linear to the species' pooled p99.5 of positive density, clamped)
to_val <- function(dens, cell_id, how, cap = NA_real_) {
  if (how == "ud") msens::density_to_suit(dens, "ud", area = cell_area(cell_id), digits = 2)
  else             round(100 * pmin(dens / cap, 1), 2)
}

4.1 The annual surface is the mean over ALL twelve months

A month the model does not cover counts as zero. Checked on the densities, before any transform, on hand-picked species: with twelve months the annual equals the plain mean of the months; the Kogia model covers April–November only, so its annual is exactly 8/12 of the mean over its modelled months, and lower than the present-only mean the v8 ingest used (by n_present / 12).

# per sp_id: regrid every month (populations summed), add the annual (density_annual on the DENSITIES), transform
# each model on its own cells (both recipes, for the comparison), write the selected one.
# resumable (skip existing parquet) unless REDO_INGEST.
sp_ids   <- sort(unique(m$sp_id))
cmp_rows <- list(); cap_rows <- list()
for (sid in sp_ids) {
  safe <- gsub("[^A-Za-z0-9._-]", "_", sid)
  if (file_exists(pq_path(safe, NA)) && !redo_ingest) next

  dd <- sp_dens(sid)
  if (!nrow(dd)) { log_warn("no positive density for {sid}"); next }
  # the v8 recipe's 100 point: pooled p99.5 of the species' positive (regridded) densities, all months
  cap <- as.numeric(quantile(dd$dens, p_cap, names = FALSE))
  if (!is.finite(cap) || cap <= 0) cap <- max(dd$dens)
  ann <- msens::density_annual(dd, n_intervals = 12) |> mutate(interval = "annual")
  res <- bind_rows(dd, ann) |> group_by(interval) |>
    group_modify(\(x, k) tibble(cell_id = x$cell_id, dens = x$dens,
                                v_ud = to_val(x$dens, x$cell_id, "ud"), v_cap = to_val(x$dens, x$cell_id, "cap", cap))) |>
    ungroup() |> mutate(val = if (gm_transform == "ud") v_ud else v_cap)

  # per-model comparison of the two recipes (cells written = val >= 1)
  q <- \(v) if (length(v)) quantile(v, c(.1, .5, .9), names = FALSE) else rep(NA_real_, 3)
  cmp_rows[[sid]] <- res |> group_by(interval) |>
    summarise(n_cells = n(), n_ud = sum(v_ud >= 1), n_cap = sum(v_cap >= 1),
              ud_q10 = q(v_ud[v_ud >= 1])[1], ud_q50 = q(v_ud[v_ud >= 1])[2], ud_q90 = q(v_ud[v_ud >= 1])[3],
              cap_q10 = q(v_cap[v_cap >= 1])[1], cap_q50 = q(v_cap[v_cap >= 1])[2], cap_q90 = q(v_cap[v_cap >= 1])[3],
              .groups = "drop") |>
    mutate(sp_id = sid, common_name = m$common_name[m$sp_id == sid][1], .before = 1)
  cap_rows[[sid]] <- tibble(sp_id = sid, dens_cap = cap)

  for (iv in unique(res$interval)) {
    d <- res |> filter(interval == iv, val >= 1)
    if (!nrow(d)) next
    write_surface(d, sid, if (iv == "annual") NA_character_ else iv, safe)
  }
}
log_info("rasterized {length(cmp_rows)} sp_id ({gm_transform})")

NOAA SEFSC [Gulf-of-Mexico cetacean & sea-turtle spatial density models](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.nodc:256800)
(NCEI 0256800 v2.2) — 19 hexagon shapefiles, one per species/population, each carrying monthly abundance
`{Mon}_n` (individuals per 40 km² hexagon, `-9999` = no data). Like the **nc** seabird ingest
(`ingest_sdm-nc.qmd`), v11 rasterizes each (species × month) onto the global 0.05° cell grid and maps the
heavy-tailed density onto the merge's **[1,100]** scale by the **population-percentile** transform
(`msens::density_to_suit(method = "ud")`), plus an **annual** surface for scoring. Two dolphins are modelled
as split **Oceanic + Shelf** populations; each population is rasterized on its own geometry (the Oceanic
hexagons are clipped, the Shelf ones "Unclipped") and the densities are **summed** per cell.

- **Inputs are local** (`gm_shp_dir` in `libs/paths.R`, `GM_SHP_DIR` overrides): the 19 shapefiles and
  `../spp_gmx.xlsx` under `{dir_raw}/sdm/gm/0256800/2.2/data/0-data/`, hydrated by `scripts/pull_from_laptop.sh --drive`.
- **`mdl_key`**: monthly `gm|{sp_id}|{01..12}` + annual `gm|{sp_id}`; `sp_id = WORMS:{AphiaID}` of `taxa_sci`,
  resolved offline from `spp.duckdb`'s `worms` table (no API call).
- **Density** = `{Mon}_n / 40` individuals km⁻², regridded with `cells_from_raster(digits = NULL, min_value = 1e-12)`.
  The v8 ingest left `digits` at its default 2, which rounded the RAW densities (0.001–0.01 individuals km⁻² for the
  rare species) to 0.00 / 0.01 *before* dividing by the cap: Rice's whale (`gm|WORMS:1576133`) and the beaked-whale
  model (`gm|WORMS:137035`) came out flat 100 over their range.
- **Value transform (v11 Q6, D12).** Per model (species × month) AFTER regridding:
  `val = density_to_suit(d, "ud", area = cell area_km2)` — 100 minus the percent of the modelled population in
  cells strictly denser than this one, so the densest cell is 100 and `val >= 100 - p` is exactly the p % core.
  Cells with `val < 1` are dropped (the merge's floor). The old recipe (`GM_TRANSFORM=cap`: linear to the species'
  pooled p99.5 of positive density, now applied to the *regridded* densities) stays available and is compared below.
- **Annual** = `msens::density_annual(n_intervals = 12)` on the DENSITIES — a month the model does not cover counts
  as zero — and THEN the same transform. The v8 ingest averaged the transformed values over the months a cell was
  *present* in; the Kogia model covers April–November only, so its annual was biased upward by 12/8.
- **Guilds** (`is_guild`): a `sp_id` whose WoRMS rank is not Species (Delphinidae for the blackfish, *Ziphius*
  for all beaked whales, *Globicephala*, *Kogia*), or whose `spp_gmx` row names several species. They keep their
  `gm|WORMS:{id}` keys, so nothing downstream is renamed, and `merge_models_prep.qmd` excludes `is_guild` rows.
- The sea turtles in this dataset are real species and are ingested like any other; the merge gives turtles
  their own rule.

> **Not yet folded into merge/scoring** unless `FOLD_DENSITY` is set (`merge_models_prep.qmd`).

```{r}
# one shapefile (one population) -> long (cell_id, interval, dens) on the 0.05° cells: density = {Mon}_n / 40
# individuals km-2, each month rasterized on a template cropped from the cell-id COG, then cells_from_raster()
# (zero-filled; digits = NULL because the raster holds NATIVE density, which rounds to 0 at 2 decimals; min_value is
# a positive epsilon, i.e. "any positive density"). A month with no modelled hexagon (-9999 everywhere) is absent.
dens_cells_shp <- function(path) {
  x   <- read_sf(path) |> st_transform(4326)
  mos <- intersect(glue("{month.abb}_n"), names(x))
  v   <- terra::vect(x |> select(all_of(mos)))
  tmpl <- terra::crop(r_grid, terra::ext(v), snap = "out")
  map_dfr(mos, \(mo) {
    f  <- as.numeric(v[[mo]][, 1])
    ok <- which(f != NA_VAL & !is.na(f))
    if (!length(ok)) return(NULL)
    vv <- v[ok]; vv$dens <- f[ok] / 40
    r  <- terra::rasterize(vv, tmpl, field = "dens")
    msens::cells_from_raster(r, cellid_tif, min_value = 1e-12, digits = NULL) |> rename(dens = val) |>
      mutate(interval = sprintf("%02d", match(str_remove(mo, "_n$"), month.abb)))
  })
}

# a sp_id's models as (cell_id, interval, dens): populations summed per cell and month
sp_dens <- function(sid) {
  paths <- m$path_shp[m$sp_id == sid]
  map_dfr(paths, dens_cells_shp) |>
    group_by(cell_id, interval) |> summarise(dens = sum(dens), .groups = "drop")
}

# density -> [0,100]: the v11 population percentile (ud, area-weighted by the cell table), or the v8
# recipe (cap: linear to the species' pooled p99.5 of positive density, clamped)
to_val <- function(dens, cell_id, how, cap = NA_real_) {
  if (how == "ud") msens::density_to_suit(dens, "ud", area = cell_area(cell_id), digits = 2)
  else             round(100 * pmin(dens / cap, 1), 2)
}
```

### The annual surface is the mean over ALL twelve months

A month the model does not cover counts as zero. Checked on the densities, before any transform, on
hand-picked species: with twelve months the annual equals the plain mean of the months; the Kogia model covers
April–November only, so its annual is exactly 8/12 of the mean over its modelled months, and lower than the
present-only mean the v8 ingest used (by n_present / 12).

```{r}
#| label: annual-check

wide_of <- \(d) d |> pivot_wider(names_from = interval, values_from = dens, values_fill = 0)

# twelve months: annual == plain mean of the twelve (checked on three species, one of them Rice's whale)
chk12 <- c(`Sperm whale` = "WORMS:137119", `Rice's whale` = "WORMS:1576133", `Loggerhead` = "WORMS:137205")
for (nm_ in names(chk12)) {
  d   <- sp_dens(chk12[[nm_]]); stopifnot(n_distinct(d$interval) == 12)
  ann <- msens::density_annual(d, n_intervals = 12)
  plain <- wide_of(d) |> transmute(cell_id, mean12 = rowMeans(across(-cell_id)))
  j <- inner_join(ann, plain, by = "cell_id")
  stopifnot("annual != plain 12-month mean" = nrow(j) == nrow(ann), nrow(j) == nrow(plain),
            max(abs(j$dens - j$mean12)) < 1e-12 * max(j$mean12))
}

# Kogia, April-November only
kg <- sp_dens("WORMS:159024")
stopifnot("Kogia months changed (expected Apr-Nov)" = setequal(unique(kg$interval), sprintf("%02d", 4:11)))

stopifnot("Kogia annual != 8/12 of the mean over its modelled months" =
            nrow(j) == nrow(ann_kg), all(abs(j$dens - j$m8 * 8 / 12) < 1e-12 * max(j$m8)),
          "Kogia annual != present-only mean x n_present/12" = all(abs(j$dens - j$po * j$n_ssn / 12) < 1e-12 * max(j$po)),
```

```{r}
# per sp_id: regrid every month (populations summed), add the annual (density_annual on the DENSITIES), transform
# each model on its own cells (both recipes, for the comparison), write the selected one.
# resumable (skip existing parquet) unless REDO_INGEST.
sp_ids   <- sort(unique(m$sp_id))
cmp_rows <- list(); cap_rows <- list()
for (sid in sp_ids) {
  safe <- gsub("[^A-Za-z0-9._-]", "_", sid)
  if (file_exists(pq_path(safe, NA)) && !redo_ingest) next

  dd <- sp_dens(sid)
  if (!nrow(dd)) { log_warn("no positive density for {sid}"); next }
  # the v8 recipe's 100 point: pooled p99.5 of the species' positive (regridded) densities, all months
  cap <- as.numeric(quantile(dd$dens, p_cap, names = FALSE))
  if (!is.finite(cap) || cap <= 0) cap <- max(dd$dens)
  ann <- msens::density_annual(dd, n_intervals = 12) |> mutate(interval = "annual")
  res <- bind_rows(dd, ann) |> group_by(interval) |>
    group_modify(\(x, k) tibble(cell_id = x$cell_id, dens = x$dens,
                                v_ud = to_val(x$dens, x$cell_id, "ud"), v_cap = to_val(x$dens, x$cell_id, "cap", cap))) |>
    ungroup() |> mutate(val = if (gm_transform == "ud") v_ud else v_cap)

  # per-model comparison of the two recipes (cells written = val >= 1)
  q <- \(v) if (length(v)) quantile(v, c(.1, .5, .9), names = FALSE) else rep(NA_real_, 3)
  cmp_rows[[sid]] <- res |> group_by(interval) |>
    summarise(n_cells = n(), n_ud = sum(v_ud >= 1), n_cap = sum(v_cap >= 1),
              ud_q10 = q(v_ud[v_ud >= 1])[1], ud_q50 = q(v_ud[v_ud >= 1])[2], ud_q90 = q(v_ud[v_ud >= 1])[3],
              cap_q10 = q(v_cap[v_cap >= 1])[1], cap_q50 = q(v_cap[v_cap >= 1])[2], cap_q90 = q(v_cap[v_cap >= 1])[3],
              .groups = "drop") |>
    mutate(sp_id = sid, common_name = m$common_name[m$sp_id == sid][1], .before = 1)
  cap_rows[[sid]] <- tibble(sp_id = sid, dens_cap = cap)

  for (iv in unique(res$interval)) {
    d <- res |> filter(interval == iv, val >= 1)
    if (!nrow(d)) next
    write_surface(d, sid, if (iv == "annual") NA_character_ else iv, safe)
  }
}
```
