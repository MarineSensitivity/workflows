--- layout: default title: "Query the Marine Atlas" ---

A browser-only DuckDB-WASM playground that queries the v8 Marine Atlas Parquet directly on S3 — no server, no download. Pick an example or write your own SQL; it runs against the public read_parquet('…/marine-atlas/v8/tables/*.parquet') tables documented on the schema page. First run cold-starts the WASM engine (~5 s), then it's fast (DuckDB range-reads only the bytes it needs).
