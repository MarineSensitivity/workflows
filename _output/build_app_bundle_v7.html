Build the atlas app/ bundle — the browser’s data contract

Master plan D5 (“normalize at publish, not in the browser”) and atlas-1 Deliverable 4. Both Shiny apps carry a per-version adapter today — two grids, mdl_seq vs mdl_key, value vs val, is_ok vs is_valid_usa, a taxon_model self-edge on one side only — each with a production bug recorded behind it. msens::app_bundle_build() (msens 0.43.0, R/app_bundle.R) already resolves every one of those quirks, with tests. This notebook is the thin publishing shell around it: build → validate → push (gated) → verify (gated), one version-independent {ver}/app/ bundle per release.

Nothing here publishes anything. The push and verification chunks are real, runnable code, gated behind APP_BUNDLE_S3=1 (unset by default) exactly like every other side-effecting step in this repo (../CLAUDE.md reproducibility rule 1) — this notebook can be rendered top to bottom, safely, with no S3 credentials and no network write of any kind.

APP_BUNDLE_VERS=v7,v9 narrows a run to that set (comma-separated); unset, every version in data/versions.csv is attempted, and a version whose release database is not on this machine is skipped, not failed (the same convention build_version_manifest.qmd’s caps_override uses: a capability this run cannot see is FALSE, never invented). APP_BUNDLE_V7_CELLMODEL=1 additionally uploads v7’s missing serve/cell_model/ (757 MB locally, absent from S3 today even though v7’s manifest advertises cell_species_list: true — the atlas-1 “Facts” note) under its own flag, separate from the ordinary {ver}/app/ push. Both flags are strict ([app_bundle_flag()]): only exactly 1 turns them on — 0, true, false, no, anything else STOPS the render naming the variable, rather than guessing.

Two things worth saying out loud so nobody “fixes” them. First, a restricted release gets exactly the same objects under {ver}/app/ as a public one — the review gate that matters is which HOST serves them (atlas-9: the public site never renders a restricted version; the preview host does, behind Access), not what this notebook writes, so build_app_bundle.qmd never branches on access. Second, even with APP_BUNDLE_S3 and APP_BUNDLE_V7_CELLMODEL both unset — the default, publish-nothing case — a legacy-generation dry run (v1–v7b) still downloads roughly 165 MB anonymously from the public bucket (.attach_s3_legacy()’s tables/*.parquet cache, measured against v7, 2026-09-21: 13 tables, 164,894,811 bytes, dominated by cell_metric at 109 MB): reading nothing is not the same as touching nothing.

Which database. msens::sdm_db_path(ver) returns the release’s build database, and prefers sdm.duckdb over serve.duckdb whenever the former exists on this machine. That is right for v8/v9, whose native_asset table lives IN sdm.duckdb — but wrong for v1–v7b: their local sdm.duckdb has neither model_asset nor native_asset at all (verified 2026-09-21 against the real v7 release: model, not model_asset, holds only dataset/taxon/region metadata, no COG URL). model_asset is written only by backfill_versions.qmd, as a view in serve.duckdb. Opening the wrong database is not an error — app_bundle_build() runs to completion and every taxon’s merged and inputs[].assets come back silently empty, which is exactly the failure mode this contract exists to prevent everywhere else.

Three tiers, each PROBED (a view existing by name is not enough — serve.duckdb’s views embed the LOCAL paths of the machine that built them, so a copy rsynced to a laptop lists a model_asset view that then fails the moment it is queried; discovered running this notebook for real against v7):

  1. sdm_db_path(ver) (sdm.duckdb, or serve.duckdb if that is what sdm_db_path() itself falls back to) — right for v8/v9.
  2. serve.duckdb beside it, if (1) has no working asset table — right on the SERVER that built it.
  3. An ephemeral, anonymous, read-only DuckDB attached directly to this release’s published tables/*.parquet on S3 (httpfs, path-style; no credentials, no write) — right anywhere, including this laptop, for any released/public version. Never used for a restricted version (nothing to attach yet, or nothing this notebook should read anonymously either).
# does `tbl` exist AND actually return rows when queried (not just listed)?
.probe_table <- function(con, tbl) {
  if (!tbl %in% DBI::dbListTables(con)) return(FALSE)
  isTRUE(tryCatch(DBI::dbGetQuery(con, glue("SELECT count(*) n FROM {tbl} LIMIT 1"))$n >= 0,
                  error = function(e) FALSE))
}
.has_asset_tbl <- function(con) any(vapply(c("model_asset", "native_asset"), .probe_table, logical(1), con = con))

# tier 3: views over a LOCAL CACHE of the PUBLISHED tables/*.parquet -- downloaded
# once, anonymously, read-only (no S3 write, no credentials). attach_atlas() does
# the remote-view version of this for v8+'s native_asset shape, but has no
# model_asset/taxon_model view -- and a REMOTE view here was measured to be
# impractically slow: a full aggregation over `cell_metric` (unprunable row
# groups) via anonymous httpfs range reads did not finish in over an hour, where
# the equivalent LOCAL query takes seconds. `tables/` for a whole legacy release
# is under 200 MB (atlas-1 plan "Facts": v7 cell 22.7 MB + cell_metric 109 MB +
# the rest under 25 MB combined), so caching it locally costs a one-time download,
# not a redesign.
.attach_s3_legacy <- function(ver, access) {
  if (!identical(access, "public")) return(NULL)
  cache_dir <- here("_output", "app_bundle", "_s3cache", ver, "tables")
  fs::dir_create(cache_dir)
  http <- sprintf("%s/%s", base, ver)
  tbls <- c("cell", "taxon", "model", "model_asset", "metric", "cell_metric",
           "zone", "zone_cell", "zone_metric", "zone_taxon", "dataset", "taxon_model", "listing")
  got <- vapply(tbls, function(t) {
    dest <- file.path(cache_dir, paste0(t, ".parquet"))
    if (file.exists(dest)) return(TRUE)
    isTRUE(tryCatch(
      utils::download.file(sprintf("%s/tables/%s.parquet", http, t), dest,
                           mode = "wb", quiet = TRUE) == 0L,
      error = function(e) FALSE, warning = function(w) FALSE))
  }, logical(1))
  if (!any(got)) return(NULL)
  con <- DBI::dbConnect(duckdb::duckdb())
  ok <- vapply(tbls[got], function(t) {
    isTRUE(tryCatch({
      DBI::dbExecute(con, glue(
        "CREATE OR REPLACE VIEW {t} AS SELECT * FROM read_parquet('{cache_dir}/{t}.parquet')"))
      .probe_table(con, t)
    }, error = function(e) FALSE))
  }, logical(1))
  if (!.has_asset_tbl(con)) { DBI::dbDisconnect(con, shutdown = TRUE); return(NULL) }
  log_warn("{ver}: cached + attached {sum(ok)}/{length(tbls)} tables from {http}/tables/ ({cache_dir})")
  con
}

app_bundle_open <- function(ver) {
  v_row  <- versions_csv |> filter(ver == !!ver)
  access <- if (nrow(v_row)) v_row$access[1] else "restricted"
  db  <- path.expand(msens::sdm_db_path(ver))
  if (file.exists(db)) {
    con <- DBI::dbConnect(duckdb::duckdb(), db, read_only = TRUE)
    if (.has_asset_tbl(con)) return(list(con = con, db = db, ok = TRUE))
    DBI::dbDisconnect(con, shutdown = TRUE)
  }
  alt <- file.path(fs::path_dir(db), "serve.duckdb")
  if (fs::path_file(db) != "serve.duckdb" && file.exists(alt)) {
    con2 <- DBI::dbConnect(duckdb::duckdb(), alt, read_only = TRUE)
    if (.has_asset_tbl(con2)) {
      log_warn("{ver}: sdm.duckdb has no working model_asset/native_asset; using serve.duckdb ({alt})")
      return(list(con = con2, db = alt, ok = TRUE))
    }
    DBI::dbDisconnect(con2, shutdown = TRUE)
  }
  con3 <- .attach_s3_legacy(ver, access)
  if (!is.null(con3)) return(list(con = con3, db = sprintf("s3 (anonymous, tables/) %s/%s", base, ver), ok = TRUE))
  if (!file.exists(db)) return(list(con = NULL, db = db, ok = FALSE))
  log_warn(paste(
    "{ver}: no database anywhere (local sdm.duckdb, local serve.duckdb, S3 tables/) carries",
    "model_asset/native_asset -- merged COG urls and input assets will be EMPTY (not an error)"))
  list(con = DBI::dbConnect(duckdb::duckdb(), db, read_only = TRUE), db = db, ok = TRUE)
}

Build

One msens::app_bundle_build() call per version — review round 1 (2026-09-21): the prior version of this notebook composed the bundle itself (app_boot(..., tables = list()), manifest_build() with no zone_tiles), which is why boot$tables (the OPFS invalidation key) and boot$units (the drawable units) came out EMPTY on both real dry runs. app_bundle_build() is the one function that wires app_table_descriptor()/app_table_manifest() into app_boot() correctly; calling it directly is what makes tables and units non-empty, not a bigger tryCatch. geom_keys — the published geometry keys app_units() needs to exclude whole-study-area rollups (USA/FULL) — comes from [app_bundle_geom_keys()], which reads the zone-set registry’s own source GeoPackage rather than guessing a filename.

app/taxonomy.parquet still has no msens builder (a curated CSV, not a database table), so it is written here, from the JUST-WRITTEN taxon.parquet (never a second query), via app_taxonomy_table() (libs/app_bundle.R).

app_bundle_build() now isolates its own internal stages (msens 0.43.0 @ 7c6eb3a, landed during review round 1): strict = TRUE (its default) still stops the WHOLE build at the first failing stage — right for an actual publish, wrong for this notebook’s diagnostic pass — so this notebook always passes strict = FALSE, matching the function’s own documented “notebook’s diagnostic pass” use case: every stage that CAN complete does, out$failed names whichever didn’t, and the outer tryCatch below is only a safety net for anything upstream of stage() (e.g. manifest_build() itself).

build_one <- function(ver) {
  t0 <- Sys.time()
  opened <- app_bundle_open(ver)
  if (!isTRUE(opened$ok)) {
    log_warn("{ver}: no local release database at {opened$db} -- SKIPPED")
    return(list(ver = ver, ok = FALSE, reason = "no local database"))
  }
  con <- opened$con
  on.exit(DBI::dbDisconnect(con, shutdown = TRUE), add = TRUE)
  duckdb_tune(con, file.path(tempdir(), "app_bundle_spill", ver))

  dir_out <- file.path(dir_out_root, ver)
  if (fs::dir_exists(dir_out)) fs::dir_delete(dir_out)   # clean slate every run
  fs::dir_create(dir_out)

  v_row <- versions_csv |> filter(ver == !!ver)
  status <- if (nrow(v_row)) v_row$status[1] else "prerelease"
  access <- if (nrow(v_row)) v_row$access[1] else "restricted"

  f_scog  <- file.path(fs::path_dir(opened$db), "tables", "score_cog.parquet")
  metrics <- if (file.exists(f_scog)) {
    arrow::read_parquet(f_scog) |> filter(!startsWith(metric_key, "_")) |>
      transmute(metric_key, subregion_key, cog = cog_url, rescale_min, rescale_max, colormap)
  } else NULL

  zone_sets <- readr::read_csv(here("data/zone_sets.csv"), show_col_types = FALSE)
  # round-2 fix: manifest_build()'s zone_tiles was never passed, so every
  # zone's pmtiles stayed NA and app_units() -- which requires a non-NA
  # pmtiles -- returned ZERO units regardless of geom_keys. Same construction
  # build_version_manifest.qmd uses.
  zone_tiles <- setNames(
    as.list(glue("{base}/zones/{zone_sets$zone_set_key}/zones.pmtiles")),
    zone_sets$zone_set_key)
  mfst <- msens::manifest_build(con, ver, status = status, access = access, base = base,
                                metrics = metrics, zone_tiles = zone_tiles, zone_sets = zone_sets)
  geom_keys <- app_bundle_geom_keys(mfst$zones, zone_sets, dir_derived)

  out <- tryCatch(
    msens::app_bundle_build(con, ver, dir_out, manifest = mfst, base = base,
                            geom_keys = geom_keys, strict = FALSE),
    error = function(e) {
      log_warn("{ver}: app_bundle_build() FAILED (upstream of stage isolation): {substr(conditionMessage(e), 1, 300)}")
      NULL
    })
  if (!is.null(out) && length(out$failed))
    for (nm in names(out$failed))
      log_warn("{ver}: stage '{nm}' FAILED: {substr(out$failed[[nm]], 1, 300)}")

  txm_ok <- FALSE
  if (!is.null(out)) {
    txm_ok <- isTRUE(tryCatch({
      tx <- arrow::read_parquet(file.path(dir_out, "taxon.parquet"))
      d  <- app_taxonomy_table(tx)
      msens::write_atlas_parquet(d, file.path(dir_out, "taxonomy.parquet"))
      TRUE
    }, error = function(e) {
      log_warn("{ver}: taxonomy.parquet FAILED: {conditionMessage(e)}")
      FALSE
    }))
  }

  list(ver = ver, ok = !is.null(out), dir_out = dir_out, con_db = opened$db, manifest = mfst,
       geom_keys = geom_keys, out = out, taxonomy_ok = txm_ok,
       n_failed_stages = if (is.null(out)) NA_integer_ else length(out$failed),
       wall_s = as.numeric(Sys.time() - t0, units = "secs"))
}

Validate

app_bundle_build()’s builders already validate their own output as they write it (app_validate(), R/app_bundle.R); this chunk re-validates the WRITTEN BYTES, round-tripped through disk exactly as an app would fetch them — the same discipline build_version_manifest.qmd applies to manifest.json — and proves the schemas actually reject a broken shape, not just accept a good one.

revalidate_written <- function(b) {
  if (!isTRUE(b$ok)) return(tibble())
  files <- list(
    boot  = list(path = file.path(b$dir_out, "boot.json"),  schema = "boot"),
    taxa  = list(path = file.path(b$dir_out, "taxa.json"),  schema = "taxa"))
  rows <- purrr::imap(files, function(f, nm) {
    if (!file.exists(f$path)) return(data.frame(ver = b$ver, object = nm, ok = NA, note = "not built"))
    x <- jsonlite::fromJSON(f$path, simplifyVector = FALSE)
    ok <- tryCatch({ msens::app_validate(x, f$schema); TRUE },
                    error = function(e) { message(conditionMessage(e)); FALSE })
    data.frame(ver = b$ver, object = nm, ok = ok, note = "")
  })
  for (kind in c("taxon", "alias")) {
    d <- file.path(b$dir_out, kind)
    if (!dir.exists(d)) next
    fs_ <- list.files(d, full.names = TRUE)
    bad <- 0L
    for (f in fs_) {
      x <- jsonlite::fromJSON(f, simplifyVector = FALSE)
      ok <- tryCatch({ msens::app_validate(x, kind); TRUE }, error = function(e) FALSE)
      if (!ok) bad <- bad + 1L
    }
    rows[[kind]] <- data.frame(ver = b$ver, object = sprintf("%s/*.json (n=%d)", kind, length(fs_)),
                               ok = bad == 0L, note = if (bad) sprintf("%d shard(s) FAILED", bad) else "")
  }
  bind_rows(rows)
}

boot.json actually carries its OPFS keys and drawable units

Review round 1’s root finding: composing the bundle by hand (rather than calling app_bundle_build()) left boot$tables and boot$units EMPTY on both real dry runs. boot.json now carries its own id_field (msens 7c6eb3a), so this gate cross-checks it against the manifest’s directly, rather than only checking the manifest’s in isolation (round 1’s stopgap, removed).

boot_contract_gate <- function(b) {
  if (!isTRUE(b$ok) || is.null(b$out)) return(tibble())
  boot   <- b$out$boot
  tables <- b$out$tables      # named list of app_table_descriptor() results
  digest_ok <- vapply(tables, function(d) {
    got <- as.character(msens::parquet_digest(file.path(b$dir_out, d$path))$digest[1])
    identical(got, d$digest)
  }, logical(1))
  data.frame(
    ver = b$ver,
    n_tables            = length(tables),
    tables_ge_3         = length(tables) >= 3,
    all_digests_match   = length(digest_ok) > 0 && all(digest_ok),
    n_digest_mismatches = sum(!digest_ok),
    n_units             = length(boot$units),
    units_ge_1          = length(boot$units) >= 1,
    boot_id_field       = boot$id_field %||% NA_character_,
    manifest_id_field   = b$manifest$id_field %||% NA_character_,
    id_field_matches    = !is.null(boot$id_field) && !is.null(b$manifest$id_field) &&
      identical(boot$id_field, b$manifest$id_field) &&
      boot$id_field %in% c("mdl_key", "mdl_seq"))
}
`%||%` <- function(a, b) if (is.null(a)) b else a

set_gates <- function(b, ver) {

  on.exit(DBI::dbDisconnect(con, shutdown = TRUE), add = TRUE)

  layer_keys <- sort(vapply(b$out$boot$layers, function(l) l$metric_key, ""))
  layers_ok  <- identical(cell_keys, layer_keys)

  taxa_keys <- if (file.exists(taxa_path))
    unique(unname(unlist(jsonlite::fromJSON(taxa_path, simplifyVector = FALSE)$key))) else character()

  taxon_dir <- file.path(b$dir_out, "taxon")

    shard_keys <- unique(unname(unlist(lapply(list.files(taxon_dir, full.names = TRUE), function(f)
      names(jsonlite::fromJSON(f, simplifyVector = FALSE)$taxa)))))
    shards_ok <- setequal(shard_keys, taxa_keys)
    n_shard_keys <- length(shard_keys)
  }

  alias_ok <- NA; n_alias_bad <- NA_integer_
  alias_dir <- file.path(b$dir_out, "alias")

    targets <- unname(unlist(lapply(list.files(alias_dir, full.names = TRUE), function(f) {

    n_alias_bad <- length(bad)

}

.budget_row <- function(object, sizes, kind, budget_bytes) {
  if (!length(sizes)) return(NULL)
  data.frame(object = object, kind = kind, n = length(sizes),
             bytes_p50 = as.integer(round(median(sizes))),
             bytes_p90 = as.integer(round(quantile(sizes, 0.9))),
             bytes_max = as.integer(max(sizes)),
             budget_bytes = as.integer(budget_bytes),
             n_over_budget = sum(sizes > budget_bytes))
}
.sizes_for <- function(dir_out, object, kind) {
  gz_of <- function(p) { tmp <- tempfile(fileext = ".gz"); app_bundle_gzip_file(p, tmp)
                         sz <- file.size(tmp); unlink(tmp); sz }
  if (object %in% c("boot.json", "taxa.json")) {
    p <- file.path(dir_out, object)
    if (!file.exists(p)) return(numeric())
    if (kind == "gzip") gz_of(p) else file.size(p)
  } else if (object %in% c("taxon/*.json", "alias/*.json")) {
    d <- file.path(dir_out, sub("/\\*\\.json$", "", object))
    if (!dir.exists(d)) return(numeric())
    fs_ <- list.files(d, full.names = TRUE)
    if (kind == "gzip") vapply(fs_, gz_of, numeric(1)) else file.size(fs_)
  } else if (object == "cell/tile=*/data_0.parquet") {
    fs_ <- Sys.glob(file.path(dir_out, "cell", "tile=*", "data_0.parquet"))  # browser-equivalent
    file.size(fs_)
  } else {  # taxon.parquet, taxonomy.parquet, zone_taxon.parquet
    p <- file.path(dir_out, object)
    if (!file.exists(p)) numeric() else file.size(p)
  }
}

s3_root <- "s3://oceanmetrics.io-public/marine-atlas"

list_prefix <- function(prefix) {
  out <- system2("aws", c("s3", "ls", shQuote(glue("{s3_root}/{prefix}")), "--recursive"),
                stdout = TRUE, stderr = TRUE)
  if (!is.null(attr(out, "status")) && attr(out, "status") != 0) character(0) else out
}

push_one <- function(b) {
  if (!isTRUE(b$ok)) return(invisible(NULL))
  ver <- b$ver
  before <- list_prefix(glue("{ver}/app/"))
  log_info("{ver}/app/ BEFORE push: {length(before)} object(s)")

  # a controlled directory walk of dir_out -- every file that exists under it,
  # nothing else -- then EVERY key derived from it still goes through the
  # whitelist guard before anything touches S3; the walk being "controlled"
  # is not itself the protection, the guard call two lines down is
  files <- list.files(b$dir_out, recursive = TRUE, full.names = TRUE)
  rels  <- fs::path_rel(files, b$dir_out)
  keys  <- glue("{ver}/app/{rels}")
  app_bundle_assert_prefix(keys, ver)                       # refuse before touching S3

  for (i in seq_along(files)) {
    is_json <- grepl("\\.json$", files[i])
    src <- files[i]
    if (is_json) {
      gz <- tempfile(fileext = ".gz")
      app_bundle_gzip_file(files[i], gz)                    # byte-safe, never readLines()
      app_bundle_assert_gzip_roundtrip(gz, files[i])         # proves upload bytes == validated bytes
      src <- gz
    }
    args <- c("s3", "cp", shQuote(src), shQuote(glue("{s3_root}/{keys[i]}")),
              if (is_json) c("--content-type", shQuote("application/json"),
                             "--content-encoding", "gzip"))
    out <- system2("aws", args, stdout = TRUE, stderr = TRUE)
    if (!is.null(attr(out, "status")) && attr(out, "status") != 0)
      stop(glue("aws s3 cp failed for {keys[i]}: {paste(out, collapse = '\n')}"))
    if (is_json) unlink(src)
  }

  if (isTRUE(do_v7_cm) && ver == "v7") {
    cm_local <- path.expand("~/_big/msens/derived/v7/cell_model")
    if (dir.exists(cm_local)) {
      cm_files <- list.files(cm_local, recursive = TRUE, full.names = TRUE)
      cm_keys  <- glue("v7/serve/cell_model/{fs::path_rel(cm_files, cm_local)}")
      app_bundle_assert_prefix(cm_keys, "v7", allow_v7_cell_model = TRUE)
      system2("aws", c("s3", "sync", shQuote(cm_local), shQuote(glue("{s3_root}/v7/serve/cell_model")),
                       "--only-show-errors"), stdout = TRUE, stderr = TRUE)
    } else log_warn("APP_BUNDLE_V7_CELLMODEL=1 but {cm_local} does not exist locally")
  }

  after <- list_prefix(glue("{ver}/app/"))
  log_info("{ver}/app/ AFTER push: {length(after)} object(s) ({length(after) - length(before)} new)")
  invisible(list(before = before, after = after))
}
push_out <- purrr::map(builds, push_one)

  if (!isTRUE(b$ok)) return(tibble())
  ver <- b$ver
  files <- list.files(b$dir_out, recursive = TRUE, full.names = TRUE)
  rels  <- fs::path_rel(files, b$dir_out)
  urls  <- glue("{base}/{ver}/app/{rels}")
  purrr::map_dfr(seq_along(urls), function(i) {
    r <- tryCatch(
      httr2::req_perform(httr2::req_error(httr2::req_method(httr2::request(urls[i]), "HEAD"),
                                          is_error = function(resp) FALSE)),
      error = function(e) NULL)
    is_json <- grepl("\\.json$", files[i])
    data.frame(
      ver = ver, key = rels[i],
      status = if (is.null(r)) NA_integer_ else httr2::resp_status(r),
      path_style = grepl("^https://s3\\.[a-z0-9-]+\\.amazonaws\\.com/", urls[i]),
      gzip_ok = if (is.null(r) || !is_json) NA else
        identical(httr2::resp_header(r, "content-encoding"), "gzip"),
      bytes = if (is.null(r)) NA_integer_ else
        suppressWarnings(as.integer(httr2::resp_header(r, "content-length"))))
  })
}
verify_tbl <- bind_rows(purrr::map(builds, verify_one))
