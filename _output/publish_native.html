A release owns pointers, never files (asset store, 2026-10). Every distribution file this notebook produces — the per-model COGs, the per-model range PMTiles, the merged whole-range COGs — goes into the content-addressed store shared by every release, and the release gets a pointer table (native_asset: mdl_key × representation → asset_url) that names those objects. Nothing is ever written under {ver}/.

marine-atlas/cog/global05/{hash}.tif        rasters ON the analysis grid: per-input "model", merged, score
marine-atlas/native/{ds_key}/{hash}.tif     source-resolution originals (AquaMaps 0.5°, AquaX as delivered)
marine-atlas/native/{ds_key}/{hash}.pmtiles source polygons of a vector range, one PMTiles per model
marine-atlas/assets.parquet                 the catalog: one row per stored object
{ver}/tables/native_asset.parquet           the release's pointers (pushed by release_marine-atlas.qmd)

The key is known before the file is built. It is the hash of the content the file will hold — the pixels a COG stores (msens::pixel_hashes(): the rows quantised as the writer quantises them, repeated cells collapsed by max() as the merge consumes them) or the source geometry of a range (msens::native_vector_hash()) — folded with the file family’s encoding tag (msens::asset_store_key()). So a surface the catalog already lists costs neither a build nor an upload; a changed surface gets a new key, and older releases keep pointing at the old, still-present object. The object’s MD5 is an integrity column of the catalog, never a key.

Order of operations (and why). Keys → build only what the catalog lacks → decode-verify every new COG against its key → upload → catalogue → gate (msens::store_publish_gate(): every pointer is a catalogued store object; nothing bulk under {ver}/) → write the pointer table. A pointer is written only after its object is catalogued, so a reader can never follow one into a 404.

Two representations per input where the source has one of its own: native (the original: polygons, the 0.5° AquaMaps cells, the AquaX band as delivered) and model (the 0.05° gridded surface the merge consumed). AquaX is delivered ON the grid, so its pair is Delivered / As ingested (dataset.on_grid). The served set is every taxon valid in EITHER surface ((is_valid_usa OR is_valid_global) & is_marine, non reptile/amphibian): neither flag alone is a superset of the other.

Flags: NATIVE_NO_S3=1 (dry run: keys, builds and the upload plan; no upload, no catalog, no pointer table), NATIVE_TEST_N=<n> (first n keys per class), NATIVE_SKIP_AM / NATIVE_SKIP_PMTILES, NATIVE_PMT_DS=a,b (vector datasets to tile), NATIVE_VEC_COG=1 / PUBLISH_MERGED_COG=1 (opt-in classes), REDO_MERGED_COG=1 / REDO_MERGED_COG_KEYS / REDO_MERGED_COG_SPATIAL=1 (repartition the merged surface; the key then decides whether anything is new), REDO_IUCN_SRC=1, REDO_KEYS=1 (recompute the cached content hashes), NATIVE_NO_VERIFY=1 (skip the decode check of new COGs), NATIVE_LEGACY_OK=1 (before the M6 prune: v8/v9 still carry pre-store copies under {ver}/native/; the gate then warns instead of stopping), NATIVE_REGISTRY_REBUILD=1 (publish ONLY what this run built; otherwise a class this run did not build is carried forward from the published table), NATIVE_WORKERS=<n>, NATIVE_CATALOG=<assets.parquet> (read the catalog from a file instead of the bucket — tests).

NATIVE_SKIP_AM cannot be combined with a merged rebuild. The am-only aliases — ms_merge pointer rows at an existing AquaMaps model object — are derived from the am rows, so skipping am empties their source and the ms_merge class shrinks; registry_merge() refuses that, but the run has spent its time by then.

# a content-hash table is cached per (release, class) and recomputed when its source changed (file count,
# bytes, newest mtime) or REDO_KEYS=1 -- hashing dist/am is minutes, not seconds
src_sig <- function(paths) {
  fi <- file_info(dir_ls(paths[dir_exists(paths)], recurse = TRUE, type = "file"))
  paste(nrow(fi), sum(as.numeric(fi$size)), as.integer(max(c(fi$modification_time, as.POSIXct(0, origin = "1970-01-01")))), sep = "-")
}
cached_keys <- function(name, src_dirs, expr) {
  f <- glue("{dir_keys}/{name}.parquet"); sig <- src_sig(src_dirs)
  if (!redo_keys && file_exists(f)) {
    x <- as_tibble(read_parquet(f))
    if (identical(x$src_sig[1], sig)) return(select(x, -src_sig))
    log_info("keys {name}: source changed, recomputing")
  }
  t0 <- Sys.time(); x <- as_tibble(expr); x$src_sig <- sig
  write_parquet(x, f, compression = "zstd")
  log_info("keys {name}: {nrow(x)} models in {round(as.numeric(Sys.time() - t0, units = 'mins'), 1)} min")
  select(x, -src_sig)
}
# a big source is hashed in FILE BATCHES, each its own read_parquet([...]): the GROUP BY (by, cell_id)
# then never holds more than one batch. The whole-glob form over dist/am (50 GB, 23,699 one-model files)
# spilled 138 GB of DuckDB temp and filled the laptop disk (2026-10-06), and over dist_merged_global
# (3.1 G rows) ran out of memory outright (2026-10-07). Valid only where a model's rows never straddle two
# batches -- a key seen in two batches stops the run rather than hash half a surface. `files` may be globs
# (one per bucket dir or hive partition); `from(lst)` builds the source from the quoted file list
pixel_hashes_batched <- function(files, n_batch, by = "mdl_key", from = function(lst) glue("read_parquet([{lst}])"), ...) {
  b   <- split(files, ceiling(seq_along(files) / n_batch))
  out <- vector("list", length(b))
  for (i in seq_along(b)) {
    con <- new_con()
    lst <- paste(sprintf("'%s'", b[[i]]), collapse = ",")
    out[[i]] <- pixel_hashes(con, from(lst), by, ...)
    dbDisconnect(con, shutdown = TRUE)
    if (i %% 5 == 0 || i == length(b)) log_info("  hashed file batch {i}/{length(b)}")
  }
  h <- bind_rows(out)
  stopifnot("a model's rows straddle two file batches -- batching by file is invalid for this source" =
              !anyDuplicated(h[[by]]))
  h
}

add_plan <- function(d, class) {                                             # d: mdl_key, key, hash, content_hash, enc, file (local, may be NA when catalogued)

# a painter shared by every gridded class: rows (mdl_key, out, sql) -> publish_cog() into the store mirror.
# `sql` selects (cell_id, val) for the model; `round_first` applies the writer's own rounding (ax, merged-suit)
paint_rows <- function(rows, grid, round_first = FALSE, workers = n_workers) {
  rows <- rows[!file_exists(rows$out), ]
  rows <- rows[!duplicated(rows$out), ]                                    # two models with identical pixels = one object
  if (!nrow(rows)) return(invisible(0L))
  one_batch <- function(b) {
    suppressMessages({library(DBI); library(duckdb); library(terra)})
    con <- dbConnect(duckdb()); dbExecute(con, "SET memory_limit='3GB'; SET threads=2")   # SET: the config list is ignored
    on.exit(dbDisconnect(con, shutdown = TRUE))
    for (i in seq_len(nrow(b))) {
      if (file.exists(b$out[i])) next
      d <- dbGetQuery(con, b$sql[i])
      if (round_first) d$val <- round(d$val)
      if (nrow(d)) msens::publish_cog(d$cell_id, d$val, b$out[i], grid)
    }
    nrow(b)
  }
  if (workers > 1 && nrow(rows) > 1) {
    plan(multisession, workers = workers); on.exit(plan(sequential), add = TRUE)
    future_map(split(rows, (seq_len(nrow(rows)) - 1) %% workers), one_batch,
               .options = furrr_options(packages = c("msens"), seed = TRUE))
  } else one_batch(rows)
  invisible(sum(file_exists(rows$out)))
}

A release **owns pointers, never files** (asset store, 2026-10). Every distribution file this notebook
produces — the per-model COGs, the per-model range PMTiles, the merged whole-range COGs — goes into the
**content-addressed store** shared by every release, and the release gets a **pointer table**
(`native_asset`: `mdl_key × representation → asset_url`) that names those objects. Nothing is ever
written under `{ver}/`.

```
marine-atlas/cog/global05/{hash}.tif        rasters ON the analysis grid: per-input "model", merged, score
marine-atlas/native/{ds_key}/{hash}.tif     source-resolution originals (AquaMaps 0.5°, AquaX as delivered)
marine-atlas/native/{ds_key}/{hash}.pmtiles source polygons of a vector range, one PMTiles per model
marine-atlas/assets.parquet                 the catalog: one row per stored object
{ver}/tables/native_asset.parquet           the release's pointers (pushed by release_marine-atlas.qmd)
```

**The key is known before the file is built.** It is the hash of the content the file will hold — the
pixels a COG stores (`msens::pixel_hashes()`: the rows quantised as the writer quantises them, repeated
cells collapsed by `max()` as the merge consumes them) or the source geometry of a range
(`msens::native_vector_hash()`) — folded with the file family's encoding tag
(`msens::asset_store_key()`). So a surface the catalog already lists costs neither a build nor an
upload; a changed surface gets a new key, and older releases keep pointing at the old, still-present
object. The object's MD5 is an integrity column of the catalog, never a key.

**Order of operations (and why).** Keys → build only what the catalog lacks → decode-verify every new COG
against its key → upload → catalogue → **gate** (`msens::store_publish_gate()`: every pointer is a
catalogued store object; nothing bulk under `{ver}/`) → write the pointer table. A pointer is written
only after its object is catalogued, so a reader can never follow one into a 404.

Two representations per input where the source has one of its own: `native` (the original: polygons,
the 0.5° AquaMaps cells, the AquaX band as delivered) and `model` (the 0.05° gridded surface the merge
consumed). AquaX is delivered ON the grid, so its pair is *Delivered / As ingested* (`dataset.on_grid`).
The served set is every taxon valid in EITHER surface (`(is_valid_usa OR is_valid_global) & is_marine`,
non reptile/amphibian): neither flag alone is a superset of the other.

**Flags:** `NATIVE_NO_S3=1` (dry run: keys, builds and the upload plan; no upload, no catalog, no
pointer table), `NATIVE_TEST_N=<n>` (first n keys per class), `NATIVE_SKIP_AM` / `NATIVE_SKIP_PMTILES`,
`NATIVE_PMT_DS=a,b` (vector datasets to tile), `NATIVE_VEC_COG=1` / `PUBLISH_MERGED_COG=1` (opt-in
classes), `REDO_MERGED_COG=1` / `REDO_MERGED_COG_KEYS` / `REDO_MERGED_COG_SPATIAL=1` (repartition the
merged surface; the key then decides whether anything is new), `REDO_IUCN_SRC=1`, `REDO_KEYS=1`
(recompute the cached content hashes), `NATIVE_NO_VERIFY=1` (skip the decode check of new COGs),
`NATIVE_LEGACY_OK=1` (before the M6 prune: v8/v9 still carry pre-store copies under `{ver}/native/`;
the gate then warns instead of stopping), `NATIVE_REGISTRY_REBUILD=1` (publish ONLY what this run
built; otherwise a class this run did not build is carried forward from the published table),
`NATIVE_WORKERS=<n>`, `NATIVE_CATALOG=<assets.parquet>` (read the catalog from a file instead of the
bucket — tests).

> **`NATIVE_SKIP_AM` cannot be combined with a merged rebuild.** The am-only *aliases* — `ms_merge`
> pointer rows at an existing AquaMaps `model` object — are derived from the am rows, so skipping am
> empties their source and the `ms_merge` class shrinks; `registry_merge()` refuses that, but the run
> has spent its time by then.

```{r}
# a big source is hashed in FILE BATCHES, each its own read_parquet([...]): the GROUP BY (by, cell_id)
# then never holds more than one batch. The whole-glob form over dist/am (50 GB, 23,699 one-model files)
# spilled 138 GB of DuckDB temp and filled the laptop disk (2026-10-06), and over dist_merged_global
# (3.1 G rows) ran out of memory outright (2026-10-07). Valid only where a model's rows never straddle two
# batches -- a key seen in two batches stops the run rather than hash half a surface. `files` may be globs
# (one per bucket dir or hive partition); `from(lst)` builds the source from the quoted file list
pixel_hashes_batched <- function(files, n_batch, by = "mdl_key", from = function(lst) glue("read_parquet([{lst}])"), ...) {
  b   <- split(files, ceiling(seq_along(files) / n_batch))
  out <- vector("list", length(b))
  for (i in seq_along(b)) {
    con <- new_con()
    lst <- paste(sprintf("'%s'", b[[i]]), collapse = ",")
    out[[i]] <- pixel_hashes(con, from(lst), by, ...)
    dbDisconnect(con, shutdown = TRUE)
    if (i %% 5 == 0 || i == length(b)) log_info("  hashed file batch {i}/{length(b)}")
  }
  h <- bind_rows(out)
  stopifnot("a model's rows straddle two file batches -- batching by file is invalid for this source" =
              !anyDuplicated(h[[by]]))
  h
}
```

```{r}
# `sql` selects (cell_id, val) for the model; `round_first` applies the writer's own rounding (ax, merged-suit)
paint_rows <- function(rows, grid, round_first = FALSE, workers = n_workers) {
  rows <- rows[!file_exists(rows$out), ]
  rows <- rows[!duplicated(rows$out), ]                                    # two models with identical pixels = one object
  if (!nrow(rows)) return(invisible(0L))
  one_batch <- function(b) {
    suppressMessages({library(DBI); library(duckdb); library(terra)})
    con <- dbConnect(duckdb()); dbExecute(con, "SET memory_limit='3GB'; SET threads=2")   # SET: the config list is ignored
    on.exit(dbDisconnect(con, shutdown = TRUE))
    for (i in seq_len(nrow(b))) {
      if (file.exists(b$out[i])) next
      d <- dbGetQuery(con, b$sql[i])

  }
```

## Verify every new COG against its key

The key promises the pixels; before anything leaves this machine, each newly staged COG is decoded and
hashed the same way (`native_raster_rows()` + `content_hashes_df()`), and the result must equal the
key's payload hash. A mismatch is a bug in a painter, never something to upload.

```{r}
#| label: verify

plan_df <- bind_rows(plan)

    suppressMessages({library(terra); library(msens)})

      r <- msens::native_raster_rows(terra::rast(rows$file[i]), grids[[rows$family[i]]])
      if (!nrow(r)) return(NA_character_)
      msens::content_hashes_df(cbind(mdl_key = "x", r))$content_hash
    }, "")
    rows[c("key", "decoded")]
  }
  plan(multisession, workers = n_workers)
  got <- bind_rows(future_map(split(new_cogs, (seq_len(nrow(new_cogs)) - 1) %% max(1, min(n_workers, nrow(new_cogs)))), dec, grids = grids,
                              .options = furrr_options(packages = c("msens", "terra"), seed = TRUE)))
  plan(sequential)
  new_cogs <- new_cogs |> left_join(got, by = "key")                       # by key, never by position: the split interleaves rows
  bad <- new_cogs |> filter(is.na(decoded) | decoded != content_hash)
  if (nrow(bad)) {
    print(bad |> select(class, mdl_key, key, content_hash, decoded) |> head(20))
    stop(sprintf("%d of %d new COGs do not decode to the pixels their key promises — not uploading", nrow(bad), nrow(new_cogs)), call. = FALSE)
  }
  log_info("verified {nrow(new_cogs)} new COGs: decoded pixels == key")
} else if (nrow(new_cogs)) log_warn("NATIVE_NO_VERIFY: {nrow(new_cogs)} new COGs uploaded without the decode check")
```

## Upload → store, then catalogue

Only keys the catalog lacks are uploaded, each with its local store-mirror path; a key that already
exists on S3 but not in the catalog is an error (something wrote to the store outside it). After every
upload, the listing is re-read to prove each object is there, and only then are the rows appended to
`assets.parquet` and the catalog pushed.

```{r}
#| label: upload

up <- plan_df |> filter(!catalogued) |> distinct(key, .keep_all = TRUE)

  have_s3 <- c(cog_store_index("global05"), native_store_index())

  log_info("catalog: +{length(attr(catalog, 'added'))} rows -> {nrow(catalog)} objects, pushed assets.parquet")
  catalog <- as_tibble(catalog)
```
