Calibrating a cutoff and an island rule on the AquaMaps x IUCN pairs: Jaccard by cutoff, connected components, occurrence support, and the FAO-area consistency check

1 Goal

The merge masks AquaMaps suitability to a species range map (IUCN, BirdLife, FWS) where one exists. About 15,000 scored taxa have only AquaMaps, so their whole envelope, over-prediction included, enters the score. This notebook builds the evidence for a quantitative rule (AM_RANGE_RULE, default off) that constrains AquaMaps where no range map exists, calibrated on the taxa that have both an AquaMaps model and an IUCN range:

  1. per pair, the suitability mass inside the range, and for cutoffs t the footprint {val >= t} against the range (Jaccard, range kept, footprint outside), with t* = the cutoff of best Jaccard;
  2. whether t* is one number, follows a covariate available without a range map, or follows taxonomy;
  3. the islands a cutoff leaves (8-neighbour connected components), and how many of them hold an AquaMaps occurrence cell or an OBIS record;
  4. illustrative maps;
  5. the FAO-area consistency check of the AquaMaps native maps (plan section 6).

4 Calibration pairs

The spec pairs model_am.csv$iucn_id with model_rng_iucn.csv$id_no, falling back on the scientific name. In this release iucn_id is empty for every AquaMaps model (and spp.iucn_id in am.duckdb is too), so the id join yields nothing. The merge itself pairs models through WoRMS (merge_models_prep: every model’s scientific name to an accepted WoRMS id, so synonyms meet), and that crosswalk is in v8’s merge.duckdb taxon_model. The calibration set is the merge’s own pairing: every (AquaMaps model, IUCN range) that share an ms_merge_key.

# 0.5-degree occurrence cell -> its 100 global05 cell ids (column of a 100 x n matrix)
occ_cells <- function(lat, lon) {
  if (!length(lat)) return(matrix(integer(), 100, 0))
  br <- floor((90 - lat) / 0.5); bc <- floor((lon + 180) / 0.5)
  o  <- expand.grid(dr = 0:9, dc = 0:9)
  matrix(as.integer((rep(br * 10, each = 100) + o$dr) * nc + (rep(bc * 10, each = 100) + o$dc) + 1L), nrow = 100)
}

6 Connected components

terra::patches() on a global 0.05-degree raster took 2 min for one wide species (yellowfin tuna, 10.7 M cells, 11 cutoffs), so ~1,600+ pairs would take days. Instead cc8() labels 8-neighbour components from horizontal runs: each row’s runs of consecutive cells are nodes, a run touches the runs of the next row whose column span overlaps its own widened by one cell (that is the diagonal), and igraph::components() labels the graph. Runs at column 1 and 7200 also touch across the antimeridian (terra::patches does not wrap). The check below reproduces terra::patches exactly with the wrap off, on a coral (80 k cells) and the walrus (1.3 M cells).

Code 
cc8 <- function(id, nc = 7200L, wrap = TRUE) {
  # id: sorted global05 cell ids; returns the component of each, 1..n
  n <- length(id)
  if (n == 0) return(integer())
  id0 <- id - 1L; row <- id0 %/% nc; col <- id0 %% nc
  brk <- c(TRUE, diff(id0) != 1L | diff(row) != 0L)
  run <- cumsum(brk)
  R   <- data.table(run = seq_len(sum(brk)), row = row[brk], c0 = col[brk], c1 = col[c(brk[-1], TRUE)])
  A   <- R[, .(run, row = row + 1L, lo = c0 - 1L, hi = c1 + 1L)]
  e   <- R[A, on = .(row, c0 <= hi, c1 >= lo), .(a = i.run, b = x.run), nomatch = NULL, allow.cartesian = TRUE]
  if (wrap) {
    w0 <- R[c0 == 0L, .(run, row)]; w1 <- R[c1 == nc - 1L, .(run, row)]
    if (nrow(w0) && nrow(w1))
      e <- rbindlist(c(list(e), lapply(-1:1, \(d) w1[, .(row = row + d, b = run)][w0, on = .(row), .(a = i.run, b), nomatch = NULL])))
  }
  g <- make_graph(as.vector(t(as.matrix(e))), n = nrow(R), directed = FALSE)
  components(g)$membership[run]
}

For each pair: total suitability mass M = sum(val) over the AquaMaps cells, mass inside the IUCN range M_in, r = M_in / M; for each cutoff t the footprint F_t = {val >= t} against the ocean cells R of the range: Jaccard |F n R| / |F u R|, range kept |F n R| / |R|, footprint outside 1 - |F n R| / |F|, the number of components of F_t, and how many of them hold an AquaMaps occurrence cell and / or an OBIS record. Two connectivity rules are scored at every t: C1 keeps the components holding an AquaMaps occurrence cell, C2 those holding an AquaMaps occurrence cell or an OBIS record. The same statistics are computed inside US waters (in_usa), where the score is. t* = the cutoff of best Jaccard (ties to the lower t). Counts are cells, not km^2 (a 0.05-degree cell shrinks with latitude). Batches of 100 pairs are cached; a re-render reads them.

8.3 One cutoff vs taxonomy vs a covariate rule (5-fold cross-validation)

Each rule picks a cutoff for a species without looking at its range; the score is the Jaccard that cutoff achieves against the held-out species’ IUCN range, compared with the oracle t. Single: the one t maximizing mean Jaccard over the training folds. Class: the best t per AquaMaps class on the training folds (single t where a class is absent). Covariate tree: rpart regression of t on log occurrence records, log occurrence cells, log footprint cells, class, pelagic, layer, map_opt and reviewed, prediction snapped to the nearest cutoff on the grid. Leaf best: the same tree’s leaves, each given the cutoff that maximizes mean Jaccard over its training pairs (the tree as a grouping, not a predictor of t*).

No probability cutoff is supported as a single rule. Over the 3,549 calibration pairs the best cutoff t* is bimodal: for 52 % of species the whole AquaMaps footprint (t = 1, today’s merge for an AquaMaps-only taxon) is already the best match to the IUCN range, and the rest spread almost evenly from 5 to 90. In 5-fold cross-validation the single best cutoff is t = 1 in every fold, so the “single” rule IS the whole footprint (mean held-out Jaccard 0.353); the per-species oracle reaches only 0.385. A cutoff mainly trades range for footprint: at t = 30 the median species keeps 51 % of its IUCN range (72 % at t = 1) while the share of footprint outside the range falls from 53 % to 43 %. O’Hara et al. (2017)’s P >= 0.5 keeps 40 % of the range.

Taxonomy carries what signal there is, and it is the cartilaginous fishes. A per-class cutoff lifts the held-out mean to 0.363, almost all of it from Elasmobranchii (+0.045, cutoff 50 to 60), Holocephali and Myxini, whose envelopes hold only a third or less of their suitability mass inside the IUCN range (median r 0.34, 0.17, 0.25) against 0.56 for ray-finned fishes, 0.83 for corals and 0.72 for mammals. The covariate tree (0.354) does no better than the class rule and puts 68 % of its importance on class itself; the one strong continuous correlate of t* is range size (Spearman -0.50: small ranges want high cutoffs), which is unknown for exactly the taxa the rule is for. Species clipped by FAO areas alone (map_opt 2, 44 % of AquaMaps) match their ranges far worse (median Jaccard 0.26 vs 0.47) and want higher cutoffs.

Connectivity beats any cutoff. The footprint of a median species breaks into about 50 connected components at any cutoff, and at t = 30 only 23 % of a species’ components (15 % of all components) hold an AquaMaps occurrence cell or an OBIS record. Support scales with size: at t = 30, 96 % of components of 100 cells or fewer have no occurrence of either kind, while 85 % of components over 10,000 cells have one. Keeping only occurrence-supported components (rule C2) at t = 1 raises mean Jaccard from 0.353 to 0.381 while removing 11 % of footprint cells and lowering the median range kept from 72 % to 69 %. That gain is larger than any cutoff rule’s and close to the cutoff oracle’s, and it is the one rule that removes exactly what the maps show as islands.

Limits of the calibration. The IUCN range is the target, not the truth: 40 % of components overlap it, and the “range looks wrong” example (Micropogonias furnieri, 1,961 range cells against 97,038 AquaMaps cells, no occurrence inside the range) shows the target can fail. Jaccard inside US waters is low for every rule (0.14 at t = 1), so the agreement measured here is mostly a global statement; the US-scoring effect of a rule needs the pipeline’s own attribution run. OBIS records enter without effort correction.

12.1 Proposed rule for AM_RANGE_RULE (default off)

  1. connected: keep the whole AquaMaps footprint (no cutoff) but drop every connected component (8-neighbour, antimeridian wrapped) that holds neither an AquaMaps good cell nor an OBIS record since 1950. This is rule C2 above: the best measured agreement, 11 % of cells removed, the islands gone.
  2. connected_chondrichthyes (option to evaluate against 1): the same, plus a cutoff of 50 for Elasmobranchii, Holocephali and Myxini, the one taxonomic group where a cutoff is supported out of sample. The joint effect of cutoff and connectivity for that group is not measured here.
  3. Not proposed: a global cutoff (none beats t = 1), a covariate rule (no better than class, and range size is unavailable for the target taxa), or an FAO-area rule (AquaMaps already clips to the listed areas plus one ring of adjacent areas; a rule built on fao_areas would remove 11 % of cells AquaMaps deliberately painted).

The rule belongs in the merge input as a filter like supersede_sql(), behind the flag, with fixtures in msens, and its US-scoring effect read from one attribution variant before it is a v11 or v12 default.

## Goal

The merge masks AquaMaps suitability to a species range map (IUCN, BirdLife, FWS) where one exists. About 15,000
scored taxa have only AquaMaps, so their whole envelope, over-prediction included, enters the score. This notebook
builds the evidence for a quantitative rule (`AM_RANGE_RULE`, default off) that constrains AquaMaps where no range map
exists, calibrated on the taxa that have **both** an AquaMaps model and an IUCN range:

1. per pair, the suitability mass inside the range, and for cutoffs t the footprint {val >= t} against the range
   (Jaccard, range kept, footprint outside), with t* = the cutoff of best Jaccard;
2. whether t* is one number, follows a covariate available without a range map, or follows taxonomy;
3. the islands a cutoff leaves (8-neighbour connected components), and how many of them hold an AquaMaps occurrence
   cell or an OBIS record;
4. illustrative maps;
5. the FAO-area consistency check of the AquaMaps native maps (plan section 6).

## Connected components

`terra::patches()` on a global 0.05-degree raster took 2 min for one wide species (yellowfin tuna, 10.7 M cells, 11
cutoffs), so ~1,600+ pairs would take days. Instead `cc8()` labels 8-neighbour components from **horizontal runs**:
each row's runs of consecutive cells are nodes, a run touches the runs of the next row whose column span overlaps its
own widened by one cell (that is the diagonal), and `igraph::components()` labels the graph. Runs at column 1 and 7200
also touch across the antimeridian (`terra::patches` does not wrap). The check below reproduces `terra::patches` exactly
with the wrap off, on a coral (80 k cells) and the walrus (1.3 M cells).

```{r}
#| label: cc8

cc8 <- function(id, nc = 7200L, wrap = TRUE) {
  # id: sorted global05 cell ids; returns the component of each, 1..n
  n <- length(id)
  if (n == 0) return(integer())
  id0 <- id - 1L; row <- id0 %/% nc; col <- id0 %% nc
  brk <- c(TRUE, diff(id0) != 1L | diff(row) != 0L)
  run <- cumsum(brk)
  R   <- data.table(run = seq_len(sum(brk)), row = row[brk], c0 = col[brk], c1 = col[c(brk[-1], TRUE)])
  A   <- R[, .(run, row = row + 1L, lo = c0 - 1L, hi = c1 + 1L)]
  e   <- R[A, on = .(row, c0 <= hi, c1 >= lo), .(a = i.run, b = x.run), nomatch = NULL, allow.cartesian = TRUE]
  if (wrap) {
    w0 <- R[c0 == 0L, .(run, row)]; w1 <- R[c1 == nc - 1L, .(run, row)]
    if (nrow(w0) && nrow(w1))
      e <- rbindlist(c(list(e), lapply(-1:1, \(d) w1[, .(row = row + d, b = run)][w0, on = .(row), .(a = i.run, b), nomatch = NULL])))
  }
  g <- make_graph(as.vector(t(as.matrix(e))), n = nrow(R), directed = FALSE)
  components(g)$membership[run]
}
```

## Per-pair statistics

For each pair: total suitability mass M = sum(val) over the AquaMaps cells, mass inside the IUCN range M_in, r =
M_in / M; for each cutoff t the footprint F_t = {val >= t} against the ocean cells R of the range: Jaccard |F n R| /
|F u R|, range kept |F n R| / |R|, footprint outside 1 - |F n R| / |F|, the number of components of F_t, and how many of
them hold an AquaMaps occurrence cell and / or an OBIS record. Two connectivity rules are scored at every t: **C1** keeps
the components holding an AquaMaps occurrence cell, **C2** those holding an AquaMaps occurrence cell or an OBIS record.
The same statistics are computed inside US waters (`in_usa`), where the score is. t* = the cutoff of best Jaccard
(ties to the lower t). Counts are cells, not km^2 (a 0.05-degree cell shrinks with latitude). Batches of
`r batch_sz` pairs are cached; a re-render reads them.

### One cutoff vs taxonomy vs a covariate rule (5-fold cross-validation)

Each rule picks a cutoff for a species without looking at its range; the score is the Jaccard that cutoff achieves
against the held-out species' IUCN range, compared with the oracle t*. **Single**: the one t maximizing mean Jaccard
over the training folds. **Class**: the best t per AquaMaps class on the training folds (single t where a class is
absent). **Covariate tree**: `rpart` regression of t* on log occurrence records, log occurrence cells, log footprint
cells, class, pelagic, layer, map_opt and reviewed, prediction snapped to the nearest cutoff on the grid. **Leaf best**: the same tree's leaves, each given the cutoff that maximizes mean Jaccard over its
training pairs (the tree as a grouping, not a predictor of t*).

## FAO-area consistency of the AquaMaps native maps

Plan section 6: every one of the 118 M `spp_cells` rows is flagged `fao_area_yn = 1`, yet for 12.7 M of them the cell's
FAO area (`cells.fao_area_m`) is not in the species' `spp_prefs.fao_areas`. Four candidate explanations are tested per
off-list cell: (a) the cell's **inland** FAO code (`fao_area_in`) is listed; (b) the species has an AquaMaps
**occurrence** in that FAO area (`spp_occs.fao_area_m`), so the list is incomplete rather than the map wrong; (c) the
cell's area **borders** a listed area (FAO areas adjacent on the 0.5-degree grid, 8-neighbour, across the antimeridian);
(d) the cell's distance to the nearest cell of a listed area (geodesic, cell centres).

```{r}
                WHEN d_km <= 300 THEN 'c: 120-300 km' WHEN d_km <= 600 THEN 'd: 300-600 km' WHEN d_km <= 1200 THEN 'e: 600-1200 km' ELSE 'f: > 1200 km' END AS dist_to_listed,
           count(*) AS cells, count(DISTINCT sp_key) AS species,
           avg(in_in::INT) AS share_inland_listed, avg(m_occ::INT) AS share_area_has_occurrence, avg(m_adj::INT) AS share_area_adjacent,
           avg((m_occ OR m_adj OR in_in)::INT) AS share_any
    FROM fao_off GROUP BY 1 ORDER BY 1")
  tot <- dbGetQuery(con, "
    SELECT (SELECT count(*) FROM am.spp_cells WHERE fao_area_yn = 1) AS cells_flagged, count(*) AS cells_off_list, count(DISTINCT sp_key) AS species_off_list,
           sum(in_in::INT) AS inland_listed, sum(m_occ::INT) AS area_has_occurrence, sum(m_adj::INT) AS area_adjacent,
           sum((m_occ OR m_adj)::INT) AS occurrence_or_adjacent, sum((m_occ AND NOT m_adj)::INT) AS occurrence_not_adjacent,
           sum((NOT m_occ AND NOT m_adj AND NOT in_in)::INT) AS unexplained,
           sum((d_km <= 120)::INT) AS within_120km, sum((d_km <= 600)::INT) AS within_600km,
           sum((NOT m_occ AND NOT m_adj AND NOT in_in AND d_km > 600)::INT) AS unexplained_beyond_600km
    FROM fao_off")
  sp_top <- dbGetQuery(con, '
    SELECT o.sp_key, s.genus || \' \' || s.species AS species, p.fao_areas, p.map_opt, count(*) AS cells_off,
           string_agg(DISTINCT CAST(o.fao_area_m AS VARCHAR), \', \') AS off_areas, avg(o.m_occ::INT) AS share_occ,
           avg(o.m_adj::INT) AS share_adj, median(o.d_km) AS d_km_median
    FROM fao_off o JOIN am.spp s USING (sp_key) JOIN am.spp_prefs p USING (sp_key)
    GROUP BY ALL ORDER BY cells_off DESC LIMIT 15')
  # the ring test: every (species x marine FAO area) as listed / adjacent to a listed area / two or more areas away,
  # and whether the species' native map paints any cell there
  ring <- dbGetQuery(con, "
    WITH sp AS (SELECT DISTINCT sp_key FROM am.spp_prefs), ar AS (SELECT DISTINCT a AS fao FROM fao_adj),
    lst  AS (SELECT f.sp_key, f.fao FROM sp_fao f JOIN ar USING (fao)),
    adj1 AS (SELECT DISTINCT l.sp_key, j.b AS fao FROM lst l JOIN fao_adj j ON j.a = l.fao),
    pnt  AS (SELECT sc.sp_key, c.fao_area_m AS fao, count(*) AS n FROM am.spp_cells sc JOIN am.cells c ON c.cell_id = sc.cell_id
             WHERE sc.fao_area_yn = 1 GROUP BY ALL),
    g AS (
      SELECT sp.sp_key, ar.fao,
             CASE WHEN l.fao IS NOT NULL THEN '1 listed' WHEN a1.fao IS NOT NULL THEN '2 adjacent to a listed area' ELSE '3 two or more areas away' END AS ring,
             so.fao IS NOT NULL AS has_occurrence, p.n
      FROM sp CROSS JOIN ar
      LEFT JOIN lst l          ON l.sp_key  = sp.sp_key AND l.fao  = ar.fao
      LEFT JOIN adj1 a1        ON a1.sp_key = sp.sp_key AND a1.fao = ar.fao
      LEFT JOIN sp_occ_fao so  ON so.sp_key = sp.sp_key AND so.fao = ar.fao
      LEFT JOIN pnt p          ON p.sp_key  = sp.sp_key AND p.fao  = ar.fao)
    SELECT pr.map_opt, g.ring, g.has_occurrence, count(*) AS species_x_area, count(g.n) AS painted,
           avg((g.n IS NOT NULL)::INT) AS share_painted, COALESCE(sum(g.n), 0) AS cells
    FROM g JOIN am.spp_prefs pr USING (sp_key) GROUP BY ALL ORDER BY ALL")
  write_parquet(fao, f_fao); write_parquet(tot, f_fao_t); write_parquet(mo, f_fao_m); write_parquet(sp_top, f_fao_s); write_parquet(ring, f_fao_r)
  dbExecute(con, "DROP TABLE fao_off")
  duckdb_unregister(con, "fao_dist"); duckdb_unregister(con, "fao_adj")
}
fao <- read_parquet(f_fao); fao_tot <- read_parquet(f_fao_t); fao_mo <- read_parquet(f_fao_m); fao_sp <- read_parquet(f_fao_s); fao_ring <- read_parquet(f_fao_r)
```

**No probability cutoff is supported as a single rule.** Over the `r format(nrow(pv), big.mark = ",")` calibration pairs the
best cutoff t* is bimodal: for `r pct(p_t1)` of species the whole AquaMaps footprint (t = 1, today's merge for an
AquaMaps-only taxon) is already the best match to the IUCN range, and the rest spread almost evenly from 5 to 90.
In 5-fold cross-validation the single best cutoff is t = `r t_single` in every fold, so the "single" rule IS the
whole footprint (mean held-out Jaccard `r f3(cvm[["single"]])`); the per-species oracle reaches only
`r f3(cvm[["jac_star"]])`. A cutoff mainly trades range for footprint: at t = 30 the median species keeps 51 % of
its IUCN range (72 % at t = 1) while the share of footprint outside the range falls from 53 % to 43 %. O'Hara et al.
(2017)'s P >= 0.5 keeps 40 % of the range.

**Taxonomy carries what signal there is, and it is the cartilaginous fishes.** A per-class cutoff lifts the held-out
mean to `r f3(cvm[["class"]])`, almost all of it from Elasmobranchii (+`r f3(cls_gain$gain[cls_gain$cls == "Elasmobranchii"])`,
cutoff 50 to 60), Holocephali and Myxini, whose envelopes hold only a third or less of their suitability mass inside
the IUCN range (median r 0.34, 0.17, 0.25) against 0.56 for ray-finned fishes, 0.83 for corals and 0.72 for mammals.
The covariate tree (`r f3(cvm[["covariate_tree"]])`) does no better than the class rule and puts 68 % of its
importance on class itself; the one strong continuous correlate of t* is range size (Spearman -0.50: small ranges want
high cutoffs), which is unknown for exactly the taxa the rule is for. Species clipped by FAO areas alone
(`map_opt` 2, 44 % of AquaMaps) match their ranges far worse (median Jaccard 0.26 vs 0.47) and want higher cutoffs.

**Connectivity beats any cutoff.** The footprint of a median species breaks into about 50 connected components at
any cutoff, and at t = 30 only `r pct(mean(t30$n_cc_occ / t30$n_cc))` of a species' components (`r pct(sum(t30$n_cc_occ) / sum(t30$n_cc))` of all components) hold an AquaMaps occurrence cell or an OBIS record.
Support scales with size: at t = 30, 96 % of components of 100 cells or fewer have no occurrence of either kind, while
85 % of components over 10,000 cells have one. Keeping only occurrence-supported components (rule C2) at t = 1 raises
mean Jaccard from `r f3(conn1$jac)` to `r f3(conn1$jac_c2)` while removing `r pct(conn1$dropped)` of footprint cells and
lowering the median range kept from `r pct(conn1$keep)` to `r pct(conn1$keep_c2)`. That gain is larger than any cutoff
rule's and close to the cutoff oracle's, and it is the one rule that removes exactly what the maps show as islands.

**Limits of the calibration.** The IUCN range is the target, not the truth: 40 % of components overlap it, and the
"range looks wrong" example (*Micropogonias furnieri*, 1,961 range cells against 97,038 AquaMaps cells, no occurrence
inside the range) shows the target can fail. Jaccard inside US waters is low for every rule (0.14 at t = 1), so the
agreement measured here is mostly a global statement; the US-scoring effect of a rule needs the pipeline's own
attribution run. OBIS records enter without effort correction.

### Proposed rule for `AM_RANGE_RULE` (default off)

1. `connected`: keep the whole AquaMaps footprint (no cutoff) but drop every connected component (8-neighbour, antimeridian
   wrapped) that holds neither an AquaMaps good cell nor an OBIS record since `r year_min`. This is rule C2 above: the
   best measured agreement, 11 % of cells removed, the islands gone.
2. `connected_chondrichthyes` (option to evaluate against 1): the same, plus a cutoff of 50 for Elasmobranchii,
   Holocephali and Myxini, the one taxonomic group where a cutoff is supported out of sample. The joint effect of
   cutoff and connectivity for that group is not measured here.
3. Not proposed: a global cutoff (none beats t = 1), a covariate rule (no better than class, and range size is
   unavailable for the target taxa), or an FAO-area rule (AquaMaps already clips to the listed areas plus one ring of
   adjacent areas; a rule built on `fao_areas` would remove 11 % of cells AquaMaps deliberately painted).

The rule belongs in the merge input as a filter like `supersede_sql()`, behind the flag, with fixtures in msens, and
its US-scoring effect read from one attribution variant before it is a v11 or v12 default.
